# PW04 PPSW1-6b / 6c 독립 검증 (Schmitt & Weiner, SINUM 42(1) 2004)

범위: 정확/수치 재현 + 문헌만. Rust, git 없음. 스크립트와 receipt(cmd, exit, sha256)는 같은 폴더의 `PW04_PPSW1_6BC_VERIFICATION.json`에 있다. 모든 수치는 `python3 -I`로 실행했다 (mpmath 80-90자리, numpy/scipy).

## 1. 독립 재구성 (두 경로)
- 입력: 논문 (7), (14)-(16), (20)-(24), Table 1, Table 2. 매듭 c=(-1,-0.5,0,0.4,0.8,1).
- R1 (직접 선형풀이): Gamma(s) 조건 (14)에서 Gamma = -gamma*C*W^-1, beta는 (23) (beta~ = F0 S D^-1), A = beta - Gamma, AB(s) (15)에서 B*W = C - Q 풀이.
- R2 (닫힌 형태): Theta = V S P V^-1 (16), Gamma = -gamma*Theta, B = (I+gamma E)Theta + sigma*beta*E (21), E = -V D F0^T V^-1.
- 일치 (sigma=0.5, 0.8, 1, 1.05, 1.1; 6b, 6c 모두): B, A, Gamma는 약 86-88자리, beta는 90자리 일치. AB k=0..5와 Gamma k=0..5 잔차는 모두 1e-79 이하.
- (24)의 닫힌 형태 B~는 R2의 V^-1 B V와 1e-88 이내로 일치.
- 인쇄 오류 해석 (UNRESOLVED 항목, 일관성으로 해소): pdftotext상 V = (c_j^(i-1))로 읽히지만 이 규약이면 B*1 = 1과 B~ e1 = e1이 성립하지 않는다 (실제로 R2 AB 잔차가 O(10)). V_ij = c_i^(j-1) (노드 행)로 바꾸면 모두 성립한다.
- Table 1 (sympy): 다항식 v~_{s+1}(gamma)를 s=2..6에 대해 (24)의 (s+1)차 확장 행렬의 좌고유벡터에서 계산했고, 인쇄된 계수와 정확히 일치한다 (s=6: 720g^6 - 7920g^5 + 32760g^4 - 64200g^3 + 62130g^2 - 28098g + 4683).
- 6차 실근 90자리: 0.42378, **0.619411975066250516310763...**, **1.087080240637296732920472...**, 1.92572, 3.00457, 3.93943. 인쇄값 0.619411975066, 1.087080240637과 차이 2.5e-13, 3.0e-13 (반올림 범위). 인쇄된 gamma-hat 재현 = 예.
- 추가 확인: sigma=1에서 v^T r6 / v~_7(gamma) = 1.0 (gamma 6개 값에서 일치). 이는 정리 3.5의 초수렴 메커니즘(국소 잔차의 v 투영이 v~_{s+1}에 비례)을 수치로 확인한 것이다.

## 2. 차수 조건
- 변보폭 sigma in {0.5, 0.8, 1.0, 1.05, 1.10} 및 무작위 sigma 열 (0.5-1.10, 4열x40스텝): AB(6) (order-5 조건, k=0..5) 잔차 약 1e-78.
- k=6 잔차 (order-6 조건)는 0이 아니다. 최대 AB k6: 6b 30-153, 6c 72-408. 따라서 변보폭 국소 차수는 정확히 5 = s-1 (논문과 일치).
- 정수 보폭 초수렴: 논문 3.2절/정리 3.5. v^T Delta의 선도항이 v~_{s+1}(gamma)에 비례하므로 gamma-hat (6b, 6c 둘 다)에서 전역 차수 s=6. 변보폭에서는 일반적으로 성립하지 않는다 ("convenient for constant stepsizes only"). 6b와 6c의 gamma가 모두 v~_7의 영점이므로 두 변형 모두 해당된다 (아래 4절 수치 확인).

## 3. 영안정성과 L(alpha)
- sigma=1: eig(B) = {1, 약 3e-3 이하 5개}, 1은 단순. beta^6 = 0 (1e-18), 즉 beta 멱영 (정리 3.1).
- 무작위 sigma 열 (60열, 12스텝 곱): (s-1)개 B 곱은 rank 1 (제2 특이값 비율 최대 6e-9 이하), 길이 6의 beta 곱은 0 (1e-15 이하). 정리 3.1과 보조정리 3.2 확인.
- 여유 (곱의 최대 성분, 안정성 상수 척도): sigma in [0.5,1.10]: 6b 138, 6c 996. sigma in [0.5,1.5]: 6b 709, 6c 6608. 구조상 모든 sigma에서 rank-1이지만 상수는 sigma와 함께 증가하며 6c가 더 크다 (이 수치는 상수 크기의 증거이지 임계 sigma가 아니다).
- A(alpha) 각도 (stability matrix (I-gamma z)^-1 (B+z beta), 부채꼴 스캔 0.02도 간격): 6b 57.54도 (인쇄 57.5), 6c 87.96도 (인쇄 87.9). 재현 = 예 (0.1도 이내). M(inf) = -beta/gamma는 멱영으로 rho 0 이므로 L(alpha).

## 4. 전역 차수 실험 (합성 프로토타입, qualification 아님)
구현: 단계식 (3)/(7), 스텝당 LU 1회 + 6개 solve. E1 = 정확한 Y_0, E2 = Y_0에 h0^p 오프셋 (p=3,4,5). 해석: 이 방법은 직전 구간 스테이지 한 벌 Y_0만 필요하므로 "처음 s-1 스텝"이 아니라 Y_0만 정확/오프셋으로 주었다. 정확한 Y_0는 t0 + h0 c_i (c_1 = -1이므로 t0 이전)에서 필요하므로 참조해를 t=-1부터 계산했다.
- PR lambda=-1 (mpmath 50자리, N=32,64,128): 균일 보폭 정확 시작 관측 차수 6b 5.84, 5.92 (6차에 접근), 6c 5.69, 5.86. 무작위 sigma<=1.10: 6b 6.46, 5.41; 6c 6.55, 5.34 (잡음). sigma<=1.50: 6b 4.1, 5.0; 6c 5.8, 4.1 (정보용).
- Fisher MOL N=20, DOP853 rtol 1e-13 참조 (double, N=16..128 적합, 잔차 log10 0.03-0.2): 정확 시작 6b 균일 5.89, 무작위 6.00; 6c 5.90, 5.89. 정확 J와 고정 J(t0,y0) 모두 동일한 차수.
- 오프셋 시작 (시작 요건 확인): PR lambda=-1 (mp) p=3 -> 3.00-3.03, p=5 -> 4.9-5.03 (p=4 -> 약 4.0). Fisher: p=3 -> 2.7-3.2, p=5 -> 4.8-5.2. 즉 전역 오차는 min(시작 오차 차수, 6)이며 정리 3.3의 O(h^{s-1}) 시작 요건과 정합. 시작 오차는 v^T X_0 항으로 감쇠하지 않고 남는다.
- W-허용 범위 (T = c J): c=1.0, 1.2는 수렴 (Fisher 차수 5.6-5.9; LIN3는 아래 참고). c=0.8과 0.6은 Fisher/LIN3에서 발산 (6c Fisher c=0.8, 6b/6c c=0.6 모두 inf). 0.8-1.0 사이는 NOT_RUN. 따라서 T는 J를 과소추정하면 안정성이 깨진다. 과대추정(1.2)은 안전했다.
- 결론 불가 (NOT_RUN으로 간주): PR lambda=-1000 (진폭 0으로 수정, mp)은 N>=64에서 오차 4e-15 이하로 부동 소수점 바닥에 걸려 차수 확정 불가 (기울기 3.8-7.3 흩어짐). LIN3 stiff (lambda -1,-50,-1000, double)는 t0 이전 스테이지의 e^{1000h} 시작값 때문에 반올림이 지배, 적합 차수 무의미 (30-46) -> 결론 불가.

## 5. 인수 점검 (스텝당 작업)
카운터 (N=128, 127 스텝, Fisher): LU 127회 = 스텝당 1회 (I - gamma h T 하나를 6개 스테이지가 공유), solve 762 = 스텝당 6, f 평가 768 = 스텝당 6 (+ 초기 6), 자코비안 평가 127 (정확 J) 또는 총 1회 (고정 J). 스텝당 스테이지 6개.

UNRESOLVED:
1. V 색인 규약 (인쇄본 모호; 일관성으로 V_ij = c_i^(j-1) 채택).
2. 오차 추정기 계수: 논문은 산문으로만 기술 (Y_{m-1,2..s}에 대한 s-2차 다항식 예측자와 Y_ms 비교). 계수 표는 없어서 재구성하지 않았다 (NOT_RUN).
3. 시작: Y_0는 t0 이전 점 (c_1 = -1)을 요구하며 논문은 RODAS 언급 외 시작 절차를 주지 않는다. 실제 IVP 구현 설계가 필요하다.
4. 출력 스테이지는 Y_m^s (c_s = 1)로 가정.
5. E1의 "처음 s-1 스텝" 해석 (위 4절). PR lambda=-1000와 LIN3 전역 차수는 결론 불가.

## 7. 권고 (소유자용, 권고일 뿐)
6b 권고. 이유: (a) 인쇄 각도 57.5도이므로 PLATE류 고경직 문제에는 부족하다는 논문 지적이 있으나, 두 변형 모두 L-안정이고 인수 점검과 차수는 동일하다. (b) 6c의 보폭 변화 안정성 상수가 약 7배 크다 (sigma<=1.1: 996 vs 138; sigma<=1.5: 6608 vs 709) 그리고 W 허용에서 6c Fisher c=0.8 발산이 6b보다 먼저 나타났다. (c) 논문 4절도 "gamma가 작은 방법이 약간 더 정확"하다고 서술. 단, 강한 경직 (각도 요건 71도 이상)이 목표라면 6c가 필요하다. 어느 쪽이든 시작값 절차(UNRESOLVED 3)가 구현 전에 먼저 해결되어야 한다.
