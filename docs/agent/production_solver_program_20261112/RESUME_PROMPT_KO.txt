PPSW1 qualification
논문/표에서 계수를 독립 재구성한다. 구현에서 추출한 계수로 구현을 검증하지 않는다. step ratio sigma=h/h_prev와 approximate-J factor theta(T=theta*J)는 별개 축이다. sigma는0.5..1.1 및 작은 final-clipping 비율, theta는 독립 oracle에서0.8..1.1 및 비가환 perturbation을 검사한다. stiff/nonnormal Prothero–Robinson, LIN3, startup h0, estimator cancellation, rejection/clipping, endpoint/events/mass refusal를 실행한다. 새 근거 없이 tolerance/controller/constants를 조정하지 않는다.

변경 계약
작업 전 정확한 파일 allowlist·동작·독립 기대값·테스트·보호 파일을 기록한다. 현재 요청 범위의 수정에 반복 승인을 요구하지 않는다. 경계 결함은 RED 재현 후 최소 수정/GREEN으로 닫는다. method 변환은 별도 method_id/식/조건을 갖는다. 새 경쟁 API 대신 기존 Problem/Options/ProductionConfig/Session/Solution/capabilities를 우선 확장한다.

수치·권한 계약
- Jacobian-free, derivative-free, matrix-free, Newton-free를 따로 판정한다. JVP/FD/AD, dense matrix, startup/fallback을 포함한다. model-supplied L과 derivative 추정을 구별한다.
- 각 stage 원 방정식 residual을 검사한다. projected/보조계 residual만으로 수렴을 선언하지 않는다.
- session 소유권+generation+소비/폐기 상태를 확인한다. 실패/거절 work는 남기고 state/history/controller는 원자적으로 유지한다.
- fallback은 원래 허용 capability만 사용한다. 불가능하면 typed failure와 accepted prefix를 반환한다.
- callback Sync와 순서 독립 의미론은 별개다. 병렬 모드에는 pure/thread-safe 계약을 명시하고 실제 실행한 모든 작업을 계수한다.
- macro-step causality, 내부 quadrature causality, 공간/ensemble parallelism을 구별한다.
- 같은 rtol/step수가 아니라 같은 달성 global output error에서 비교한다. 참조 불확실성·출력 격자·startup·setup·fallback·실패·RSS·CPU/wall time을 포함한다. holdout으로 tuning하지 않는다.
- Layout3(q,mu,phi)는 Cartesian3D가 아니다. H-weighted geometry norm, 보존량, 경계, 공간/시간 오차를 별도로 검증한다.
