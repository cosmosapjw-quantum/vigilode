SCIENTIFIC PREMISE
The protected RODAS5P method is an eight-stage one-step Rosenbrock-W method with a strict lower-triangular stage dependency graph. The locked transformed tableau has all 28 possible strict-lower couplings nonzero and causal depth eight. A shared W matrix/factorization does not remove the dependency of each stage RHS on earlier stages.
For a strictly lower-triangular 8x8 stage matrix N, N^8=0 and:
(I - lambda N)^(-1) = sum_{k=0}^7 lambda^k N^k
             = (I+lambda N)(I+lambda^2 N^2)(I+lambda^4 N^4).
This is an exact finite algebraic identity. It is NOT a runtime speedup theorem: operator powers may densify, composing black-box actions has cost, and nonlinear remainder/roundoff/certification still matter.

CRITICAL SEMANTIC DISTINCTIONS
- JVP is a derivative action; it is not derivative-free.
- Matrix-free means no explicit matrix assembly; it does not mean no JVP, preconditioner or linear solve.
- Finite-difference JVP is approximate differentiation.
- Newton-free does not mean solve-free, derivative-free or generically convergent.
- Peer-W is a distinct two-step/general-linear method, not a reordering of RODAS5P.
- Stage reuse is not proof of stage independence.
- An affine error-prefix scan parallelizes a supplied recurrence, not an adaptive nonlinear IVP trajectory.
- A source-specific sphere or Gray-Scott client is not a general sphere/3D solver.
- A linearized output correction is not a rigorous nonlinear LTE certificate unless nonlinear remainder is bounded.
