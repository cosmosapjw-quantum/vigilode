# Workflow

## 빠른 연구 세션

`prompts/quick/ultralight.md` → 필요한 state 갱신 → 종료.

## 중요한 연구 cycle

1. Research contract
2. Evidence acquisition
3. Claim–source audit
4. Hypothesis space
5. Independent adversarial review
6. Physics/math validation
7. Verification design
8. External decision gate
9. Survivor-only formalization
10. Closeout

## Reopen policy

외부 gate가 completion bar 미충족을 발견하면 부족한 phase만 reopen한다. 전체 cycle을 무조건 처음부터 반복하지 않는다.
