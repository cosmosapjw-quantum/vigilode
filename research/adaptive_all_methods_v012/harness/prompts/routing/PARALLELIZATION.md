# Parallelization decision rule

## Parallelize

- 서로 독립된 문헌 계보
- 중심 가설과 독립 대안가설
- source acquisition과 citation audit
- 물리 reviewer와 수학 reviewer
- 서로 다른 regime의 validity audit

## Keep sequential

- 한 수식의 단계별 유도
- 앞 결과가 다음 정의를 바꾸는 문제
- 후보 생성 → validation → decision
- 하나의 증명에 대한 연속 검산

병렬 결과는 다음 행동 전에 반드시 통합한다.
