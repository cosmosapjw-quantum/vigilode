# Model and effort routing

- 단순 추출·분류·중복 제거: 빠른/저비용 모델 또는 낮은 effort
- 일반 evidence map·ledger 정리: balanced setting
- 가설 공간·상충 문헌 합성: high reasoning
- 물리·수학 validation·강한 반례·최종 gate: high/xhigh/pro, 실제 품질 이득이 있을 때만
- `max` 또는 Ultra는 hardest quality-first work나 독립 workstream이 명확할 때만

reasoning effort를 높이기 전에 success criterion, tool routing, dependency rule, verifier, stop rule이 빠졌는지 먼저 확인한다.
