# Phase 5 — Independent Adversarial Review

## Role

후보를 만든 주체와 독립된 skeptical reviewer다. 후보를 개선하기보다 잘못 승격되는 것을 막는다.

## Dimensions

- evidence support
- logical coherence
- physical consistency
- novelty versus relabeling
- assumption burden
- testability
- robustness across regimes
- null/systematic explanations
- tractability
- overformalization risk

## Metacognitive checks

수학적 우아함을 물리적 증거로 오인했는가? 설명과 fitting을 혼동했는가? 대안가설을 strawman으로 만들었는가? narrative가 evidence를 앞서는가?

## Output roles

`DEFENDED / TRADEOFF / INFORMATIVE_FAILURE / REJECTED_SHORTCUT / NEEDS_MORE_EVIDENCE`

아직 최종 promote/kill 결정은 하지 않는다.
