# Phase 10 — PROMOTE/HOLD Closeout

## PROMOTE — common adaptive research layer

- shared bounded I/PI controller and diagnostics;
- native RODAS5P embedded endpoint adaptivity for Sequential/SABR/Homotopy families;
- exact nonuniform BDF2 kernel;
- BDF1/2 step-doubling adaptive reference lane;
- Radau IIA1/3 step-doubling adaptive reference lane;
- Homotopy adaptive transaction with protected fallback;
- deterministic ten-candidate adaptive global-error screen;
- local Rayon case-level execution with exact scientific identity;
- requested-output-only storage and full work accounting.

## HOLD — production or ranking claims

- step doubling as an efficient BDF/Radau production controller;
- BDF orders 3–5 or variable-order selection;
- native RADAU5 embedded estimator/predictive controller;
- adaptive Homotopy or SABR speedup;
- wall-time ranking from this corpus;
- verified dense output;
- singular-mass/index-1 DAE, sparse, MPI or GPU claims;
- deferred SDC, Peer/W, ROK, BOROK and exponential/Leja implementations.

## Final scientific statement

Every currently executable complete-integrator family now has an adaptive requested-output API under a common transaction and reporting contract. The result is sufficient to start production-family estimator/controller research, but not to declare a fastest method.

## Successor work

Next work should begin with a lane that removes output-clipping bias and replaces reference estimators with native production estimators:

1. verified dense-output or endpoint-only controller stress authority;
2. variable-order/variable-step BDF1–5 with Nordsieck history and stability-limit detection;
3. native Radau IIA3 estimator and predictive/Gustafsson-style controller;
4. adaptive SDC step/sweep controller;
5. Peer/W step-ratio controller;
6. ROK/BOROK joint step/subspace controller;
7. exponential/Leja joint step/degree controller;
8. joint comparison with RODAS5P, SABR and Homotopy under matched global error.
