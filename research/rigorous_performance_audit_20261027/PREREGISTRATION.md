# Bounded audit and performance experiments

Baseline: `3064d453091af1dec7f99f0c8afabd98b447ea34`. This new task follows the user request for an adversarial audit, theory, implementation and real performance improvement. Existing V6/V8 physical ledgers and old profiling runs are preserved.

Separate lanes: adapter comparison work; exact per-mode allocation cost; mathematical contraction and residual-to-error prototype. Shared numerical defaults, tolerances and existing acceptance conditions remain the reference. Any new selection optimization is opt-in.

Correctness acceptance: targeted new/affected tests with raw exits; same-output baseline comparison where arithmetic is preserved; analytic-reference state error for changed algorithms. Cost acceptance: allocation and deterministic work first; serial alternating timing batches on one host, no concurrent compilation. A wall-time speedup is reported only for the actual qualifying cohort and raw measurements, including regressions. Pre-existing measurements are provenance, not new experimental outcomes.

Current benchmarks may be extended only to test a concrete new risk or measure the selected change. No remote HPC campaign and no replay of closed physical tests. The research prototype is not silently enabled as a production solver.
