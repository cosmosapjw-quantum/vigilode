# 특이 연산자 재시도 시험의 fixture 교정 기록

이 기록은 `adaptive_trajectory::singular_trial_operator_retries_a_smaller_physical_step`의 두 사전 조건 실패와 후속 교정을 구분한다. 두 실패는 적분기를 호출하기 전에 발생했으며, 수치 솔버의 재시도 동작에 관한 성공 또는 실패 증거로 해석하지 않는다. 원래 실행 로그와 종료 상태는 그대로 보존한다.

| 관찰 | 실행 전 조건 | 결과와 해석 |
|---|---|---|
| 첫 실행 | `h = 1`, `rate = gamma.recip()`, `gamma * rate == 1` | 곱이 `0.9999999999999999`여서 assertion 실패. 정확히 특이한 연산자를 구성하지 못했다. |
| 두 번째 실행 | 위 reciprocal과 인접한 두 binary64 rate 중 곱이 정확히 1인 값 탐색 | 해당 세 값 중 조건을 만족하는 값이 없어 fixture 생성이 실패했다. 솔버는 여전히 실행되지 않았다. |
| 후속 교정 | `h0 = 0.1`, `rate = (h0 * gamma).recip()` | `ShiftedOperator`의 실제 평가 순서인 `(h0 * gamma) * rate == 1.0`을 그대로 검증한다. 최종 실행 결과는 별도 영수증으로 판정한다. |

교정 후 시험은 첫 번째 실제 trial의 `h == h0`도 확인한다. 시작 시간이 0이고 최종 시간이 `h0`이므로 시험에 사용되는 물리적 간격과 assertion의 간격을 일치시킨다. 이후 검사하는 요구사항은 변경하지 않았다. 첫 시도의 선형해법 실패가 재시도 가능한 실패로 기록되어야 하고, 상태를 전진시키지 않은 채 더 작은 간격으로 재시도해야 하며, 최종 해는 독립적인 지수함수 해와 주어진 상대오차 기준을 만족해야 한다. 실제 callback이 `LinearSolve` 오류를 반환하는 별도 시험은 재시도를 허용하지 않는다.

이 교정은 실패한 assertion의 허용오차를 완화하지 않는다. 검증하려던 특이 연산자가 실제 이진 부동소수점 연산에서 구성되도록 입력만 수정한다. 이 문서 자체는 최종 시험 통과를 주장하지 않는다.
