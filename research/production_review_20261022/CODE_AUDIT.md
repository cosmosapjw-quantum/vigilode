# 최신 코드 구조와 수치 계약에 대한 검토

감사 기준은 `555e71e03fe31e6c9b21961c8e2d263b1794eb6f`이며, 직전 연구 결과 `5fd6e459a3f67cee90e002821b9b4b740c47475b` 이후의 변경 중 시간 적분기의 확장 인터페이스와 복사 수송 응용을 집중 검토하였다. 이미 게시된 수치 실험을 다시 실행하지 않고, 변경된 실패 처리 및 연산량 계수에 대한 반례를 추가한다. 따라서 이 문서는 전체 저장소의 모든 경로를 재시험했다는 주장이 아니다.

## 1. 실제 구현된 방법

### 시간 적분과 선형 대수

`crates/rodas5p-integrators/src/rodas5p_fast.rs`는 8단계 RODAS5P의 변환된 표현을 사용한다. 각 시도에서 \(W=(h\gamma)^{-1}I-J\)를 준비하고,

\[
W u_i=f\!\left(t+c_i h,y+\sum_{j<i}a_{ij}u_j\right)
 +h^{-1}\sum_{j<i}C_{ij}u_j+\gamma_i h f_t
\]

를 푼다. 새 상태는 \(y^+=y+\sum b_i u_i\)이다. 마지막 단계 벡터로부터 \(\sqrt{n^{-1}\sum_i (u_{8,i}/[a_i+r\max(|y_i|,|y_i^+|)])^2}\)를 계산하여 국소 오차를 제어한다. 비자율 문제의 \(f_t\)는 사용자 콜백으로 버퍼에 직접 쓸 수 있고, 콜백이 없으면 유한 차분 대체 경로가 메모리를 할당한다. 단계 선형계 해의 유한성은 검사하지만 임의의 사용자 선형 솔버가 반환한 유한한 값의 정확성은 해당 솔버의 계약이다.

새 `StageLinearSystem` 인터페이스는 `dimension`, `linearize`, `factor`, `solve_in_place`를 제공한다. 문제를 다시 선형화해야 하는 시점, 단계의 순서, 거절 및 재시도, 출력의 저장은 시간 적분기가 관리한다. 따라서 직전 보고서의 ‘구조화 선형 솔버를 실제 단계에 연결해야 한다’는 작업은 현재 브랜치에서 구현되었다. 일반 밀행렬, 대역행렬 및 사용자 구조화 솔버가 같은 단계식과 제어기를 사용한다. `jacobian_builds`와 `linear_solves`의 계수는 적분기가 소유하며, 사용자 솔버는 자신의 분해·반복·전처리 연산을 추가한다.

### 축대칭 복사 수송

`examples/lrs_photon_fv_support/mod.rs`의 상태는

\[
[L_{\rm lo},\;(N_{i0},\ldots,N_{i,N_\mu-1},A_i)_{i=0}^{N_q-1},\;L_{\rm hi}],
\qquad n=2+N_q(N_\mu+1)
\]

이다. \(N_{ij}\)는 셀에 적분된 광자 수, \(A_i\)는 흡수량, 양 끝의 \(L\)은 경계 유출량이다. 모든 성분의 합이 반이산 선형 불변량이다. 에너지와 각도 수송은 1차 상류 유한체적법이며, 물리 에너지 또는 공변 로그 에너지 좌표를 선택한다. Thomson 산란의 각도 이득은 각 에너지 군에서 두 모멘트로 계산한다. 이 랭크는 **에너지 군별 2**이며 전체 문제에 대해 고정 랭크 2라는 뜻은 아니다.

`block_solver.rs`는 각도 방향의 삼중대각 행렬을 Thomas 소거로 풀고, 2×2 모멘트 보정을 적용한다. 모든 각도 열에서 에너지 이동 방향이 같으면 에너지 군을 상류 순서로 방문하여 전체 선형계를 직접 푼다. 보존식을 사용한 모멘트 방정식은 산란률이 큰 경우 \(1-\Gamma\sum z_1\)의 차감 소실을 줄인다. 현재 코드의 사칙연산 계수에 따르면 보존형 분해는 \(N_q(29N_\mu-3)\), 유출 경계를 포함한 직접 해법은 \(N_q(15N_\mu+9)+4\)회이다. 이는 계수 구성, 기하 및 물리 콜백 계산을 제외한 커널 계수이며, \(O(N_qN_\mu)\) 복잡도를 직접 설명한다.

에너지 이동 방향이 각도에 따라 달라지면 직접 모드는 명시적으로 거절한다. 이때 구조화 행렬 작용과 대칭 군 순회 전처리를 사용하는 재시작 우측 GMRES를 선택할 수 있다. 군별 광자 수의 거친 보정을 추가한 2단계 전처리도 구현되었다. 이 경로의 총비용은 행렬 차원뿐 아니라 실제 반복 횟수에 의존한다. 코드와 기존 자료는 임의의 혼합 이동·강성에서 3–5회 수렴을 보장하지 않는다.

### 물질 결합, 재격자화, 전구면 확장

`border.rs`에는 전단, 이온화 변수와 물질 응력으로 이루어진 3성분 경계를 작은 Schur 보완행렬로 처리하는 선형 솔버가 구현되어 있다. `chem.rs`는 광자 상태 뒤에 12개의 물질·에너지 성분을 붙이며, H/He 광이온화와 Case-A 재결합, 열에너지, 서명 있는 응력 및 전단을 계산한다. 이 화학 모형은 해석적 밀집 Jacobian과 밀집 시간 적분 경로를 사용한다. 표의 온도 범위를 벗어난 콜백은 지정된 오류를 반환하며, 임의 외삽으로 숨기지 않는다.

`remesh.rs`는 수락된 상태에서 적분을 중지하고, 보존적 중첩 재분배를 제안한 뒤 새 격자·모형·선형 솔버의 준비가 끝나면 상태를 공개한다. 같은 형상에서는 기존 구조화 솔버를 새 격자에 다시 연결하고, 형상이 바뀌면 새 솔버를 만든다. 실패한 제안은 기존 상태와 격자를 보존한다. 다음 시간 간격의 제안을 전달하므로 항상 최초의 작은 간격으로 돌아가지는 않는다. 그러나 각 구간의 시간 적분 작업 공간과 출력 버퍼는 다시 구성되고 형상 변경 시 선형 솔버도 재구성된다. **전체 재격자화 실행이 무할당이라는 주장은 성립하지 않는다.** 무할당 실험은 해당 콜백·커널 또는 고정 차원 구간 내의 정상 경로에 한정해야 한다.

`examples/sphere_photon_fv_support/mod.rs`에는 비기울어진 삼축 Bianchi-I 배경에서 \((q,\mu,\phi)\) 유한체적 수송과 각 군별 랭크 6의 비편광 Thomson 연산자가 구현되어 있다. 상태 크기는 \(2+N_q(N_\mu N_\phi+1)\)이다. 현재 시간 적분은 밀집/대역 선형 대수를 사용한다. 전구면에 맞는 구조화 선형 솔버, 편광, 기울기·광행차, 반동 및 전구면 재격자화는 이 구현의 완성된 기능이 아니다.

## 2. 발견한 결함과 최소 수정

### CA-01: 전처리 진단 API의 형상 검사 누락

`BlockStageSolver::precondition`은 분해 상태만 검사한 뒤 내부 인덱스 루프를 호출한다. 길이가 짧으면 panic이 발생하며, 큰 벡터의 여분 성분도 거절하지 않는다. 수정은 출력에 쓰기 전에 입력과 출력 길이를 현재 차원과 비교하는 것이다. 1단계 및 2단계 전처리에 대해 짧은/긴 입력과 출력을 시험하고, 거절 시 출력이 보존되는지 확인한다. 정상 시간 적분 경로가 내부적으로 구성한 동일 길이 버퍼의 기존 수치 결과를 반박하는 결함은 아니다.

### CA-02: 거절된 분해 갱신 후 이전 분해가 노출됨

`factor_with`는 시간 간격에 따른 계수의 유한성과 양성을 검사한 후에야 기존 `Factored` 상태를 해제한다. 따라서 NaN, 무한대, 0 또는 음수로 재분해를 요청하여 실패하면 이전 분해를 사용한 해법이 계속 허용된다. 계수 검증 전에 분해 상태를 해제하고 선형화 자체는 보존하면, 실패한 갱신 이후 모든 분해 소비자가 거절하며 올바른 계수로 다시 시도할 수 있다. 이 수정은 호출자의 실패 처리 실수를 조기에 드러낸다.

### CA-03: Krylov 단계의 선형계 계수 중복

단계 적분기는 사용자 솔버를 호출하기 전에 `linear_solves`를 증가시킨다. 그런데 구조화 Krylov 솔버가 호출하는 `solve_gmres_into` 역시 성공 시 같은 계수를 증가시킨다. 결과적으로 성공한 Krylov 단계가 두 번 집계된다. 내부 반복·행렬 작용·전처리 연산은 모두 누적하되, 내부 호출이 늘린 적분기 소유의 단계 계수는 제외해야 한다. 이 수정은 수치 경로가 아니라 연산량 보고의 의미를 바로잡는다. 기존 Krylov 실행의 해당 열은 원자료를 보존한 채 이 중복 가능성을 명시해야 한다.

세 결함은 모두 최소 수정으로 교정하였다. 수정 전 새 회귀 시험 3개가 각각 계수 14 대 13의 불일치, 범위 밖 인덱스 panic, 거절된 갱신 뒤의 이전 분해 재사용을 검출하였다. 수정 후 새 시험 3개와 기존 구조화 솔버 시험 8개가 모두 통과하였다. 기존 시험은 밀집 LU 대비 잔차와 후방 오차, 혼합 이동 GMRES 수렴, 연산량 공식, 성공 경로의 무할당, 단계 수에 독립적인 할당 횟수, 시간 적분의 결정성과 대역 경로 일치, 작은 경계의 Schur 해법을 포함한다.

현재 수정 및 실행 상태의 최종 기록은 `CODE_AUDIT.json`과 `evidence/code_audit/`를 따른다. 첫 빌드는 의존성 컴파일 중 실행 환경의 메모리 압력으로 중단되었으며, 이는 수치 시험 실패와 구별한다.

## 3. 실사용 판단과 남은 개발

현재 저장소는 지정된 고정 격자·물리 모형에 대해 유의미한 정확도와 비용 자료를 갖춘 수송 솔버를 포함한다. 특히 단방향 에너지 이동의 구조화 해법에는 실제 선형 복잡도의 구현상 근거가 있다. 이 결론을 임의 비선형 문제, 전구면 편광 수송 또는 임의의 적응 격자에 확대할 수는 없다.

공개된 기준해와의 일치는 같은 반이산 방정식의 **시간 적분 오차**를 검증한다. 연속 분포함수에 대한 정확도는 에너지·각도 격자 오차, 반응률 표 및 모형 근사, 재분배 오차를 추가로 포함한다. 큰 광자 수의 보존과 작은 물리 관측량의 정확도도 구분해야 한다. 고차 Rosenbrock 단계 자체가 모든 양의 초기 상태에서 양성을 보장하지 않으며, 재격자화 후 큰 시간 간격을 재사용하는 것만으로 전체 5차 정확도가 따라오지 않는다.

다음 개발은 다음 순서가 적절하다.

1. 이번 실패 처리 및 계수 수정을 반영하고, 검증된 응용 모듈을 예제의 상대 경로 포함에서 독립적인 버전 관리 가능한 라이브러리 인터페이스로 이전한다. 실행 가능한 예제는 그 라이브러리를 호출하도록 남긴다.
2. 광자·물질 상태의 허용 영역과 수락된 단계의 양성 검사를 구분하여 정의한다. 작은 음수의 허용량, 재시도 조건, 물리적으로 보존해야 하는 합과 clipping을 하지 않을 조건을 명시한다.
3. 시간 허용오차와 독립적인 에너지·각도 격자 세분화 실험으로 관측량의 공간 오차를 측정한다. 같은 시간 오차 예산을 만족한 격자에서 비교하고, 공간 오차가 지배하면 시간 적분을 더 엄격하게 하는 비용을 피한다.
4. 재분배의 총수 보존 검사와 근사 오차를 분리한다. 관측량별 또는 가중 L1 재분배 오차를 누적하여 허용 예산을 넘는 병합을 거절하고, 구간 간 작업 공간 재사용은 별도의 성능 최적화로 구현한다.
5. H/He 화학의 큰 밀집 Jacobian을 광자 군 블록과 12변수 경계로 나누어 구조화 Schur 해법을 구현한다. 실제 Jacobian의 비국소 결합과 조건수를 먼저 확인하고, 기존 밀집 경로와 잔차·관측량을 비교한다.
6. 전구면 산란의 군별 랭크 6을 활용하되 각도 수송의 2차원 희소 구조를 보존하는 전처리를 구성한다. 각도 격자가 커질수록 기존 대역폭이 증가하므로 단순 대역 LU의 선형 복잡도를 가정하지 않는다.
7. 성능 비교는 동등한 출력·관측량 오차와 같은 계측 구간에서 실시한다. 현재 NCP 자료의 서로 다른 언어/호출 경계와 반복 실행 분포를 그대로 공개하고, 통계적 우월성과 하드웨어 내부 병렬 확장은 새 실험으로 평가한다.

## 4. 새로운 저랭크 모듈에 대한 보완 검토

동일한 검토 회차에서 `crates/rodas5p-core/src/low_rank_bordered.rs`의 증강 행렬 부호와 전치, 활성 크기별 배열 배치, 랭크 0 및 물질 경계 0의 처리, 용량 오버플로 검사, 실패 시 출력 보존, mutex를 통한 안전한 작업 공간 접근을 읽었다. 현재 읽은 범위에서 기능상의 반례는 찾지 못하였다. 다만 오류 문자열은 할당되므로 ‘실패 시에도 무할당’이라는 문장은 ‘성공한 적용은 무할당이고 실패 시 출력은 보존된다’로 교정하도록 구현자에게 전달하였다. 독립 잔차 및 오버플로 회귀 시험의 실제 결과는 해당 모듈의 실행 기록을 따른다.
