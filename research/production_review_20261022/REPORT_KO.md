# VigilODE 최신 코드·연구·실행 결과 통합 감사

2026년 10월 22일 기준 코드 `555e71e03fe31e6c9b21961c8e2d263b1794eb6f`와 별도 연구·실행 브랜치를 검토하였다. **범용 production 판정은 HOLD**이다. 현재 코드는 공개 API, 8단계 RODAS5P, 구조화 광자 수송, 물질 결합, 수락 단계 재격자화 및 전구면 수송까지 상당한 기능을 포함한다. 지정된 고정 격자 문제에서는 응용 정확도 예산을 만족하는 결과와 구조적 비용 감소의 근거가 있다. 다만 이 결과를 모든 상태 성분의 전역 정확도, 임의의 비선형 문제, 임의 재격자화 또는 보편적 속도 우위로 확대할 근거는 부족하다.

이번 작업은 기존 연구를 처음부터 반복하는 대신 실제 변경과 누락을 대상으로 수행했다. 별도 브랜치의 **2,532개 파일을 원본과 같은 bytes로 통합**했고, 코드 결함 세 건과 평가기 결함 한 건을 수정했다. 원래 상태 차원을 유지하는 저랭크 경계 역연산자를 새로 구현했으며, 관련 **Rust 시험 19개와 Python 시험 3개가 통과**했다. 별도 C99 오차 norm은 현재 호스트에서 유한 입력 10개와 오류 입력 5개를 검증했다. **새 NCP 캠페인은 실행하지 않았다.** 기존 NCP 시간은 원래 수치 소스의 결과로 유지한다.

## 2. 어떤 코드와 연구를 통합했는가

`production/wave3-integration`과 `production/vigilode-plan-20261021`의 tip은 모두 기준 코드의 조상이다. 조사한 `origin/production/*` 25개 ref에는 기준 코드에 없는 incoming commit이 없었다. 따라서 이미 포함된 독립 개발을 다시 cherry-pick하여 덮어쓸 필요가 없었다. 공개 facade, 사건 검출, typed status, dense/banded 및 matrix-free 경로의 실제 기능과 제한을 현재 소스에서 확인했다. 역사 문서의 오래된 결함 중 이미 수정된 dense-output 오류 수용과 통계 record 소유권 문제는 현재 blocker로 재등록하지 않았다.

기준 checkout에 없던 두 별도 결과는 실제로 가져왔다. `research/orchestration-sandbox-20261022-vigilode`에서는 affine 30→33 오차 norm의 C99 코드·유도·실패 및 수정 기록 16개 파일을, `results/ncp-followup-fvm-5fd6e45`에서는 과거 NCP followup의 원자료·분석·재현 자료 2,516개 파일을 수용했다. 총 2,532개 파일의 Git blob, SHA256 및 길이를 원본 commit에 연결하였고 byte 불일치는 없었다. 기존 소스나 실행 일자를 새 코드의 결과처럼 바꾸지 않았다.

이 통합은 과거 근거를 보존하는 작업이다. 새 저랭크 구현의 검증, 최신 물리 모형의 검증 및 과거 열방정식 최적화의 검증은 서로 다른 범위를 갖는다. 같은 저장소에 들어왔다는 사실만으로 한쪽의 성능·정확도 결과가 다른 쪽으로 전이되지는 않는다.

## 3. 최신 코드에서 확인한 변화와 수정

시간 적분기의 `StageLinearSystem`은 사용자 소유 선형화를 실제 RODAS5P 단계에 연결한다. `linearize`, `factor`, `solve_in_place`가 단계 순서와 적응 제어기에 결합되므로, 이전 보고서의 ‘구조화 솔버 연결이 아직 없다’는 판단은 현재 소스에 적용되지 않는다. 비자율 우변의 시간 편미분을 직접 버퍼에 쓰는 경로와 수락 단계의 중단·재시작 인터페이스도 추가되었다.

축대칭 광자 수송은 에너지 군별 삼중대각 각도 블록과 랭크 2 Thomson 보정을 사용한다. 모든 각도 열의 에너지 이동 방향이 같으면 상류 순서의 직접 해법이 작동한다. 해당 커널의 분해는 \(N_q(29N_\mu-3)\), 유출 경계의 한 해법은 \(N_q(15N_\mu+9)+4\) 사칙연산으로 계수된다. 이는 계수 구성과 물리 콜백을 제외한 \(O(N_qN_\mu)\) 비용이다. 혼합 이동에서는 재시작 우측 GMRES와 1단계 또는 2단계 전처리를 사용하며, 반복 횟수는 문제에 의존한다.

새 감사에서는 다음 반례를 재현하고 최소 수정했다.

| 결함 | 관측과 영향 | 수정 및 검사 |
|---|---|---|
| 전처리 진단 API의 형상 검사 누락 | 짧은 입력에서 범위 밖 인덱스 panic; 긴 입력도 명시적으로 거절하지 않음 | 입력·출력 길이를 쓰기 전에 검사하고 두 전처리 모드의 짧은/긴 벡터를 시험 |
| 거절된 분해 갱신 뒤 이전 분해 사용 | NaN 또는 잘못된 shift를 거절해도 기존 factor가 계속 노출됨 | shift 검사 전에 factor 상태를 무효화; 올바른 shift로 재시도 가능 |
| Krylov 단계 계수 중복 | 적분기와 내부 GMRES가 `linear_solves`를 각각 증가시킴 | 적분기 소유 계수만 복원하고 실제 반복·행렬 작용·전처리 작업은 보존 |
| 평가기의 비물리적 기준 밀도 수용 | 음의 밀도에 음의 고갈 가중치가 붙어 같은 음수 궤적이 오차 0으로 평가됨; 초기 밀도 0에서 나눗셈 오류 | 초기 복사 에너지는 유한 양수, 이후 기준 에너지는 유한 비음수임을 확인한 뒤 평가 |

Rust 회귀 시험은 수정 전 세 건 모두 실패했고 수정 후 통과했다. 평가기 시험은 수정 전 실패·예외를 보존했으며 수정 후 세 건이 통과했다. 이 수정은 과거 정상 궤적을 자동으로 무효화하지 않는다. 다만 과거 Krylov 단계 계수는 중복 의미를 명시해야 한다. 최신 원시 궤적이 없는 상태에서 평가기 수정으로 과거 오차를 다시 계산했다고 주장하지 않았다.

수락 단계 재격자화도 실제로 구현되어 있다. 격자와 상태의 제안을 준비하고 새 모형을 구성한 뒤 공개하며, 실패한 제안은 기존 상태를 보존한다. 그러나 구간마다 적분 작업 공간과 출력 버퍼를 다시 만들고 차원 변경 시 구조화 솔버도 재구성한다. 따라서 전체 적응 격자 실행이 무할당이라는 표현은 부정확하다. 다음 간격의 재사용 또한 과거 제어기 상태나 5차 전역 정확도의 자동 보존을 뜻하지 않는다.

## 4. 추가 수학 연구와 저랭크 구현

새 모듈은 원래 행렬

\[
M=\begin{pmatrix}A+UV^T&B\\C&D\end{pmatrix}
\]

을 보조 행렬

\[
Q=\begin{pmatrix}A&B&U\\C&D&0\\-V^T&0&I\end{pmatrix}
\]

로 풀고 보조 변수를 버린다. 마지막 식이 \(z=V^Tu\)이므로 원래 해를 정확히 복원하며, 외부 Krylov 차원은 \(n+m\)으로 유지된다. 내부 Schur 크기는 \(m+r\)이다. 대역폭 \(b\), 물질 경계 크기 \(m\), 랭크 \(r\)가 고정된 문제군에서 setup과 apply가 \(n\)에 선형이라는 계산량 증명을 구현 사양으로 연결했다.

구현은 `crates/rodas5p-core/src/low_rank_bordered.rs`에 있다. 현재 충분조건은 대역 블록 \(A\)의 엄격한 행 대각 우세이며, \(A+UV^T\) 자체의 대각 우세를 요구하지 않는다. 성공한 재분해·적용은 생성 후 힙 할당 없이 동작하고, 실패한 적용은 출력 벡터를 보존한다. 실패한 재분해는 이전 factor를 무효화한다. trait의 기본 적용은 내부 scratch mutex로 직렬화되므로 병렬 적용에는 caller별 작업 공간을 사용해야 한다. **이 모듈은 테스트된 재사용 가능한 core 구성요소이며, ODE 경로에 자동 연결되어 있지 않다. 실제 시간 단축도 아직 측정하지 않았다.**

추가 이론은 보조 잔차에서 원래 잔차로의 전달, 인수분해 재사용의 정량적 반경, 고정 메모리 다항식 반복 및 매개변수 병렬화를 다룬다. \(\|I-MP^{-1}\|_2\le q<1\)이면 정확한 산술의 우측 GMRES 잔차가 \(q^k\)로 제한된다. 독립 매개변수 문제 \(K\)개가 같은 유효 반경 안에 있으면 setup 작업량을 \(KS\)에서 \(S\)로 줄일 수 있다. 이는 시간적으로 인과 의존하는 구간들을 독립 계산해도 된다는 주장이 아니다.

양의 선형 수송에서는 비음수 비대각과 비양수 열합 아래 정확한 전파의 L1 수축을 증명하고, 공간·재분배·선형 풀이 오차를 분리한 누적식을 제시했다. 재분배의 질량 보존과 표현 변화량은 참해 오차의 상계가 아니다. 5차 시간 수렴을 전체 해에 주장하려면 시간 국소 결함 외에 누적 공간·재분배 오차도 같은 차수 이하임을 확인해야 한다.

## 5. 벤치마크에서 말할 수 있는 것

최신 NCP 캠페인의 수치 소스는 `2064366ea39ef35a9eae7966b4b5b2424a46124c`이다. 저장된 최종 기록은 정상 완료 1,144행, 시간 초과 2행, 계획상 미적용 66행을 포함한다. 64 논리 CPU와 약 125 GiB를 보고한 단일 가상 호스트에서 독립 실행을 병행했으며, 한 trajectory의 64코어 확장성을 측정한 실험은 아니다.

주요 22개 VigilODE 문제–방법 조합은 내부 상대 허용오차 \(10^{-8}\)에서 저장된 관측량 예산을 만족했다. 최대 기록 오차는 약 \(1.23\times10^{-8}\)이며, 응용 예산 \(10^{-6}\)에 대한 최소 여유는 약 81배이다. 이 척도는 요청된 출력에서 선택한 관측량에 바닥값과 일부 고갈 가중치를 적용한다. 모든 셀의 상태 오차, 출력 사이의 오차 또는 연속체 공간 오차와 같지 않다.

8,322변수 강성 수송의 예산 충족 기록은 구조화 직접해법 약 0.0741초, 구조화 Krylov 약 1.19초, 일반 대역 해법 약 6.82초이다. 반면 비강성 수송·화학에서는 Julia와 diffsol의 명시적 방법이 더 빠른 사례가 있다. 구현별 timer 범위와 실제 달성 오차가 다르고 단일 호스트의 일곱 확인 블록만 사용하므로, 관측 최솟값–최댓값을 신뢰구간으로 표현하지 않는다. 비교 그림은 VODE/DVODE, diffsol, Julia 계열을 사용하며 Julia가 호출한 CVODE의 원래 구현도 표시한다.

과거 128변수 열방정식의 해석적 stencil은 별도 소스 `5fd6e459…`에서 1,046개 실행의 times/states를 유지하면서 총 RHS 평가를 5,712에서 336으로 줄였다. 이는 해당 Jacobian 조립 특수화의 승격 근거이다. 현재 저랭크 모듈 또는 최신 물리 모형의 신규 성능 자료로 재사용하지 않는다.

중요한 공개 범위 제한이 남아 있다. **최신 두 시도의 전체 상태 궤적과 기준해 원본은 가져온 저장소 묶음에 없다.** 44개 manifest 항목의 해시, 저장된 허용오차 선택과 AB/BA 비율은 검사할 수 있지만 원래 수치 오차 전부를 독립 재계산할 수는 없다. 2,532개 과거 파일의 정확한 통합이 이 최신 누락을 해결한 것은 아니다. 기존 압축 원자료의 SHA256을 확인하고 필요한 궤적·요청·기준해를 공개하는 작업이 우선이다.

Rust 첫 빌드는 의존성 컴파일 중 환경의 메모리 압력으로 중단했다. 이후 작업 수 2와 debug 정보 비활성화 설정으로 검증을 마쳤다. 중단 로그와 exit 130은 수치 실패와 구분하여 보존했다. 이 19개 시험을 저장소 전체 회귀시험의 새 전수 통과로 표현하지 않는다. 기존 캠페인은 원래 identity와 범위로 재사용했다.

## 7. 범위별 판정과 다음 구현 순서

| 대상 | 판정 | 적용 범위 |
|---|---|---|
| 범용 production solver | HOLD | 광범위 사용에 필요한 정확도·재현성·기능 조합 근거가 충분하지 않음 |
| 단방향 강성 광자 수송 | specialized for specific cases only | 검증된 고정 격자·비편광·비기울어진 물리 모형 |
| 해석적 열방정식 stencil | promote | 시험한 periodic heat/advection-diffusion의 opt-in Jacobian 조립 |
| 비강성 문제의 dense 기본 선택 | optimization possible | 명시적 방법 또는 비용 기반 선택을 검토하되 작은 문제의 fallback 유지 |
| 새 일반 저랭크 역연산자 | HOLD | core 검증 완료, 실제 ODE 연결과 비용 측정 필요 |
| affine 30→33 norm | HOLD | 독립 커널 검증 완료, 단계 수락 경로 연결 필요 |
| 전구면 수송 | specialized for specific cases only | 제한된 비편광 삼축 Bianchi-I 구현 |
| solver 계열 제거 | HOLD | 특정 설정의 실패만으로 방법 전체를 prune하지 않음 |

개발 순서는 [NEXT_STEPS.json](NEXT_STEPS.json)의 파일별 구현·의존성·수용 조건을 따른다. 첫째, 새 계산 없이 최신 NCP 압축 원자료를 복구하여 전체 상태와 두 기준해를 공개한다. 둘째, affine 축약의 오차를 \(e^TL^TD^{-2}Le/33\)로 계산하는 client-owned norm을 실제 수락 경로에 연결한다. 30개 대각 scale 조정으로 대체하지 않고, 상관된 H/He/Li 오차에서 원래 33차원 결정과 비교한다.

셋째, 비선형 화학의 광자 블록과 12변수 물질 경계를 분리하여 구조화 stage solver를 연결한다. 에너지별 랭크 2 산란을 큰 전역 랭크로 모으지 않고 국소 블록에 유지하며, 원래 연산자의 단계 잔차를 기존 밀집 경로와 비교한다. 넷째, 출력 시각에 매번 착지하는 비용을 continuous extension 경로와 분리하여 측정한다. 보간 정확도와 사건 누락 정책을 유지한 상태에서 실제 절약을 확인한다.

다섯째, 격자 해상도·시간 허용오차·리매핑 빈도를 독립 변화시키고, 양성 및 종 분율의 허용 영역을 별도로 검사한다. 여섯째, 전구면의 랭크 6 산란과 희소 각도 수송을 활용하는 선형 대수를 개발한다. 이후 동일 정확도·같은 timer 범위에서 재현 가능한 비용 비교를 수행한다. 다항식 및 homotopy 연구는 검증된 노름 반경과 독립 매개변수 문제에서 시작한다. 이미 유효한 증명을 반복하기보다 실제 조건을 검사하고 원래 잔차와 총비용으로 다음 구현을 판단한다.

로컬 Codex에는 [복사 가능한 인계 프롬프트](CODEX_HANDOFF_KO.md)를 제공한다. 기존 checkout을 보존한 detached worktree에서 source identity를 기록하고 변경 관련 시험만 실행하도록 구성했다. 범용 production 판정은 단일 커널 시험의 성공으로 바꾸지 않으며, 다음 개발의 완료 여부는 구현된 경로와 그 경로의 실제 실행 결과로 결정한다.

## 8. 게시 직전 확인된 과거 출처 가용성 문제

이번 리뷰 폴더에 대한 출처 검사는 53개 인용·32개 식별자에서 통과했다. 그러나 저장소 전체 검사에서는 4,999개 인용·516개 식별자 중 **과거 식별자 14개를 해결하지 못하여 실패**했다. 해당 53개 인용이 있는 파일 27개는 기준 코드의 파일과 byte가 같으며, 이번 코드 수정에서 발생한 수치 실패는 아니다. 원래 객체가 없는 경우 commit/tree/blob의 종류도 단정할 수 없다.

[PROVENANCE_CHECK.json](PROVENANCE_CHECK.json)과 [원본 로그](evidence/PROVENANCE_CHECK.log)에 결과를 보존했다. [NEXT_STEPS.json](NEXT_STEPS.json)의 N12는 원래 checkout/archive에서 객체를 복구하고 원격 접근 가능성을 회복하거나, 복구 불가한 인용의 비지원 범위를 정정 기록으로 남기도록 요구한다. 기존 문서나 검사 예외 목록을 고쳐 이 실패를 숨기지 않았다. 전체 저장소의 출처 검사는 현재 PASS가 아니다.
