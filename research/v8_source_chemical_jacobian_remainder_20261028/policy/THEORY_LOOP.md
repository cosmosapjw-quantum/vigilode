# 이론 연구 루프 R1–R10

공통 진입을 마친 뒤 현재 이론 작업에 적용하라. 연구 서술·watchdog·no-go·정책 교정은 [RESEARCH_POLICY.md](RESEARCH_POLICY.md), 근거 상태·재사용 identity·실행 기록·인계는 [EVIDENCE_AND_HANDOFF.md](EVIDENCE_AND_HANDOFF.md)를 따르라.

현재 결론에 필요한 의존성을 따라 가장 이른 미충족 단계부터 수행하라. 각 단계의 입력과 전제가 유지되면 기존 근거를 연결해 재사용하고, 변경의 영향을 받는 하위 결과만 다시 검토하라. 구버전 기록은 단계 번호보다 실제 수행 내용과 근거로 대응시키라. 단계마다 별도 문서를 만들 필요는 없다.

실행 요청의 완료 근거는 실제 유도·증명·구성·반례·계산 또는 근거로 불확실성을 줄인 결정이다. 문헌 조사·설계·교정 요청에는 그 요청의 산출물 기준을 적용하라.

## R1 연구 위치·계약

- **입력:** 현재 질문, 탐색/수렴 목적, 사용자가 고정한 대상·가정·정확도, 기존 자료·체크포인트, 실제 도구와 프로젝트 계산 권한을 확인하라.
- **행동:** 현재 연구 단위의 대상 명제 또는 구성 문제, 사용할 convention, 필요한 산출물과 완료 조건을 구체화하라. 이미 확인한 승인과 입력을 재사용하라.
- 운영 장벽이나 과학적 오류가 목표와 충돌하면 근거를 특정하고 공통 정책에 따라 최소 대체 규칙을 적용하라. 교정된 가정·식에 의존하는 결과를 연결하라.
- 사용자가 고정한 물리 문제·정확도를 바꾸는 선택은 원래 목표의 상태와 대안별 결과를 보존해 제시하라. 그 선택과 독립된 승인 범위의 작업을 계속하라.
- **종료 근거:** 연구 단위, 적용 범위, 완료 조건, 다음 미충족 의존성이 식별된다. 계약이 같으면 다음 재개 때 이 기록을 참조하라.

## R2 근거·재사용

- **입력:** 관련 원전, 기존 정의·유도·증명·데이터·코드, 성공과 실패 기록을 필요한 범위로 읽어라.
- **행동:** 재사용할 정리·식·입력의 출처와 위치를 확인하고 현재 가정·정규화·경계조건으로의 대응을 작성하라. 문헌의 주장과 직접 확인한 내용을 구별하라.
- 미완성 자료에서도 유효한 중간식·예제·진단을 추출하라. 의존하는 미입증 보조정리는 정확히 표시하고 다음 유도에 연결하라.
- identity나 전제가 달라졌으면 영향받는 대응과 결과만 갱신하라. 자료·검색 접근의 공백은 필요한 원전이나 식을 특정해 남기고 독립적인 유도를 진행하라.
- **종료 근거:** 다음 단계가 실제 사용할 근거, 적용 조건, 확인이 남은 의존성을 추적할 수 있다.

## R3 주장·전제 정렬

- **입력:** R1의 목표와 R2에서 확보한 식·정리·가정의 연결을 사용하라.
- **행동:** 정의, 입력 가정, 인용 결과, 직접 유도한 결론, 탐색 가설을 구별하라. 각 핵심 명제의 양화·정의역·정칙성·경계조건을 필요한 만큼 명시하라.
- 명시된 가정 아래 확보한 결론을 직접 서술하라. 새 기호나 변수 변환이 기존 주장과 같으면 대응식을 쓰고 실제 차이를 특정하라.
- 미입증 보조정리를 쓴 유도는 그 의존성을 명시하라. 별도 응용·검산의 상태는 해당 주장의 의존성에만 연결하라.
- **종료 근거:** 무엇이 증명 대상이며 무엇을 전제로 쓰는지 분명하다. 표현만 바뀌고 진리조건이 같으면 기존 논증을 재사용하라.

## R4 가설·표현 탐색

- **입력:** 열린 명제, 막힌 유도, 구별할 해석이나 모델 선택을 사용하라.
- **행동:** 목적에 맞는 후보 표현·잠정 정의·근사·판별량을 구성하라. 후보를 가를 수 있는 구체적인 유도·예제·계산을 선택하고 가능한 최소 부분을 실제 수행하라.
- 새 정식화에는 원래 변수와의 사상, 작은 구성 예제, 보조정리 또는 계산식 중 유용한 첫 연결을 작성하라. 예상 기여를 밝히고 완성된 응용이나 관측량을 탐색의 선행 요건으로 요구하지 말라.
- watchdog이 사용되지 않는 구조나 중복을 특정하면 해당 연결을 만들거나 표현을 단순화하라. 복잡성·생소함 자체로 탐색을 기각하지 말라.
- **종료 근거:** 다음에 유도할 표현과 그 선택 근거, 판별할 질문이 있다. 기존 후보의 조건이 유지되면 그 구성과 판별 결과를 재사용하라.

## R5 구성적 유도

- **입력:** R3의 대상 명제와 R4의 표현, 필요한 보조정리·추정·구성 의무를 사용하라.
- **행동:** 증명, 방정식 변형, 해·반례 구성, 경계 추정 또는 근사 전개를 실제로 수행하라. 결론을 지탱하는 비자명한 전이와 인용 조건을 확인 가능하게 적어라.
- 열린 의무는 구체적인 보조정리·식·정의역으로 좁혀 직접 풀어라. 진행이 막히면 실패한 전이와 원인을 기록하고, 새 근거에 따라 표현·추정·구성 경로를 바꿔 진행하라.
- 완성된 조건부 유도는 그 가정 아래의 결과로 보존하라. 미수행 계산은 그 계산에 의존하는 주장에만 남은 의무로 연결하라.
- **종료 근거:** 완성된 논증·구성·반례 또는 실제로 줄어든 불확실성과 정확한 미완료 부분이 있다. 열린 필수 의무가 있으면 단계 완료로 표시하지 말고 다음 수학 작업을 이어가라.
- 변경되지 않은 보조정리는 재사용하고, 새 가정이나 교정식의 영향을 받는 전이부터 다시 유도하라.

## R6 독립 검증

- **입력:** R5의 논증, 핵심 전이, 인용 정리와 현재 주장 범위를 사용하라.
- **행동:** 오류 위험에 맞춰 독립 유도·역대입·극한 사례·검산 도구·다른 검토자 중 적절한 방법으로 핵심 결론을 확인하고 실제 검토 방법을 기록하라.
- 해당 문제의 차원·부호·대칭·보존량, 정칙성·경계·특이점, 극한 교환이나 근사의 조건을 확인하라. 순수 수학 문제에는 논증이 사용하는 조건을 적용하라.
- no-go 후보는 증명의 닫힘, 비자명성, 가정과 배제 범위의 일치를 검토하라. watchdog finding에는 대상·근거·영향·최소 교정을 붙이고 수정된 지적은 닫아라.
- **종료 근거:** 발견한 오류의 교정과 영향 범위, 확인한 논증, 남은 검증 의무가 구별된다. 새 전제 변경·모순·실패가 없으면 닫힌 검토를 재사용하라.

## R7 판별 검증

- **입력:** 결론이나 후보 선택을 바꿀 수 있는 판별 질문, 실제 도구, 현재 프로젝트의 실행 장소·계산량·예산 권한을 사용하라.
- **행동:** 필요한 기호 계산·경량 수치 검산·작은 사례 실행이 가능하고 승인 범위 안이면 직접 수행하라. 입력·방법·실제 출력과 결과가 지지하는 범위를 연결하고 도구 실행 시 명령을 기록하라.
- 순수 증명의 결론이 계산에 의존하지 않고 관련 판별 실행이 없으면 그 이유를 기록하라. 수치 실행을 일률적인 증명 완료 조건으로 추가하지 말라.
- 필요한 실행이 현재 권한·자원·도구 밖이면 가능한 준비를 완료하고, 정확한 입력·명령·판별 기준·필요 권한을 공통 인계 형식으로 남겨라. 미실행 항목의 상태를 유지하며 독립적인 연구를 계속하라.
- **종료 근거:** 실제 검증 결과, 유효한 기존 실행의 재사용, 적용 대상 밖인 이유, 필요한 미실행 계약을 구별한다. 판정에 필수인 실행이 남으면 해당 의무는 미완료다.
- 실패는 관찰된 환경·입력·방법과 실패 기작으로 기록하고, 새 진단에 따른 수정이나 대안 계산을 수행하라.

## R8 결과 판정

- **입력:** 유도·독립 검토·판별 실행의 실제 근거와 남은 의존성을 사용하라.
- **행동:** 공통 근거 상태에 따라 각 결과의 확보 범위와 다음 행동을 결정하라. 열린 증명에는 다음 lemma·추정·구성을, 반례에는 반박한 명제와 조건을, 실행 실패에는 수정 경로를 연결하라.
- 새로운 strong no-go를 성과로 채택할 때에는 공통 정책의 **NG1–NG7을 모두** 충족하고 각 기준의 근거 위치를 연결하라.

| 기준 | 확인할 채택 근거 |
|---|---|
| NG1 | 정확한 대상과 양화 |
| NG2 | 완결된 증명 |
| NG3 | 비자명성·비공허성 |
| NG4 | 핵심 장애 기작 |
| NG5 | 구체적인 과학적 중요성 |
| NG6 | 원전 대조로 확인한 문헌 대비 새 기여 |
| NG7 | 주장 범위와 독립 검토의 일치 |

- 조건들의 양립 불가능성이 정리의 주제이면 전체 조건의 동시 충족 예를 선행 요건으로 요구하지 말라. 기초 모델·부분 조건과 논증의 비공허성은 공통 정책에 따라 확인하라.
- 기준이 미충족이면 확보한 증명·국소 결과를 보존하고 해당 과학적 귀결·문헌 대조·증명 의무를 실제 수행하라. 기존 no-go는 원전과 적용 조건을 갖춘 선행 결과로 재사용하라.
- **종료 근거:** 각 판정이 실제 근거와 일치하고 다음 연구 행동이 정해진다. 판정 기록만으로 열린 의무를 끝내지 말고 승인된 범위에서 이어가라.

## R9 정식 결과·코딩 연결

- **입력:** R8의 판정, 완성된 식·논증·계산, 현재 요청의 문서·구현 요구를 사용하라.
- **행동:** 결과 → 가정·범위 → 증명·출처·실행 근거 → 필요한 다음 의무의 순서로 작성하라. 근거 상태는 한 위치에 모으고 정보가 늘지 않는 반복 제한 문장을 정리하라.
- 물리적 해석이 요청되면 원래 변수·관측량으로의 대응과 직접 귀결을 유도하라. 코딩 연결이 필요하면 식의 정의역, 입력·출력, 단위·정규화, 근사·특이점 처리, 참조값·검증 기준을 구현 계약으로 옮겨라.
- 문서·코드 계약은 실제로 채택한 식과 provenance를 연결하라. 기존 계약과 동등하면 참조를 재사용하고 바뀐 의존성만 수정하라.
- **종료 근거:** 요청된 결과를 재검토·재사용할 수 있으며, 필요한 코딩 입력이 정해진다. 문체 편집에서도 원래 진리조건과 실제 오류·실패 근거를 보존하라.

## R10 종료·재개

- **입력:** 현재 연구 단위의 산출물, 전체 요청에 남은 단위, 바뀐 가정·정책과 열린 의무를 확인하라.
- **행동:** 산출물과 근거 identity, 완료·재사용·미실행 범위, 다음 실행점을 공통 기록 형식으로 보존하라. 정책 override는 이전 규칙·교정 근거·대체 규칙·영향·검증을 기존 기록에 짧게 남겨라.
- 재개 지점에는 필요한 입력, 정확한 다음 유도·계산, 판별 또는 완료 기준을 연결하라. 되풀이할 필요가 없는 근거와 변경 때문에 다시 볼 부분을 구별하라.
- **종료 근거:** 현재 단위의 상태와 재개 경로를 확인할 수 있다. 여러 단위의 연속 수행을 요청받았으면 체크포인트를 남기고 승인 범위의 다음 단위를 계속하라.
- 전체 요청의 필수 산출물과 의무를 확인한 뒤 완료를 보고하라. 재개할 때에는 변경된 의존성이 처음 필요한 R단계로 돌아가라.
