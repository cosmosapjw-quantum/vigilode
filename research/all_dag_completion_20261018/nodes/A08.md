# A08 — guarded Leja/Laguerre/Chebyshev fused action

## Delivered scope

A new native selector, `rodas5p_core::polynomial_router::guarded_polynomial_action`, executes the three existing polynomial families on the same represented input and retains only complete-budget-admitted outputs. Its concrete action is

\[
F(A,h,w)=\sum_{k=0}^{4}\varphi_k(hA)w_k,\qquad
\varphi_k(z)=\sum_{j\ge0}\frac{z^j}{(j+k)!}.
\]

`A` is the stored dense exactly symmetric matrix with a Gershgorin-verified nonpositive enclosure; `h≥0`; all input bits are finite; the budget is finite and strictly positive. `Distinct` means five represented vectors; `SameVector` means the exact mathematical products `w_k=s_k v` specified by the stored vector and scales. The latter input is passed directly to each backend, so no unaccounted preparatory multiplication is introduced. `hA` is dimensionless; the absolute 2-norm budget has the units of the fused output. The current API assumes the same arithmetic environment as the reused directed-enclosure proofs.

The result binds the operator fingerprint, `h`, exact input encoding and unchanged total budget by a request SHA-256. All evidence-bearing fields are private; there is no `Deserialize` implementation. The fused output is owned by its result and stays fixed when the workspace is reused. No generic ODE trajectory claim is attached to a matrix-function action.

## Selection correctness

**Proposition A08.1 (unchanged target and budget).** Let a candidate backend return a vector `y_b` with a bound `e_b` produced by its admitted complete-total route. If `0≤e_b≤ε`, the selector's owned copy/move satisfies

\[
\|\widehat F-F(A,h,w)\|_2\le e_b\le\varepsilon.
\]

The selector validates the common input before dispatch, passes the identical immutable operator, `h` and `JointPhiInput`, and never changes `ε`. Leja consumes the private original-budget admission token. Chebyshev/Laguerre execute a plan made from the same request and subsequently require their complete total bound to fit `ε`. The quarter-budget used by their planner is only a truncation allocation; a small tail alone cannot admit an output. A copy of binary64 values has exactly the same represented center; a vector move has no numerical effect. Thus the backend bound applies unchanged. Result ownership prevents later cache/workspace mutation from replacing this center. This is a compositional reuse theorem, not a new approximation theorem.

When `ε/4` underflows, the planner refuses; the caller's tolerance is not increased. A declared spectrum abstains before any backend executes, including `h=0`. A valid request whose candidates cannot satisfy the budget returns typed `Abstained` with all failure stages and work. Malformed inputs are errors.

## Proven cost reduction without inferred timing superiority

**Proposition A08.2 (short-circuit work).** Let `C_i≥0` denote the complete cost of attempt `i` on the same cache state and let `j` be the first admitted attempt in the configured order. First-admitted routing executes attempts `1,…,j`, hence costs

\[
C_{\mathrm{route}}=C_{\mathrm{validation/hash/selection}}+\sum_{i=1}^{j}C_i.
\]

Compared with the same ordered three-attempt evaluation, it avoids the subsequent backend calls and their retained-output storage. This follows directly from the loop exit after its first admitted status. It does not claim that the prescribed first candidate is fastest; callers can use matched repeated measurements to choose a priority. `CompareAll` evaluates every candidate on one common request and retains their costs while preserving the same deterministic output priority.

**Proposition A08.3 (Laguerre authority preflight).** The present complete signed-adjoint authority covers `m≤128`. If its existing planner returns `m>128`, no call to that Laguerre executor can become admitted under the current authority. Refusing immediately after planning preserves all admitted outcomes and avoids the original `m` block operator applications (at most `5m` vector products for distinct inputs), recurrence storage and unsupported certificate work. For stored dense `A`, that discarded execution would cost `Θ(m n²)` arithmetic plus scalar setup. Planning itself is retained and charged. This is a constructive implementation optimization under the current authority boundary, not a no-go result about higher-degree Laguerre methods.

All valid-call timing spans include validation, request hashing, lazy workspace growth, cache lookup/setup, planning, execution, certificate, rejected attempts and retained-output copies/moves. The pre-existing operator constructor and caller workspace constructor are separate setup boundaries and must be included consistently in a cold benchmark. Work ledgers retain vector/block products, coefficient series/setups, Leja setup history/coverage and certification kernel counts in their own units. They are not combined into fictitious hardware FLOPs. `measured_allocated_bytes` remains `null`; allocator calibration and matched hardware timing belong to A07. Peak memory for the selected action is not inferred from block-allocation counters.
