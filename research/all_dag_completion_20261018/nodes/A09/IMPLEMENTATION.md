# A09 original represented-K H5 client and nonlinear window client

This implements both the original represented-K H5 obligation and a window-level nonlinear client. `actual_k_homotopy::certify_collective_actual_k_homotopy` certifies the complete represented stage equations, including all upper and diagonal coefficient leakage, on a common lambda tube. `nonlinear_homotopy::integrate_nonlinear_homotopy` independently certifies true ODE values at requested endpoints. These scopes differ: the first is a stage-target certificate and the second is an ODE endpoint certificate. Historical HT01/HT02 timing campaigns retain their recorded ABSTAIN/NOT_RUN states; neither result grants global performance promotion. ## Actual implementation

`nonlinear_homotopy::integrate_nonlinear_homotopy` takes an immutable `CollectiveModel`, exact-duration requested mesh, and fixed configuration. It executes a strict homotopy schedule ending at lambda=1. Candidate fine maps are repeated symmetric linear/nonlinear/linear splitting. The nonlinear subflow uses the actual stored weight sum and the common mean displacement formula. Every correction round evaluates the old window inputs in parallel, then solves a diagonal complex affine vector recurrence with a fixed binary tree. Weighted projection follows the entire recurrence; it is not inserted inside the scan. Every represented projected center is checked by outward energy arithmetic before reuse.

Candidate sin/cos, mean reduction, diagonal products, and prefix sums use ordinary binary64. They have no arithmetic-certificate authority. An independently rebound packet curve at each FINAL input encloses its true nonlinear ODE endpoint. For kappa=0, the source-bound packet curve uses its centered weighted radius, including returned-center displacement. For kappa>0, the A03 `verify_damped_packet_window` route verifies the original common-damped ODE with explicit subdivision budgets; its complete attempted-work summary is retained. The damped local tolerance is allocated from the unchanged user endpoint budget and conservative transport gain. This route can be expensive for unequal frequencies, so no speed claim follows from accepting damping. The difference between this local verified center and the actual candidate successor supplies the true ODE defect. Fixed gains `exp(c h)` with `c=|chi| S^2 E_upper` and the already implemented scalar outward affine prefix transport those defects. This bound is conservative and does not require the iteration contraction constant to be below one.

The successful result privately owns the original model, mesh, configuration, final candidate centers, and endpoint radii. No public constructor can create a successful result from an unverified candidate. Every requested weighted radius must satisfy the original absolute tolerance. Individual mode radii are obtained by dividing by the square root of that mode's source weight. No continuous-trajectory or relative-tolerance certificate is returned.

If the final certificate misses the budget, the configured retry doubles the split substeps and adds a correction round, capped at the number of windows. The old failed work remains charged. It does not widen the tolerance, renormalize the model, change chi, or substitute a nearby final lambda. Packet refusal, nonfinite arithmetic, resource-count overflow, inexact duration, unsuccessful inward projection, and exhausted budgets are typed failures.

## Work and cost semantics

Work counters preserve attempted fine-window/substep, vector-map/mode composition, projection input, final verification, and scalar-prefix events. All per-window packet counters are retained in deterministic order, including failed verification attempts. These selected event counters are not a full FLOP or allocation accounting. Vector prefix setup allocates O(MN) entries; each composition costs O(N), so the implemented serial-per-mode recursive tree has O(MN) work and O(N log M) span after setup. Every refinement currently rebuilds its tree and coarse seed. Those setup costs are included in the example's end-to-end elapsed time. No zero-allocation claim is made.

The example prints complete source inputs, actual configuration/tolerance, centers/radii, counters, and elapsed time including setup and independent verification. It is a single-arm run and explicitly reports no measured speed comparison. The theory's eta floor is not asserted for the implementation: it has no outward replay of candidate iterations. Final ODE certification is a separate, implemented route that does not need such a replay.
