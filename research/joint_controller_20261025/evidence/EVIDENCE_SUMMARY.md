# 최신 로컬 실행 근거의 재분석

## 확인한 결과

최신 로컬 후속 게시본 `4fe67602502440d76aa9dd245c6b1d67558c14bf`에 실린 50개 측정 행과 25개 비교 블록의 산술과 연결 관계를 다시 계산했다. 실제 측정 소스는 `d914b4c8a53405ea846f710e07f77fff5f45b16f`이며, 게시 커밋과 구분한다. 원자료 전체는 사용자 호스트에 있으므로 이번 검사는 저장소에 실린 값·출처 연결을 대상으로 한다. 기존 실행을 다시 돌리지 않았다.

같은 블록의 두 후보에 대해 문제·파라미터·시작 상태·구간·물리 오차 기준·참조·호스트·소스·빌드·출력·시간 측정 범위가 일치했다. 보고된 이진 부동소수점 오차와 참조 불확실도의 합은 정확한 유리수로 계산하여 상한과 비교했고, 50개 모두 통과했다. 비용 성분의 합, 50개 영수증 및 stdout 해시의 매니페스트 연결, 집계 중앙값과 블록별 비용비, 기존 독립 심사가 읽은 보고서의 SHA-256도 일치했다. 결과는 `PUBLISHED_SELECTION_AUDIT.json`, 재현 코드는 `../tools/audit_published_selection.py`에 있다.

## 비교 단위와 분모

| 조건 | 선택 경로 / 직접 대안의 시간 중앙값 | 중앙값의 비 | 블록별 선택/최소 후보 비용비 중앙값 | 직접 대안보다 비싼 블록 |
|---|---:|---:|---:|---:|
| 선언된 chirp chart, 물리 상태 129점 | 0.204 / 63.428 ms | 0.00322 | 1.000 | 0/5 |
| rotation, endpoint | 2.059 / 0.416 ms | 4.946 | 8.011 | 5/5 |
| stiff-forced, endpoint | 0.270 / 0.172 ms | 1.570 | 1.964 | 5/5 |
| gyromotion, endpoint | 9.146 / 2.707 ms | 3.379 | 3.094 | 5/5 |
| case5, endpoint | 2.620 / 0.193 ms | 13.569 | 14.597 | 5/5 |

두 종류의 비는 서로 다른 통계량이다. `median(C_selected)/median(C_direct)`와 `median(C_selected/C_direct)`는 일반적으로 같지 않다. 특히 짧은 rotation 측정에서 차이가 크므로 하나를 다른 값으로 해석하지 않는다. 원래 보고서는 두 값을 구분해 실었으며 집계 오류는 없었다.

자동 선택 wrapper는 네 문제의 20개 반복 블록 모두에서 대응하는 직접 대안보다 비쌌다. 이는 **동일 물리 오차 상한을 통과한 전체 실행의 관측 비용**에 관한 결과다. 네 문제를 각각 다섯 번 반복한 자료이며, 20개의 독립적인 문제 표본이 아니다. 개별 전환 시점의 오탐률을 얻으려면 해당 시점의 선택과 반사실 후보를 별도로 비교해야 한다. chirp는 사용자가 구조를 선언한 특화 경로이므로 자동 구조 탐지의 성공 사례로 세지 않는다.

## 비용 증가의 성격

rotation에서는 선택 경로가 사용한 6,395 RHS 중 1,150회가 버린 RODAS 진입 pilot에 속한다. 직접 DOPRI의 5,227회와 비교한 RHS 증가분 1,168회의 약 98.5%다. gyromotion에서는 증가분 1,615회 중 1,019회, 약 63.1%가 해당 pilot에 속한다. 이 비율은 기존 보고서의 실제 세그먼트 집계를 재사용한 것으로, 이번에 로컬 원시 세그먼트를 새로 읽어 산출한 값은 아니다. 두 경우 모두 **부적합한 후보를 최종 채택한 횟수**와 **채택하지 않을 후보를 알아내기 위해 쓴 비용**을 구분해야 한다.

case5는 선택 경로 1,633 RHS/232시도에 비해 직접 RODAS가 307 RHS/39시도였다. stiff-forced도 706 대 80 RHS다. 처음 명시법으로 진행한 비용, pilot, 세션 전환 및 implicit 재시작이 포함된다. RHS는 여러 비용 성분 중 하나이므로 이 비를 전체 실행 시간의 비로 대체할 수 없다.

`NARROW_GROUP_SUMMARY.json`의 `selected_route_counts`는 그대로 최종 채택된 방법의 점유율로 쓰지 않는다. 예를 들어 gyromotion의 RODAS 20개 기록은 다섯 반복의 버린 pilot 네 개씩과 대응한다. 전환 품질을 평가할 때에는 각 세그먼트의 `is_probe`, `committed`, `success`를 함께 읽어야 한다.

## 적응 제어와 구조 활용

case5와 KS의 새 2,000회 시도 계측에서는 각각 1,942회와 1,946회가 수락되었고 출력 착지에 의한 clipping은 없었다. 마지막 500개 수락 스텝의 중앙값은 음의 실축 선형 안정성 한계의 0.999668배와 0.999630배다. 작은 스텝이 누적되는 원인에 명시법 안정성 제한이 강하게 작용한다는 해석이 유지된다. 이 자료는 `h`가 작다는 사실만으로 일반적인 stiffness 라벨을 부여할 근거가 되지는 않는다. 같은 현상은 진동 위상 오차·출력 착지·원래 변수로의 오차 증폭에서도 나타날 수 있다.

chirp의 선언된 equivariant chart는 물리 상태 129점의 오차 상한을 통과하면서 1,033 RHS/172시도를 사용했다. 원래 좌표의 정밀도를 조인 DOPRI는 1,327,699 RHS/221,283시도를 사용했다. 원래 물리 상태로 재구성한 최대 오차는 각각 약 9.04e-9와 5.83e-5이고 공통 상한은 1e-4다. 다른 달성 오차를 동일한 정확도로 표현하지 않는다. 구조의 정확성을 알고 있을 때 빠른 carrier를 제거하는 이득은 실측 근거를 갖고 있으며, 다음 단계는 이 구조 정보와 물리 오차·유효기간을 자동 선택기에서 함께 소비하는 것이다.

## 이번 개발에 주는 수용 기준

1. 부적합 pilot의 반복 비용을 줄이되, 기존 후기 강성 전이와 위치를 바꾼 전이에서 필요한 재탐색이 살아 있어야 한다.
2. 전환 판단에는 같은 시작 상태와 물리 구간에서의 오차 조건을 만족하는 후보만 넣는다. 실패한 대안의 짧은 실행 시간은 우위로 세지 않는다.
3. 검토에 사용한 구간과 그 이후 평가 구간을 분리한다. 방법·차트·모델·물리 norm·실행 환경이 바뀌면 이전 비용 근거를 갱신한다.
4. 최종 방법의 선택, pilot을 시작한 판단, 전체 wrapper 비용을 각각 기록한다. 비용의 분해가 없으면 inclusive envelope에 한 번만 포함한다.
5. 병렬 callback의 미시 벤치마크는 통합 solver의 출력·정확도·전체 비용 자료와 연결한 뒤 평가한다.

현재 근거는 특화 chart와 DOPRI 세션 유지의 효용을 지지한다. 범용 production 판단을 완료하려면 새로운 재탐색 정책의 전이 검증, implicit 세션 유지 또는 재시작 비용 제어, 일반 구조 provider의 물리 오차 계약, 큰 격자 통합 실행 및 해당 릴리스 소스의 폭넓은 검증이 남아 있다.
