\begin{abstract}
We replayed source-sensitive support checks at their original commits and
ran a separate native validation on the integrated delivery plus limited
contract repairs. The original 23-node, 34-edge plan, 73-path coverage, ten
interactions and negative evidence remain intact. The native contract and
manufactured-model results below are scoped; full research-reference authority,
public API compatibility and broad physical-client qualification remain open.
\end{abstract}

\section{Matched accuracy and profile}
For the rapid oscillator, both retained DOPRI and RHS-only switching produced
the same 17-point maximum state error $9.4603\times10^{-7}$ at input tolerance
$10^{-8}$, below the common achieved-error cap $10^{-6}$. Their maximum
phase and amplitude errors were $1.4996\times10^{-7}$ radians and
$9.8307\times10^{-7}$. They used identical work counters: 10027 accepted
steps, 10845 attempts and 65071 RHS calls, with zero JVP calls. Three timed
samples gave median solver-reported times 5.591 ms (DOPRI) and 5.702 ms
(switching). The small difference is diagnostic only. At input tolerance
$10^{-6}$ both arms exceeded the common $10^{-4}$ achieved-error cap, so no
speed ratio was assigned to that first cohort. Separate Callgrind differences between 16 and 32 windows (17 and 33 requested observation points)
at the same endpoint gave 14827 and 14849 marginal guest instructions
per added point, respectively. Numerical work changed between grids, so these
are neither whole-solve instruction counts nor native elapsed time.

\section{Open gates and claim ceiling}
The full research-reference authority check fails on this checkout with 49
missing citations; the PR94 CI failure reported 53 under its own snapshot.
The attempted Q-LEDGER repair and a proposed stiff-cubic benchmark driver
were rejected in independent review and were not merged. The standalone vendor validator was invoked without its required directory
argument (exit 2), leaving that graph validation unperformed, although locked
offline metadata and builds passed. Whole-workspace
format checking still fails on the same two coupled files as the delivered
source. Public switching configuration changes still need an explicit
compatibility or version decision. The ten prospective interaction campaigns,
six candidate implementation nodes and real-client qualification are not
promoted by the tests above. Broad production remains \textbf{HOLD}.
