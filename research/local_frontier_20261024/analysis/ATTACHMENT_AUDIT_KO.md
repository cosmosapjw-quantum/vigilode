# 로컬 벤치마크 제안의 수학·실행 계약 교정

입력은 `evidence/LOCAL_BENCHMARK_REQUEST.txt`에 원문 그대로 보존한다.
아래 교정은 시험 목적을 유지하면서 방정식, 비교 대상, 수용 기준을 맞춘다.
실제 24개 모델의 초기조건·경계조건·정규화는 BENCHMARK_MODELS 문서가 정의한다.

## 경계층과 강성의 구별

제안 #5에서 \(z=y_1-\cos y_2\)를 정의하면 정확히

\[
\dot z=-z/\epsilon,\qquad
\dot y_2=-y_2/(1+t)+0.2\cos y_2+0.2z
\]

이다. 이 좌표의 야코비안은 하삼각이며 대각 성분 중 하나는 항상
\(-1/\epsilon\)이다. 따라서 경계층 진폭의 소멸과 빠른 섭동 모드의 소멸은
서로 다른 조건이다. 원식은 느린 궤적만 보고 위험하게 명시적 방법으로 돌아가는지
검사하는 대조군으로 사용한다. 실제 시간 의존 강성 전이는 #6 및 별도 제조해
holdout에서 검사한다. #6은 표의 \(t^{-3}\)와 본문의 4제곱이 다르므로 본문 식을
명시적으로 채택하고 해당 모델 identity에 기록한다.

## 주어진 점화식의 성질

제안 #7의 \(f(T)=(1-T)\exp[(T-1)/(\epsilon T)]\)에 대해

\[
f'(T)=\exp[(T-1)/(\epsilon T)]
\left[-1+\frac{1-T}{\epsilon T^2}\right],\qquad f'(1)=-1.
\]

\(T(0)=0.1,\epsilon=0.02\)에서는 지수가 \(-450\)이다. 원문에 적힌
\(-e^{1/\epsilon}\)의 평형 고유값과 지연 점화 설명은 이 식에서 나오지 않는다.
원식을 보존하여 정체 대조군으로 사용하며, 열폭주식의 수정 모델을 추가하면 별도
model ID·식·초기조건을 부여한다. 원식의 통과를 점화 시험의 통과로 세지 않는다.

## 결함과 비강성 판정

\(f(t,y)=-\lambda[y-g(t)]+g'(t)\)를 생각하자. \(g\)가 연속 출력이 정확히
표현하는 다항식이고 \(y(0)=g(0)\)이면 그 궤적의 결함은 모든 점에서 0이다.
그럼에도 섭동은 \(\dot\delta=-\lambda\delta\)를 만족하며 \(\lambda\)에는
상한이 없다. 중점 결함은 출력 일관성 진단으로 사용할 수 있지만, 그 값만으로 명시적
방법의 안정 영역을 보증할 수 없다. 현재 전환기의 실제 수락 상태·시도 예산·비용 비교를
사용한다.

## 탐색 비용 정리의 조건

\(L=\max(1,\lceil C/(\varepsilon P)\rceil-1)\)이면 정확 산술에서
\((L+1)P\ge C/\varepsilon\)이다. 이 부등식을 실제 추가 탐색비 비율로 쓰려면
실패한 탐색 뒤 보호 스텝이 수락되고, 다음 \(L\)개 보호 스텝의 대표 비용이 \(P\)이며,
최대 대기 상한이 식을 잘라내지 않아야 한다. 예를 들어 \(C=100,P=1,
\varepsilon=1/4,L_{\max}=64\)이면 실제 식의 비율은 \(100/65>1/4\)이다.
이번 구현은 비용 참조의 step/state/epoch 유효성을 검사하고 비용 예측과 보장을 구분한다.

## 모델 및 병렬 실험의 의미

- #2 본문은 POLLU 또는 HIRES를 허용한다. 구현한 표준 모델의 이름과 차원을 그대로
  기록하며 HIRES를 POLLU로 표기하지 않는다.
- KS 식 \(u_t+uu_x+u_{xx}+\nu u_{xxxx}=0\)의 RHS 선형 푸리에 기호는
  \(k^2-\nu k^4\)이다. 주기 경계에서 장파 성장과 단파 감쇠를 독립 검사한다.
- #13의 flux·냉각, #17의 속도장, #19의 구면 기저와 closure, #20의 정규화·바리온 방정식,
  #23의 반응망은 이름만으로 완전히 정해지지 않는다. 구현된 변형의 식·범위·남은 원형을
  명시한다. 선형화한 구면 모드를 완전한 비선형 SWE로 부르지 않는다.
- #10의 상대론적 식은 무차원화와 운동량 단위를 명시해야 한다. 물리 상수의 수치를
  암묵적으로 바꾸는 대신 benchmark의 기준 척도에 포함한다.
- 24개 모델과 5개 thread budget은 120개 설정이다. 적분법·허용오차·반복 프로세스·참조
  계산을 곱하면 실제 실행 수는 더 많다. 완성된 계획에서 실제 개수를 계산한다.
- 7개 독립 stage task의 이상적 묶음 수는 \(\lceil7/p\rceil\)이다. RHS 내부 병렬화,
  기저 구성, 잔차 검사, 동기화 비용은 별도로 존재한다. 8→12 스레드에서 데이터 병렬의
  가속도 보장되지 않으므로 측정한다. 중첩 pool을 기본으로 사용하지 않는다.
- 독립 IVP 앙상블과 공간적으로 결합된 격자는 다른 수학 문제다. 각 앙상블 성분의
  정확도를 개별 판정하고 처리량·단일 궤적 지연을 구분한다.
- 차원 제한의 사전 거절, 실패, timeout, 참조 미확보를 결과로 보존한다. 120개 설정을
  모두 성공시키기 위해 tolerance나 문제를 몰래 완화하지 않는다.

위의 식 변형과 반례는 직접 유도다. 수치 비교의 채택 여부는 실제 실행 결과와 모델별
참조 계약을 따른다. 제공된 초안의 모든 문장이 검증된 문헌 주장인 것으로 취급하지 않는다.
