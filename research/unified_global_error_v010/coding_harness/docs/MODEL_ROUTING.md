# Model routing

- 반복적 추출·로그 요약: fast/low-cost
- 일반 기능·작은 버그: balanced
- 복잡한 수치 알고리즘·다중 파일: high reasoning
- 어려운 architecture/numerical bug/final review: high/xhigh/pro, 측정된 이득이 있을 때
- `max`: 하나의 hardest quality-first task
- Ultra/subagents: 독립적인 exploration, tests, review, separate worktree candidates

항상 높은 effort보다 contract, environment, test route, verifier를 먼저 고친다.
