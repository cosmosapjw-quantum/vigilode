# Phase 7 — Minimal Decisive Verification Design

## Goal

각 survivor를 살리거나 죽일 최소한의 high-information test를 설계한다.

## Required fields

1. testable claim
2. required inputs
3. expected result if correct
4. expected result under strongest competitor
5. pass criterion
6. kill criterion
7. ambiguity condition
8. cheapest next action
9. escalation path

비용이 비슷하면 여러 가설을 가장 잘 구분하는 test를 우선한다.
