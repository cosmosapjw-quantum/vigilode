# ChatGPT Work / Project setup

1. ChatGPT에서 연구 주제별 Project를 만든다.
2. `PROJECT_INSTRUCTIONS.md`를 Project Instructions에 붙인다.
3. 핵심 자료와 `state/` 파일을 sources에 추가한다.
4. Deep Research 결과나 중요한 decision note는 Project source로 저장한다.
5. Work에서 긴 run을 시작할 때 `prompts/00_integrated_work_run.md`를 사용한다.
6. phase 종료 후 상태 파일을 갱신한다.

제품 기능과 이름은 rollout·플랜에 따라 다를 수 있다. `docs/RESEARCH_BASIS.md`에서 최신 공식 링크를 확인한다.
