  (earlier errors are damped by R(z) ~ -12.4/z), and that error grows like h^3 with the last step's
  length. With the estimate far below tolerance the controller grows each step by its cap 5, so
  the last step's length is set by where the ramp from h0 lands before t1 (not by the tolerance).
  R (h0 = 1e-3) ends with a short step 0.219 and is in the lucky tail (its error is 0.057 of the
  scan median). The FBP leg is a plain Rodas5p::solve from t_D + H with h0 = H; it ends with 0.743
  (A) and 0.326 (L). Rodas5p::solve with h0 = H and no handover gives the same magnitude (31.85 at
  A). Hypotheses refuted: pilot state carried to t1 (damped; it acts only through the early step
  proposals), controller history (C_cont fails too), FD time derivative, FD Jacobian, dense output
  (not used; all 162 runs end exactly at t1 with the step's own state), error norm (one norm).
  Verdict: the E7 failure is an inherent property of comparing two valid RODAS5P step sequences
  on a problem whose error is far below tolerance (N: 0.0041 and 2.9e-7 of the tolerance unit),
  with a rule without floor; NOT a defect of the route. No code change (steps 2's correction
  clause does not apply); the V27 contract tests are therefore not re-run for a change.
