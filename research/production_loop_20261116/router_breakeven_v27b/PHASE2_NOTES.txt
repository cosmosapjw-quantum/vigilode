6. DISCRIMINATORS (thresholds as frozen; u in {cb, op}; "run 1" = process 1, repeat 1)
---------------------------------------------------------------------------------------------
E1  C1 = cases where T run 1 and N run 1 succeed (no case excluded).
    G_u = exp(mean over C1 of ln(u(N)/u(T))); need G_cb < 1 and G_op < 1.
    U1 = undeclared cases of C1 in which D or R (run 1) succeeds. For X in {N, T}:
    M_u(X) = max over U1 of u(X) / min{u(Y): Y in {D, R} succeeds}; need M_u(N) < M_u(T), both units.
    Cases of C1 where neither D nor R succeeds enter G but not M. Every undeclared N run 1 must have
    run.analysis_basis.kind == "break-even": a mismatch is reported (no criterion changes).
E2  FAIL iff some case has T run 1 succeeding and N run 1 not (same options, same max_steps).
E3  Checked on each of the three N runs of a case (all three must hold).
    (a) set = N runs of undeclared cases with no leg after the first (tier1-explicit) leg, minus
        E3_excluded_runs = the N runs whose last pilot record has verdict "fatal" and whose status
        kind is "callback-failed" (owner decision D1; members listed with their pilot record).
        Checks against D run 1: final_time_bits and final_state_bits equal D's; the first leg's
        counters equal D's counters field by field and its attempts equal D's attempts; N's
        rhs_calls + ft_calls = D's + sum pilot_callbacks; N.attempts = D.attempts + sum
        pilot_attempts; op3(N) = op3(D) + sum round(3 pilot_operations); cb(N) <= 2 cb(D) and
        op3(N) <= 2 op3(D).
        R4 (ruling): an N run of the set that stops on the budget (status kind
        "max-steps-reached") after lost pilots is listed; for it, D above is the extra process of
        arm D with max_steps = the run's DOPRI5 attempts (bits, DOPRI5 counters plus exactly the
        pilots' counters, cost <= 2 cost(D): the same checks); the checks against the case's
        regular D run are reported beside it without a rule. Not expected on this set.
    (b) every N run of a declared case equals T run 1 bit for bit: final_time_bits,
        final_state_bits, success, status, stop, counters, attempts, accepted_steps,
        rejected_steps, closure entries (entries incl. rhs_by_kind). route_history text and
        route_digest are not compared (N's digest hashes "pilots": [] where T has null), reported.
E4  every N run (3 per case): A_all = sum of the legs' attempts + pilot_attempts of the pilots whose
    verdict is not "accepted" (the accepted pilot is inside the RODAS5P leg) <= max_steps;
    A_all == run.attempts; a status of kind "max-steps-reached" carries max_steps = options.max_steps;
    a run that failed with A_all >= max_steps has that typed status.
E5  every N run: (i) uncharged entries per kind = max(0, entries - charged): rhs vs rhs_calls, jvp

7. R_H AND THE LAST ACCEPTED RODAS5P STEP (no rule; E7_DIAGNOSIS.json method)
---------------------------------------------------------------------------------------------
Prefix replays as in E7_DIAGNOSIS.json: the same Rodas5p::solve call with max_steps = k returns the
last accepted point after k attempts (deterministic drivers; checked there: the last replay equals
the run). Only the last step is needed, so the runner replays k = attempts - 1, attempts - 2, ...
and stops at the first k whose last accepted time differs from the run's final time: that time is
the start of the last accepted step (none: the run's start). Recorded: start and end time (values
and bits), length h = end - start, k, number of replays. Only for runs that reached t1 (else null).
Replays run on fresh copies of the problem with their own entry counters (not charged to the case).
  arm R and R_H: the run's own call Rodas5p::solve(problem, span, y0, options).
  arm N after a handover: the RODAS5P part is the leg after the first leg. The e5 replay of the
      RODAS5P run after the handover (Rodas5p::solve from the replayed accepted pilot's end with
      h0 = H and the attempts left; after a numerical DOPRI5 stop from DOPRI5's last accepted point
      with the user's h0) is replayed by prefixes; "matches_n" records whether its final time and
      state bits equal N's. If that run made no step, the last step is the pilot's (t_D to its end).
  arm N on RODAS5P from t0 (declared facts): Rodas5p::solve(problem, span, y0, options) on a fresh
      copy, prefixes as for R; "matches_n" as above.
  arm N on DOPRI5 only, and arm T: null.

8. RULING R4: HOW DOPRI5 ATTEMPTS ARE COUNTED (reading; checked on the toys in step 0)
---------------------------------------------------------------------------------------------
The runner's DOPRI5 attempts of an N run are the attempts of its tier1-explicit leg
(run.dopri5_attempts = legs[0].attempts; every rejected attempt counts). The R4 comparison is sound
iff Dopri5::solve with max_steps = m stops after exactly m attempts (stats.attempts = m, accepted +
rejected; stop AttemptBudget) at the accepted point the route's DOPRI5 leg had after m attempts.
Check (step 0, toys only, outside the set): N with small --max-steps on toy and toy_osc so that it
stops on the shared budget after lost pilots, then D with --max-steps = that run's dopri5_attempts;
compare D.attempts with m, final time and state bits, D's counters with the first leg's counters,
N.attempts = m + sum pilot_attempts. Result written in addendum 0b below before any deciding run.
