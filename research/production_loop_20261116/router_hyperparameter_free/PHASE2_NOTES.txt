6. DISCRIMINATORS (u in {cb, op}; run 1 of each arm unless stated; thresholds as frozen)
---------------------------------------------------------------------------------------------
E1  C1 = cases where T and N succeed, problem != kt_vanishing.
    G_u = exp(mean over C1 of ln(u(N)/u(T))); need G_cb < 1 and G_op < 1.
    For X in {N, T}: M_u(X) = max over cases of C1 in which D or R succeeds of
    u(X) / min{u(Y): Y in {D, R}, Y succeeds}; need M_u(N) < M_u(T) for both units.
E2  fails iff some case has T succeeding and N not (same options, hence same max_steps).
E3  (a) every N run on the break-even route (run.analysis_basis.kind == "break-even") with no
        handover (no leg after the Tier1Explicit leg): final_time_bits and final_state_bits equal
        D's; the Tier1Explicit leg's counters equal D's counters field by field and its attempts
        equal D's attempts; N's charged rhs+ft calls = D's + sum pilot_callbacks; N.attempts =
        D.attempts + sum pilot_attempts; 3*op(N) = 3*op(D) + sum 3*pilot_operations (exact);
        and u(N) <= 2 u(D) for both units.
    (b) every N run decided by a declared fact (analysis basis not break-even: declared regime,
        supplied derivative, mass matrix, ...) equals T bit for bit: final time and state bits,
        success, status, stop, all counters, attempts, accepted and rejected steps, closure
        entries by kind. (route_history text and route_digest are not compared: the digest of N
        hashes "pilots": [] where T has null, and D5 renamed route names; both are reported.)
E4  every N run: A_all = sum of legs' attempts + attempts of pilots outside a leg (lost, fatal,
    refused; the accepted pilot is inside the RODAS5P leg) <= max_steps; A_all == run.attempts is
    checked and reported; a run that stops on the budget reports status MaxStepsReached with
    max_steps equal to the options' max_steps.
E5  every N run: (i) uncharged entries = 0: entries.rhs - counters.rhs_calls, entries.jvp -
    counters.jvp_calls, entries.time_derivative - counters.ft_calls, entries.jacobian - charged
    Jacobian callbacks, all 0.
    N runs where DOPRI5 runs first (break-even route; declared Nonstiff):
    (ii) first_is_t0_y0 true, and at_t0 and at_t0_not_y0 equal those of D (only DOPRI5's stage
         at t0);
    (iii) every right-hand-side entry that is not a stage (fd_column + fd_time_derivative) has its
         base point (column: the unshifted entry at the same time; time derivative: the entry
         with the same state next to it, i.e. the attempt's start point) equal, bit for bit, to
         either the start point of a pilot (time = pilot record t, state = the state of a DOPRI5
         stage entry at that time made before the pilot) or an accepted point of the RODAS5P leg
         (its start, or a point (t, y) of its recorded solution).
    Classification of a closure entry: as the runner's classify(): column = another entry at the
    same time whose state differs in exactly one component by the facade's FD increment
    sqrt(eps) max(|y_j|, 1); time derivative = same state as an adjacent entry at a time within
    4 sqrt(eps) max(|t|, 1); every other entry is a stage.
    N runs that start RODAS5P by a declared fact (D2, mass matrix, declared Stiff): (ii) and (iii)
    have no DOPRI5 stage to refer to and are reported as not applicable; E3(b) covers them.
E6  for every case and arm: the three runs have equal route_digest (N, T), counters, attempts,
    status, final time and state bits, and closure entries.
E7  every case except kt_vanishing where N succeeds and at least one of D, R succeeds (and has an
    error): err(N) <= 3 max{err(Y): Y in {D, R} succeeding}.
E8  F2: N succeeds. P_fatal: N's stop carries CallbackFailed with callback Rhs and message
    "sensor offline". N2: N ends with CallbackFailed at its first pilot: pilots has exactly one
    record, verdict fatal, and the run fails with a CallbackFailed stop.
E9  P_heat_fd|A|default: N's charged rhs_calls <= 5890 and a recorded handover; P_scalar_fd|A|
    default: <= 181818 and a recorded handover. (Also reported for L and S without a rule.)
E10 every N run with pilots: count <= 1 + floor(log2(A_D / b)) with A_D = DOPRI5 attempts
    (Tier1Explicit leg attempts) and b = analysis_basis.b; and sum over pilots of
    (pilot_callbacks, pilot_operations) <= DOPRI5 spend (DOPRI5 leg charged rhs calls; 52 n A_D)
    in each unit.
Frozen decision (PREDECLARED): the Auto route becomes N iff E1 to E10 all pass; otherwise today's
route stays and the implementation stays on its branch.

    callback (runner field jacobian_callback: P_blowup, P_mass, P_heat_dense, P_scalar_dense,
    P_heat_banded), else 0 (finite-difference builds are charged as rhs_calls).
    cb = rhs_calls + jvp_calls + ft_calls + charged Jacobian callbacks.

    uncharged copies of the problem), because Solution records only t0 and t1 without dense
    output, so "a point of its recorded solution" is not available: the entries of the case,
    bit for bit and in order, must be a prefix of the entries of Dopri5::solve (same options)
    with, inserted, each pilot's entries = Rodas5p::solve with h0 = H, max_steps = 1 from the
    last accepted point of Dopri5::solve with max_steps = the record's dopri5_attempts (its time
    must equal the record's t and be > t0), and after a handover the entries of Rodas5p::solve
    from the replayed accepted pilot's end point with h0 = H and the attempts left (after a
    numerical DOPRI5 stop: from DOPRI5's last accepted point with the user's h0); nothing of
    DOPRI5 after an accepted or fatal pilot. E5 (iii) holds for a run iff e5.split is true, every
    pilot row has start_equals_record and start_after_t0, and e5.parts.dopri5 has no entry

    e5.first_entry_is_dopri5_solve_first and e5.parts.pilots.at_t0 = e5.parts.rodas5p_run.at_t0 = 0.
    The runner's classifier labels by kind are reported as measures; its adjacency rule also
    labels the first stage f(t, y) of a RODAS5P attempt as a time derivative when an FD
    time-derivative call f(t +- e, y) is next to it (seen on toy_ft); no decision uses the labels
    of the RODAS5P parts.

    pilot. A run without a pilot has nothing to count or bound (for A_D < b/2, e.g. a run that
