NEW STRUCTURAL FACT (derived, then checked numerically to 1e-56 by run_exploratory.py, kind pr_pole_identity)
  b^T N^(L-1) u_2 = gamma^2 * b^T N^(L-1) 1   (N = beta - gamma I, u_2 = beta^2 1 - c^2/2, stiffly accurate b),
  because N^(L-1) only connects level 1 to level L and (u_2)_1 = gamma^2. Hence W_2(z) = 0 identically (the
  Prothero-Robinson property that RODAS5P has for q = 2 and 3) forces mu_(L-1) = b^T N^(L-1) 1 = 0, i.e. the
  stability function loses one pole: R = P/(1 - gamma z)^(L-1).
  Consequences for two processors and order 5 with R(inf) = 0:
    depth 5 + exact W_2 = 0  -> 4 poles -> impossible (theory S9, L = 4 no-go);
    depth 6 + exact W_2 = 0  -> 5 poles -> gamma pinned at 0.27805, linear order 5 (defect 5.3e-4);
    RODAS5P: 8 stages, 7 poles (theory S2: N^7 = 0) -- the same mechanism (beta_21 = 0).
  A tried variant "D6L with hard Prothero-Robinson conditions" (smoke seeds only, logs/smoke3_search_D6L_hardPR.jsonl,
  0 of 4 feasible) is infeasible for this reason and was dropped before any declared start; D6L runs as declared in
