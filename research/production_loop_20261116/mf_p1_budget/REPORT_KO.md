# V28: 행렬 없는 단계 풀이 P1의 규칙 B 단독 재시험 (OD-L1-23, 부록 A9)

이 보고서는 `parse_results.py`가 `RESULTS.json`에서 만든 것입니다. 모든 수치는 실행된 원시 로그에서 계산되었습니다.

## 결론

- 동결된 판정: **KEEP** (K PASS, V PASS, T FAIL)
- 규칙: K, V, T가 모두 성립하면 SWITCH(P1을 기본값으로), K 또는 T가 실패하고 V가 성립하면 KEEP(출하 정책 S 유지), V가 실패하면 KILL.
- 출하 정책 S가 기본값으로 남고 P1은 선택 사항(opt-in)으로 남습니다. 어떤 기본값도 바뀌지 않았습니다.
- SWITCH가 아니므로 V25의 6단계(D0, G, R)는 실행하지 않았습니다 (NOT_RUN). 보호된 파일은 하나도 편집하지 않았습니다.

## 무엇을 시험했나

- 셀: V25의 결정 셀 20개(ac3d, robertson_rd1d, schnakenberg2d, porous2d)와 V24의 결정 셀 20개(fhn3d, cusp1d, burgers2d, bruss1d), 각 가족마다 rtol = atol = 1e-3 ... 1e-7, 모두 40개. 생성기, 크기, 구간, 허용오차는 두 노드의 프로토콜 그대로입니다.
- K (같은 단계 계의 재풀이): 섭동하지 않은 S 실행과 P1 실행의 모든 단계 계를 출하 커널과 P1 커널로 0에서 다시 풀어, P1이 크릴로프 예산(200 열)을 다 쓰고 S는 그렇지 않은 계가 하나라도 있는지 셉니다.
- V: 재풀이에서 P1이 돌려준 모든 반복값의 참 잔차를 프로그램 자체의 JVP로 다시 계산해 단계 문턱값과 비교합니다.
- T (섭동 궤적): 셀마다 j = 1..8, 시작 상태를 y0_i (1 + 1e-8 xi_ij)로 섭동(xi는 (셀, j, i)로 시드한 splitmix64), 같은 섭동 상태에서 S와 P1을 실행, 쌍마다 d = (P1의 예산 소진 풀이 수) - (S의 수). W = d > 0인 쌍 수, n = d != 0인 쌍 수, P(X >= W) (X ~ Bin(n, 1/2))가 0.05 이상이면 성립.
