# 비강성 문제를 위한 명시적 적분 경로: 정확도, 연산량, 병렬화의 구성적 분석

작성·문헌 조회: 2026-10-22 UTC. 디렉터리의 `20261023`은 작업 식별자이다.

## 초록

비강성 상미분방정식에서 매 단계 자코비안과 선형계를 구성하는 비용은 정확도 달성에 필요한 비용보다 클 수 있다. 이번 확장은 VigilODE에 Dormand–Prince 5(4) 명시적 경로와 독립 궤적의 병렬 실행 경로를 추가한다. 이 방법은 우변 함수만 평가하며, 자코비안·행렬 분해·Newton 반복을 요구하지 않는다. 고정된 매끄러운 모델에 대해 5차 종점 정확도와 4차 내장 추정식을 사용하고, FSAL 재사용으로 최초의 완전한 시도에는 7회, 이후의 완전한 시도에는 6회의 우변 평가를 수행한다. 이는 유효한 도함수를 매번 다시 구하는 구현에 대한 정확한 평가 횟수 감소이며, 강성 문제에서의 보편적인 실행 시간 우위를 뜻하지 않는다.

기존 순차 단계들을 병렬 Picard 반복으로 바꾸는 구체적인 16단계 5(4) 방법도 구성했다. 이 방법은 충분히 매끄러운 문제에서 같은 차수를 유지하면서, 준비된 시작 도함수 이후의 우변 의존 깊이를 6에서 5로 줄인다. 그러나 총 우변 평가는 6에서 15로 증가하며, 작은 순허수 인수에서 증폭률이 1을 초과한다. 따라서 이번 구현에는 순차 DOPRI5와 독립 궤적 병렬화만 포함하고, 이 16단계 구성은 비용이 큰 우변을 가진 감쇠 문제에 대한 후속 후보로 남긴다. 확산형 문제에는 Chebyshev 다항식을 통한 안정성 제한 비용의 제곱근 감소를 별도로 증명한다. 모든 성능 결론에는 해당 연산 비용, 매끄러움, 안정성 및 오차 가정이 명시되어 있다.

## 1. 연구 질문과 이번 결론의 범위

대상은 전진 초기값 문제

\[
 y'(t)=f(t,y(t)),\qquad y(t_0)=y_0\in\mathbb R^n
\]

이며 질량 행렬은 항등 행렬이다. 시간 의존 우변을 허용한다. 핵심 질문은 다음 세 가지이다.

1. 비강성 영역에서 기존의 강성 적분 경로보다 적은 연산 구조로 요구 정확도를 얻을 수 있는가?
2. 사용자의 순차 루프 병렬화 아이디어를 명시적 단계에 적용하면서 정확도와 비용을 함께 증명할 수 있는가?
3. 특정 문제군에서만 성립하는 이득을 일반적인 성능 향상으로 오인하지 않도록 어떤 비교가 필요한가?

이번에 구현된 선택은 `Dopri5`의 명시적 선택과 `Dopri5Ensemble`의 독립 적응 궤적 실행이다. 강성 여부를 자동으로 증명하거나 실행 중 암묵적 방법으로 전환하는 기능은 추가하지 않는다. 새 경로의 질량 행렬, 사건 위치 추적 및 연속 출력은 지원 범위 밖이며 공개 API가 요청을 거절한다. 관측 시각은 실제 단계 종점으로 맞춘다.

아래 정리는 수학적 방법과 연산 구조에 대한 결과이다. Rust 구현의 안전성, 실제 전역 오차 및 벽시계 성능은 별도의 코드 검증과 재현 가능한 벤치마크가 필요하다. 따라서 이 문서만으로 범용 production 사용 적격성을 판정하지 않는다.

## 2. 기존 연구의 재사용과 문헌 확인

Dormand–Prince 계수는 새로 제안한 것이 아니다. 원 논문 [Dormand–Prince, 1980](https://doi.org/10.1016/0771-050X(80)90013-3)에 귀속시키고, 계수·오차식·FSAL 동작은 저자 기관에서 제공하는 [Hairer–Wanner DOPRI5 원본 코드](https://www.unige.ch/~hairer/prog/nonstiff/dopri5.f)와 대조했다. 원 논문의 전체 본문을 읽었다고 주장하지 않는다.

병렬 단계 반복의 출발점은 [van der Houwen–Sommeijer, 1990](https://ir.cwi.nl/pub/1663/1663D.pdf)이다. 이 문헌의 predictor–corrector 구성과 우변 비용 중심 분석을 현재의 명시적 계수에 적용한다. 외삽법과 deferred correction의 비교는 [Ketcheson–Waheed, 2014](https://msp.org/camcos/2014/9-2/p01.xhtml)를 통해 확인했다. 이 문헌의 다른 하드웨어·문제에서 측정한 성능을 VigilODE 성능으로 전용하지 않는다. SciSpace 검색 결과에 나타난 중복 연도 표기는 원 출판사의 2014년 정보로 정리했다.

Exa는 원 코드와 기관 원고를 조회하는 데, SciSpace는 관련 연구와 대안을 찾는 데, Wolfram은 유리수 차수 조건과 안정성 다항식을 계산하는 데 사용했다. 원자료별 조회 범위와 제한은 `SOURCES.json`에 기록했다. 기존 프로젝트의 과거 수치 실험은 이번 이론 계산에서 다시 실행하지 않았다. 이번 정확 계산의 목적은 새 explicit 경로와 새로 구성한 병렬 후보의 식을 확인하는 데 있다.

## 3. 방법, 표기, 전체 차수 조건

기울기 단계 \(K_i\)의 단위는 상태/시간이다. 고정된 한 시도에서

\[
 K_i=f\!\left(t_n+c_i h,\ y_n+h\sum_{j<i}a_{ij}K_j\right),\quad
 y_{n+1}=y_n+h\sum_{i=1}^{7}b_iK_i,
 \quad \widehat y_{n+1}=y_n+h\sum_{i=1}^{7}\widehat b_iK_i.
\]

비영 계수는 다음과 같다. 각 행의 첫 열은 \(c_i\), 나머지는 \(a_{ij}\)이다.

| 단계 | \(c_i\) | 앞선 단계에 대한 계수 |
|---|---:|---|
| 1 | 0 | 없음 |
| 2 | \(1/5\) | \(1/5\) |
| 3 | \(3/10\) | \(3/40,\ 9/40\) |
| 4 | \(4/5\) | \(44/45,\ -56/15,\ 32/9\) |
| 5 | \(8/9\) | \(19372/6561,\ -25360/2187,\ 64448/6561,\ -212/729\) |
| 6 | 1 | \(9017/3168,\ -355/33,\ 46732/5247,\ 49/176,\ -5103/18656\) |
| 7 | 1 | \(35/384,\ 0,\ 500/1113,\ 125/192,\ -2187/6784,\ 11/84\) |

\[
 b=\left(\frac{35}{384},0,\frac{500}{1113},\frac{125}{192},-\frac{2187}{6784},\frac{11}{84},0\right),
\]

\[
 \widehat b=\left(\frac{5179}{57600},0,\frac{7571}{16695},\frac{393}{640},-\frac{92097}{339200},\frac{187}{2100},\frac1{40}\right).
\]

오차 벡터는 두 큰 종점 상태를 빼는 대신

\[
 \Delta=h\sum_i(b_i-\widehat b_i)K_i
\]

로 직접 구한다. 계수 차이는

\[
 b-\widehat b=\left(\frac{71}{57600},0,-\frac{71}{16695},\frac{71}{1920},-\frac{17253}{339200},\frac{22}{525},-\frac1{40}\right)
\]

이다. 이렇게 해도 작은 추정량의 상쇄가 모두 제거되지는 않지만, 상태 자체의 공통 부분을 한 번 더 빼는 연산은 피한다.

선형 시험 방정식의 Taylor 계수 일치는 비선형 차수 검증을 대신하지 못한다. 이를 피하기 위해 모든 비동형 뿌리나무 조건을 확인했다. 잎을 \(\bullet\), 자식 나무를 \(\tau_j\)라 쓰고

\[
 |[\tau_1,\ldots,\tau_m]|=1+\sum_j|\tau_j|,\qquad
 \gamma(\tau)=|\tau|\prod_j\gamma(\tau_j),\qquad \gamma(\bullet)=1
\]

로 정의한다. 단계 가중치는 성분별 곱을 사용해

\[
 F(\bullet)=\mathbf1,\qquad
 F([\tau_1,\ldots,\tau_m])=
 \prod_{j=1}^m(AF(\tau_j))
\]

이다. 필요한 조건은 \(b^TF(\tau)=1/\gamma(\tau)\)이다.

이 조건과 Taylor 전개를 연결하면 다음과 같다. 같은 자식 나무의 중복 개수를 \(m_1,m_2,\ldots\)라 하고 \(\sigma(\bullet)=1\), \(\sigma([\tau_1,\ldots,\tau_m])=(\prod_r m_r!)\prod_j\sigma(\tau_j)\)를 정의한다. 원소 미분은 \(D_\bullet=f\), \(D_{[\tau_1,\ldots,\tau_m]}=f^{(m)}(D_{\tau_1},\ldots,D_{\tau_m})\)이다. 단계식을 Taylor 전개해 대입하면 수치해에서 나무 \(\tau\)가 곱하는 계수는 \(h^{|\tau|}b^TF(\tau)/\sigma(\tau)\)가 된다. 정확해의 미분 또는 적분식을 같은 방식으로 재귀 전개하면 계수는 \(h^{|\tau|}/(\sigma(\tau)\gamma(\tau))\)이다. 각 분기에서 Taylor의 중복 순열이 \(\sigma\)를, 시간 적분이 \(\gamma\)를 준다. 따라서 아래의 유리수 일치는 5차까지 모든 원소 미분의 계수를 일치시키며, 충분한 매끄러움 아래 나머지가 \(O(h^6)\)임을 뜻한다.

| 나무 차수 | 서로 다른 나무 수 | 주 방법 | 내장 방법 |
|---:|---:|---|---|
| 1 | 1 | 모두 일치 | 모두 일치 |
| 2 | 1 | 모두 일치 | 모두 일치 |
| 3 | 2 | 모두 일치 | 모두 일치 |
| 4 | 4 | 모두 일치 | 모두 일치 |
| 5 | 9 | 모두 일치 | 요구하지 않음 |

Wolfram과 Python `fractions.Fraction`으로 독립적으로 작성한 계산에서 주 방법 17개, 내장 방법 8개 조건이 정확히 일치했다. 또한 \(A\mathbf1=c\), \(a_{7,:}=b\), \(c_7=1\)을 확인했다. 비자율 문제는 \((t,y)'=(1,f(t,y))\)로 확장하면 같은 조건을 적용할 수 있다. 전체 나무, 분수 결과, 계수 배열 및 실행 코드는 `SYMBOLIC_CHECK.json`에 있다. 최초 Wolfram 실행에서 나타난 `MatrixPower` 관련 경고도 삭제하지 않았으며, 수정한 계산의 성공 결과를 별도로 보존했다.

## 4. 국소 정확도에서 전역 정확도로

**정리 1 — 조건부 5차 전역 정확도.** 유한 구간 \([t_0,T]\)에서 정확해와 모든 수치 단계가 포함되는 볼록 근방이 존재한다고 가정한다. 그 근방에서 \(f\)가 충분히 작은 단계에 대해 균일하게 \(C^6\)이고 필요한 도함수가 유계이며, 상태 변수에 대해 Lipschitz 연속이라고 하자. 단계는 \(h_n>0\), \(\sum h_n=T-t_0\), \(H=\max h_n\)을 만족한다고 하자. 정확 산술에서 DOPRI5의 전역 오차는 \(O(H^5)\)이다.

*증명.* 앞 절의 모든 5차 조건은 정확해에서 출발한 한 단계의 결함을 \(\|d_{n+1}\|\le C h_n^6\)으로 제한한다. 고정된 유한 단계 명시적 방법과 Lipschitz 우변에 대해, 충분히 작은 \(h_n\)에서 한 단계 사상의 Lipschitz 상수는 \(1+L_*h_n\)으로 제한할 수 있다. 따라서 초기 오차와 별도 교란 \(\delta_n\ge0\)을 포함하면

\[
 e_{n+1}\le(1+L_*h_n)e_n+C h_n^6+\delta_n.
\]

반복하고 \(\prod_n(1+L_*h_n)\le e^{L_*(T-t_0)}\), \(\sum h_n^6\le H^5(T-t_0)\)를 사용하면

\[
 e_N\le e^{L_*(T-t_0)}
 \left[e_0+C(T-t_0)H^5+\sum_n\delta_n\right].
\]

정확 산술과 정확 초기값에서는 \(e_0=0\), \(\delta_n=0\)이므로 결론을 얻는다. □

유한 정밀도에서 \(\delta_n\)에는 반올림, 부정확한 우변 및 외부 상태 변경이 포함된다. 이 결과는 강성 파라미터와 무관한 균일 오차 정리가 아니다. 도함수 상계나 안정성 상수가 커지면 실용적인 단계 크기도 작아질 수 있다. 비매끄러운 제한자, 충격, 모델 전환, 불연속 입력을 포함하는 문제에는 이 매끄러운 증명을 그대로 적용할 수 없다.

내장 방법은 4차이므로 일반적으로 \(\Delta=O(h^5)\)이다. 따라서 정규화 추정량

\[
 E=\left[\frac1n\sum_{j=1}^{n}
 \left(\frac{\Delta_j}
 {a_j+r\max(|y_{n,j}|,|y_{n+1,j}|)}\right)^2\right]^{1/2}
\]

의 점근적 크기 제어에는 \(h_{\mathrm{new}}\propto h E^{-1/5}\)를 쓴다. 주 방법의 국소 결함이 \(O(h^6)\)이라는 이유로 지수를 \(1/6\)으로 바꾸면 현재 추정식과 맞지 않는다. 실제 제어에는 안전 계수와 단계 증감 상한을 함께 둔다. 현재 구현은 성분별 절대 허용오차 \(a_j\), 공통 상대 허용오차 \(r\), 스케일된 제곱합을 사용한다.

여기서 \(E\le1\)은 국소 추정식에 따른 수락 조건이다. 특정 성분의 오차가 항상 허용오차 이하라는 뜻도, 전체 구간의 참오차가 지정 허용오차 이하라는 뜻도 아니다. 추정식의 선도 계수가 사라지거나 상쇄가 강하면 점근적 관계가 달라질 수 있다. 참조해, 단계 축소 실험, 성분별 오차와 물리적 불변량을 별도로 비교해야 한다. 특히 서로 다른 궤적을 하나의 큰 RMS 분모에 넣으면 하나의 실패를 희석할 수 있으므로 이번 ensemble 구현은 각 궤적의 제어기를 분리한다.

## 5. 정확한 연산량 감소와 재사용 계약

**정리 2 — FSAL의 우변 평가 횟수.** 우변이 한 적분 세션 동안 같은 결정론적 함수를 나타내고, 시작 도함수를 계산한 뒤 모든 시도가 일곱 단계까지 완료된다고 하자. 수락과 오차 거절을 합친 시도 수를 \(M\ge1\)이라 하면 우변 평가 수는

\[
 N_f=1+6M
\]

이다. 초기 단계 선택용 추가 계산, 조기 callback 실패 및 외부 출력 작업은 이 식의 범위 밖이다.

*증명.* 첫 시도는 7개의 우변을 계산한다. \(a_{7,:}=b\), \(c_7=1\)이므로 수락한 단계의 \(K_7\)은 정확히 다음 단계 시작점의 우변이다. 따라서 다음 시도는 2–7단계의 여섯 평가만 필요하다. 오차 거절에서는 시작 시각·상태가 그대로이므로 기존 \(K_1\)을 유지하고 바뀐 \(h\)로 2–7단계를 다시 구한다. 거절한 \(K_7\)을 시작 도함수로 사용하지 않는다. 이를 반복하면 \(7+6(M-1)=1+6M\)이다. □

모든 시도에서 새로 일곱 평가를 하는 구현과 비교하면 절약 횟수는 \(M-1\)이고, 장기적인 RHS 작업 비율은 \(6/7\)이다. 이것은 동일한 시도열에 대한 계산량 보장이다. 다른 적분법이 더 큰 단계를 선택한다면 전체 실행 시간 비교는 달라진다.

FSAL이 유효하려면 다음의 상태 동일성이 필요하다.

- 수락한 종점의 시각과 상태를 그대로 사용한다.
- 모델 파라미터와 우변 구현이 적분 중 몰래 바뀌지 않는다.
- 격자 재구성, 투영, 충돌 처리, 외부 강제 상태 변경 후에는 도함수를 새로 평가한다.
- 서로 다른 `step_into` 공개 호출 사이에는 숨은 FSAL을 넘기지 않는다.

현재 적분 세션은 내부에서 재사용하고, 공개 단일 시험 단계는 시작 도함수를 새로 계산한다. callback 실패를 포함한 실제 호출 수와 정상 완료 횟수는 별도로 센다. 따라서 실패한 실행에 기계적으로 \(1+6M\)을 대입해서는 안 된다.

**연산 복잡도.** 한 RHS 평가의 비용을 \(C_f(n)\)이라 하면 준비된 FSAL 시도는 \(6C_f(n)+O(n)\), 솔버 작업 메모리는 \(O(n)\)이다. 현재 커널은 일곱 기울기 벡터와 한 단계 상태 벡터를 한 번 할당하고, 종점·오차 버퍼는 드라이버가 보유한다. 관측값을 저장하는 메모리와 사용자 우변의 메모리는 별도이다. RHS 자체가 조밀한 상호작용을 계산하면 \(C_f(n)\)도 \(O(n^2)\) 이상일 수 있으므로 솔버가 전체 문제를 선형 시간으로 만든다고 주장할 수 없다.

비교 암묵적 경로의 한 시도 비용을 \(C_I(n)\), 명시적 경로를 \(C_E(n)\), 각 시도 수를 \(M_I,M_E\)라고 쓰면 비용 모델에서 이득의 조건은 \(M_EC_E<M_IC_I\)이다. 새 경로는 자코비안·인수분해 비용을 구조적으로 제거하지만 안정성 때문에 \(M_E\)가 커질 가능성이 있다. 그래서 단계당 시간과 전체 work–precision 곡선을 함께 측정해야 한다.

## 6. 안정성, 진동, 강성 판단의 한계

선형 시험 문제 \(y'=\lambda y\), \(z=h\lambda\)에 대한 주 방법의 안정성 다항식은

\[
 R(z)=1+z+\frac{z^2}{2}+\frac{z^3}{6}+\frac{z^4}{24}
       +\frac{z^5}{120}+\frac{z^6}{600}.
\]

음의 실수축에서 원점과 연결된 안정 구간은 대략 \([-3.3065678926,0]\)이다. 순허수축에서는

\[
 |R(ix)|^2-1=
 \frac{x^6(-200+225x^2-25x^4+x^6)}{360000},
\]

따라서 원점과 연결된 안정 구간의 반폭은 약 \(0.9971890086\)이다. 이 값들은 정확 다항식에서 수치적으로 구한 경계이며 임의 비선형 문제의 허용 단계 인증서가 아니다.

상수 정규 행렬 \(J\)의 선형 문제에서는 스펙트럼이 안정 영역 안에 있다는 조건으로 \(\|R(hJ)\|_2\le1\)을 얻을 수 있다. 비정규 행렬에서는 고유값만으로 과도 증폭이나 실제 오차를 제어할 수 없다. 빠른 진동 문제는 큰 음의 고유값이 없어도 위상 오차와 허수축 안정성 때문에 작은 단계가 필요하다. 따라서 `nonstiff`라는 이름만으로 DOPRI5가 빠르다고 분류하지 않는다.

기존 DOPRI5 계열에서 쓰는

\[
 h\,\frac{\|K_7-K_6\|}{\|Y_7-Y_6\|}
\]

형태의 진단은 특정 방향의 secant 정보이다. 이는 전체 자코비안 노름의 상계가 아니며, 작은 값이 숨은 강성 모드의 부재를 증명하지 않는다. 자동 전환을 추가하려면 이 통계, 반복 거절, 실제 오차 및 전환 비용을 함께 평가해야 한다. 이번 API는 사용자가 `Dopri5`를 명시적으로 선택하며 이 진단을 인증된 자동 선택기로 사용하지 않는다.

후속 혼합 적분기를 설계할 때에도 정확도 자체는 구성적으로 다룰 수 있다. 두 한 단계 방법이 같은 매끄러운 근방에서 각각 균일한 \(O(h^6)\) 결함과 \(1+L_*h\)의 안정성 상계를 갖고 수락한 상태에서만 전환한다면, 정리 1의 재귀식은 매 단계 어느 방법을 택해도 성립한다. 따라서 최대 단계에 대한 5차 전역 오차를 유지한다. 다만 이러한 균일 상계, 제어기 전환 및 캐시 무효화가 충족된다는 별도 검증이 필요하며, 이 정리는 현재 코드에 자동 전환이 구현되었다는 뜻이 아니다.

## 7. 순차 단계의 병렬 반복: 정확한 구성과 비용

### 7.1 유한 단계 회복과 차수 유지

원래의 명시적 단계 벡터를 \(K^*\)라고 하자. 모든 시작 추정값을 \(K_i^{(0)}=f(t_n,y_n)\)로 두고, 이전 반복의 값만 읽는 동기식 반복을 정의한다.

\[
 K_i^{(q+1)}=f\!\left(t_n+c_i h,
 y_n+h\sum_{j<i}a_{ij}K_j^{(q)}\right).
\]

각 반복 안에서 서로 다른 \(i\)의 우변 평가는 독립이다. 하지만 반복 사이에는 여전히 의존성이 있다.

**정리 3 — 삼각 구조에 따른 유한 회복.** 시작값의 첫 단계가 정확하면 \(q\)회의 반복 뒤 첫 \(q+1\)개 단계가 정확하다. 따라서 7단계 방법은 최대 6회의 반복으로 원래의 모든 단계를 회복한다. 시작 단계마저 임의 값이라면 최대 7회가 충분하다.

*증명.* 첫 단계는 이전 단계에 의존하지 않으므로 정확하다. 첫 \(q+1\)개 단계가 정확하다고 가정하면 다음 반복에서 \(q+2\)번째 단계는 이미 정확한 앞선 단계만 사용한다. 따라서 정확한 단계 접두부가 적어도 하나 늘어난다. 이 귀납법에는 수축 조건이 필요하지 않다. □

이는 유한 삼각 의존 구조에 대한 성질이다. 행렬 \(A\)가 nilpotent라는 사실만으로 비선형 반복 오차가 행렬 다항식과 같다고 가정하지 않는다.

**정리 4 — 네 번의 반복으로 5차 종점 유지.** 정리 1의 매끄러움 가정 아래 \(h\to0\)를 고려한다. \(K^{(0)}\)와 \(K^*\)의 차이는 \(O(h)\)이다. 우변의 상태 Lipschitz 상수를 \(L\), 단계 최대 노름에 대한 \(A\)의 유도 노름을 \(\|A\|\)라 하면

\[
 \|K^{(q)}-K^*\|
 \le (|h|L\|A\|)^q\|K^{(0)}-K^*\|
 =O(h^{q+1}).
\]

따라서 이 기울기로 구성한 주 종점과 원래 종점의 차이는 \(O(h^{q+2})\)이다. \(q=4\)이면 원래 방법의 \(O(h^6)\) 결함과 같은 크기이므로 5차 종점 정확도를 유지한다.

*증명.* 같은 단계 시각에서 두 상태를 평가하므로 Lipschitz 부등식으로 각 반복 오차가 최대 \(|h|L\|A\|\)배임을 얻는다. 유한 횟수 반복으로 이를 누적하면 첫 부등식이다. \(K_i^*-f(t_n,y_n)=O(h)\)는 시간·상태 매끄러움과 유한 계수로부터 나온다. 마지막에는 \(h\sum b_i(K_i^{(q)}-K_i^*)\)를 평가한다. 이 과정은 \(|h|L\|A\|<1\)이라는 반복 수렴 조건을 필요로 하지 않지만, 오차 상수는 \(L\)과 계수에 의존한다. 강성 파라미터와 무관한 균일 정확도나 큰 단계의 안정성을 보장하지 않는다. □

### 7.2 불필요한 갱신을 제거한 16단계 구성

주 종점에서 \(b_7=0\)임을 이용해 먼저 1–6단계만 네 번 반복한다. 정확해진 접두부는 다시 계산하지 않는다. 마지막에 주 종점의 우변을 새로 구해 내장 추정식과 FSAL에 사용한다.

```text
k1 = f(t, y)                         # 이전 수락 종점에서 재사용 가능
old[1..6] = k1
for q in 1..4:
    next = old                       # 이미 정확한 접두부 보존
    parallel for i in (q+1)..6:
        next[i] = f(t + c[i]*h,
                    y + h*sum(a[i,j]*old[j], j=1..i-1))
    old = next                       # 전체 batch가 끝난 뒤 교체
y5 = y + h*sum(b[i]*old[i], i=1..6)
k7 = f(t+h, y5)
err = h*(sum((b[i]-bhat[i])*old[i], i=1..6) - bhat[7]*k7)
```

첫 단계 1회, 반복별 5·4·3·2회, 마지막 1회를 합치면 최초 16회이고 FSAL 준비 후에는 15회이다. 원래 일곱 단계의 4회 반복을 그대로 구현하는 것보다 중복 계산을 줄인다. 이 식을 하나의 16단계 명시적 tableau로 펼쳤고, 주 방법의 17개 조건, 내장 방법의 8개 조건, \(A\mathbf1=c\), 마지막 행과 주 가중치의 일치를 모두 정확 유리수로 확인했다. Wolfram 구성 코드와 전체 16×16 유리수 배열은 `SYMBOLIC_CHECK.json`에 있다.

| 특성 | 원래 DOPRI5 | 네 번 반복한 후보 |
|---|---:|---:|
| 최초 완전한 시도 RHS 횟수 | 7 | 16 |
| 준비 후 완전한 시도 RHS 횟수 | 6 | 15 |
| 준비 후 순차 RHS 의존 깊이 | 6 | 5 |
| 한 batch의 최대 독립 RHS 수 | 1 | 5 |
| 주 방법/내장 방법 차수 | 5/4 | 5/4 |
| 이번 코드에 구현 | 예 | 아니오 |
| 이번 후보의 성능 실측 | 별도 실행 증거 참조 | 없음 |

**조건부 성능 결과.** 충분한 작업자가 있고 각 우변 비용이 같으며 batch 준비·동기화·메모리 비용을 무시할 수 있다면, 같은 수의 시도에서 RHS 지배 임계 경로는 6평가에서 5평가로 감소한다. 이 비용 모델에서만 이상적 시간 비율은 \(5/6\), 속도비는 \(6/5\)이다. 실제 총 작업은 2.5배이므로 우변이 저렴하거나 작업자가 적으면 느려질 수 있다. 두 방법의 안정성·오차 상수가 다르므로 같은 허용오차에서 같은 시도 수를 가진다고 가정할 수도 없다.

### 7.3 차수 유지와 안정성 유지가 다른 이유

구성한 16단계 후보의 주 안정성 다항식은

\[
 R_4(z)=\sum_{j=0}^{5}\frac{z^j}{j!}
\]

이다. 따라서

\[
 |R_4(ix)|^2-1=
 \frac{x^6(40-15x^2+x^4)}{14400}>0
\]

가

\[
 0<|x|<\sqrt{\frac{15-\sqrt{65}}2}
\]

에서 성립한다. 원점 근처의 비자명한 순허수축 수축 구간이 없다. 이 때문에 일반적인 무감쇠 진동 문제용 가속 방법으로 채택하지 않는다. 다만 작은 단계에서 증폭률이 1을 조금 초과한다는 사실이 \(h\to0\), 고정 시간 구간에서의 5차 수렴을 부정하지는 않는다. 한 단계의 초과 증폭이 \(O(h^6)\)이므로 고정 구간에 걸친 누적 효과는 \(O(h^5)\) 규모가 될 수 있다. 여기서 지적하는 문제는 유한 단계·장시간 진동에서의 안정성 및 보존 품질이다.

음의 실수축의 원점 연결 안정 구간은 대략 \([-3.2170478666,0]\)이다. 감쇠가 충분하고 우변이 비싼 비강성 문제라면 후속 실험의 가치가 있다. 다섯 번째 반복으로 주 종점에 필요한 원래 단계들을 모두 회복할 수 있지만, 종점 우변까지의 깊이는 다시 6이 되어 현재 DOPRI5 대비 RHS 의존 깊이 이득을 잃는다.

이 분석은 기존 병렬 반복 문헌을 현재 계수에 적용한 구성과 검증이다. 새로운 보편적 불가능성 정리나 병렬화 전반에 대한 부정적 결론이 아니다. Homotopy 매개변수 \(\eta\)로 \(A\)를 \(\eta A\)로 바꾸는 연속 경로도 만들 수 있지만, 여기서는 원래 명시적 계의 해를 직접 계산할 수 있으므로 continuation 단계의 추가 비용을 정당화해야 한다. 현재 구현의 기본 경로로 넣을 근거는 없다.

### 7.4 이번에 채택한 병렬화

단계 간 인과관계는 보존하면서 각 단계의 상태 성분 조합을 연속 배열 연산으로 처리한다. 이전 단계 벡터가 준비되면 서로 다른 성분의 axpy 조합은 독립이므로 컴파일러의 SIMD 벡터화 대상이 된다. 이는 특정 기계에서 SIMD 명령이 실제 생성되었다거나 벽시계 이득이 측정되었다는 뜻은 아니다. FMA나 합산 재배열은 반올림을 바꿀 수 있으므로 허용오차와 참오차로 비교한다.

독립 초기값 문제의 경우 각 궤적에 상태·FSAL·제어기·허용오차를 따로 두고 재사용 가능한 제한된 작업자 pool에서 병렬 실행한다. 이 방법은 원래 DOPRI5의 단계를 바꾸지 않으므로 위의 안정성 다항식도 바꾸지 않는다. 독립 궤적의 총 처리량 개선과 하나의 초기값 문제의 지연 시간 개선은 별도로 보고한다. 사용자 RHS 내부의 병렬화와 중첩되어 작업자를 과도하게 생성하지 않도록 해야 한다.

## 8. 확산·감쇠 문제를 위한 다항식 확장

일반적인 비강성 문제의 첫 구현으로 DOPRI5를 선택했지만, 실수 음의 스펙트럼이 지배하는 문제에는 다른 다항식이 유리하다. 다음은 특수한 선형 문제에서 계산 복잡도 감소를 직접 보이는 구성이다.

**정리 5 — Chebyshev 안정화의 안정성 비용 감소.** \(L=L^T\preceq0\), \(\sigma(L)\subset[-\rho,0]\)인 선형 문제 \(y'=Ly\)를 고려한다. 정수 \(s\ge1\)에 대해

\[
 P_s(z)=T_s\!\left(1+\frac{z}{s^2}\right)
\]

라 두면 \(P_s(0)=1\), \(P_s'(0)=1\)이고, \(h\rho\le2s^2\)이면 \(\|P_s(hL)\|_2\le1\)이다.

*증명.* \(T_s(1)=1\), \(T_s'(1)=s^2\)로 일관성이 성립한다. \(\lambda\in[-\rho,0]\)이면 가정 아래 \(1+h\lambda/s^2\in[-1,1]\)이고, 이 구간에서 \(|T_s|\le1\)이다. 대칭 행렬의 직교 대각화로 행렬 2-노름의 수축을 얻는다. □

계산은

\[
 w_0=y,\qquad w_1=(I+hL/s^2)y,
 \qquad w_j=2(I+hL/s^2)w_{j-1}-w_{j-2}
\]

의 세 벡터 재귀식으로 가능하며, 총 \(s\)회의 \(L\) 작용을 사용한다. 고정된 macro-step \(h\)를 안정하게 전진시키기 위해 명시적 Euler의 동일 분할에는 최소 \(\lceil h\rho/2\rceil\)회의 작용이 필요하지만, 이 구성은 \(s=\max(1,\lceil\sqrt{h\rho/2}\rceil)\)이면 충분하다. 즉 **안정성 제한만 비교하면** 작용 횟수가 \(O(h\rho)\)에서 \(O(\sqrt{h\rho})\)로 줄어든다.

이 다항식은 여기서 제시한 형태로는 1차 방법이다. 같은 전역 정확도에서 동일한 macro-step을 쓸 수 있다는 뜻은 아니다. 비정규 행렬, 비선형 우변, 양성 보존 및 진동 문제에도 이 수축 증명을 그대로 적용할 수 없다. 고차 RKC/ROCK 계열을 이식하려면 고차 조건과 감쇠 파라미터를 별도로 선택해야 한다. Laguerre 등 다른 다항식도 사용할 수 있으나 이름을 바꾸는 것만으로 안정 영역·차수·재귀 안정성·오차 추정식이 정해지지 않는다. 원하는 스펙트럼 영역과 목표 차수를 먼저 정하고 그 조건을 만족하는 다항식을 설계해야 한다.

따라서 향후 개발은 일반 비강성 경로에는 DOPRI5, 확산형 특수 경로에는 검증된 안정화 명시적 방법, 매우 높은 정확도에는 DOP853 또는 외삽법을 비교하는 방향이 적절하다. [Hairer의 원본 소프트웨어 목록](https://unige.ch/~hairer/software.html)은 DOP853·ODEX 및 DOPRI5의 연속 출력 차수를 구분한다. 이들 방법은 이번 코드에 구현되었다고 표시하지 않는다.

## 10. 다음 개발 단계와 판별 실험

이번 수학적 검증은 실행을 대신하지 않는다. 아래 실험은 NCP를 사용하지 않는 로컬 실행 캠페인으로 준비한다. 이미 게시된 과거 실험의 동일 항목을 무조건 반복하기보다 새 explicit 경로, 변경된 공통 부품 및 기존 실패와 연결되는 항목에 집중한다. 비교 구현은 사용자의 범위에 따라 VODE/DVODE, Diffsol, Julia 계열로 제한한다.

| 우선순위 | 다음 개발·실험 | 통과 기준과 실패 시 조치 |
|---|---|---|
| 1 | 비선형·시간 의존 문제의 단계 축소와 참조해 비교 | 충분한 점근 구간의 5차 종점 수렴, 실제 전역 오차 확인; 선형 시험만으로 통과 처리하지 않음 |
| 1 | FSAL·거절·실패 accounting | 정상 완전 시도에서 \(1+6M\), 조기 실패에서는 실제 callback 호출과 일치; 실패 상태가 수락 상태를 오염시키지 않음 |
| 1 | scalar 및 componentwise tolerance | 여러 크기 척도와 작은 성분을 포함해 참오차·불변량 확인; RMS 희석을 별도로 보고 |
| 1 | 넓은 work–precision 캠페인 | 정확도별 실제 오류, 성공률, RHS 수, 거절률, 시간·메모리를 함께 보고; 미도달 tolerance를 속도 승리로 세지 않음 |
| 2 | 비강성 성장·감쇠·비선형·진동·혼합 시간척도 | 안정 제한과 정확도 제한을 분리; 빠른 진동에서 위상·진폭·장시간 drift를 평가 |
| 2 | 독립 ensemble의 작업자 수별 처리량 | 1작업자 대비 속도와 효율, 궤적별 정확도 및 실패 보존; 하나의 IVP 가속으로 표현하지 않음 |
| 2 | 사건과 연속 출력 확장 | 별도 dense extension의 차수·사건 위치 오차·경계 처리를 검증한 뒤 API 확장 |
| 3 | 자동 방법 전환 | 전환 비용·히스테리시스·실패 복구·FSAL 무효화와 혼합 정확도 검증; secant 통계 하나로 인증하지 않음 |
| 3 | 비싼 RHS에 한정한 16단계 병렬 후보 | 기존 DOPRI5와 같은 실제 오차에서 총 작업·임계 경로·진동 품질 비교; 현재는 미구현 후보 |
| 3 | 확산형 안정화 다항식 | 고차 계수·오차 추정식·실수축 안정성·비정규 및 양성 문제의 범위를 먼저 확정 |

계측에는 최소한 문제 식별자, 방법·버전·빌드 옵션, 허용오차, 관측 시각, 참조해 출처와 정확도, 실제 오차, 성공/실패, RHS 호출 수, 거절 수, 벽시계 시간, 반복 수, CPU·작업자 수를 포함한다. 공정한 비교를 위해 동일한 관측 조건을 쓰고, 별도 보간을 제공하는 비교 솔버와 단계 착지를 하는 이번 경로의 비용 차이도 명시한다. 초기화와 컴파일 시간을 포함하는 비교와 정상 실행 시간을 비교하는 경우를 섞지 않는다.

이 문서의 연구 루프는 문제 설정, 기존 근거 확인, 형식화, 차수 증명, 연산량 증명, 안정성 감사, 병렬 대안 구성, 특수 다항식 구성, 코드 대응 확인, 후속 판별 실험의 열 단계로 완료했다. 재사용 가능한 정확 계산은 다음 두 파일에 보존한다.

- `SOURCES.json`: 문헌·도구·조회 범위·귀속·제외한 검색 결과.
- `SYMBOLIC_CHECK.json`: Wolfram 실행 입력·출력, 독립 Python 코드, 모든 뿌리나무 조건, 기본 7단계 및 후보 16단계의 정확 tableau.

Python 재검증은 다음처럼 기록에 포함된 원문을 추출해 수행할 수 있다. 이 과정은 Rust 실행이나 성능 측정이 아니다.

```bash
python - <<'PY'
import json
import pathlib
import subprocess
import sys
import tempfile

p = pathlib.Path('research/nonstiff_explicit_20261023/SYMBOLIC_CHECK.json')
record = json.loads(p.read_text())
with tempfile.TemporaryDirectory(prefix='vigilode-order-check-') as temp:
    script = pathlib.Path(temp) / 'check.py'
    script.write_text(record['python_source'])
    subprocess.run([sys.executable, str(script)], check=True)
PY
```

현재까지 증명한 것은 조건부 정확도, 특정 계약에서의 정확한 평가 횟수, 병렬 후보의 조건부 임계 경로 감소, 그리고 대칭 확산 문제의 안정성 비용 감소이다. 범용 성능 향상과 production 적격성은 위의 실행 증거로 판단해야 한다.
