# Fixed F6 slab-loop error-range argument

Scope: public `certify_trace_path` on the fixed registered grids and validated inputs, not arbitrary calls to private `propagate`. The analysis was derived against source `f52f908e4a1c4c4addbb7a30ee61a5eb8af6b7ca`; commit `36b175227b666117422cc044a7e88e6480b8b288` changes only the strict comparison spelling with independently reviewed identical NaN behavior. Further source changes must be checked before reuse. This is a conditional mathematical argument, not an all-path allocator measurement or broad production admission.

Assumptions: binary64 round-to-nearest with accurate FMA and gradual underflow, the existing outward arithmetic contract, the fixed clock, initial state, and entry checks in `trace_certificate.rs`. Preflight restricts N to 16,32,64,128,256, checks N+1 nodes, exact clock bits, finite state in [1/2,1]², exact initial state and initializes work counters. The function allocates its records before entering the slab loop and may allocate an error message after exiting; those costs are outside the loop and are not claimed to be zero.

For an interval endpoint magnitude bounded by 2^k with k>=0, use conservative exponent rules `add/sub=max(k1,k2)+2`, `mul=k1+k2+1`, and `div=k_num-d+1` when the divisor magnitude is at least 2^d. They include outward one-ulp rounding and subnormal movement. The integer script `f6_range_bound.py` applies these rules to the call graph and recorded exit 0. Bounds are deliberately loose: slopes <=2^35, Hermite coefficients <=2^42, original residual power coefficients <=2^154, residual Bernstein endpoints and delta <=2^189, path Bernstein endpoints <=2^61, delta/lambda <=2^191 and propagated endpoint <=2^194. Bounding TwoSum and FMA intermediates by 2^200 leaves ample distance below binary64 overflow. This is an integer abstract bound, not a measured residual or a tighter replacement for the exact Fraction oracle.

All denominators have explicit bounds: h=2/N lies in [2^-7,2^-3]; Bernstein binomial denominators are positive and their integer computations are exact; x=lambda*h=39/(32N) lies in [39/8192,39/512], so the T19 denominators are strictly positive and bounded. The degree graph is at most 15. The first incoming error is zero. At each completed slab, strict tube acceptance gives `whole < margin`; the first path Bernstein coefficient encloses the left endpoint in [1/2,1], hence `margin <= 1/4`, and the carried endpoint error is <1/4. A domain failure stops the loop. Counters start at zero, the finite fixed loops cannot approach integer overflow, and the records buffer has reserved N entries.

Under these assumptions, the fixed public path cannot reach an allocating interval arithmetic error in the slab loop; domain refusal is carried as an enum and formatted after the loop. This argument still needs independent review and validation of the floating-point environment. It says nothing about arbitrary E or delta supplied to a future generalized propagation API, FTZ/DAZ or arithmetic implementations outside the stated contract. Successful-path allocation tests and a reachable domain-refusal allocation test must be measured separately; absence of an exception under this proof is not itself an allocator receipt.
