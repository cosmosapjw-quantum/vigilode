# Phase 3 — Bounded design

Three options were considered: (A) immediately implement an adaptive nonlinear continuation solver; (B) implement a dense affine/reference oracle and structural kill screens; (C) create a generic sparse/matrix-free homotopy framework. Option B was selected because it closes signs, dimensions, nilpotent algebra, certification, and deterministic evidence with minimum scope. A and C are deferred until the oracle survives adversarial numerical experiments.
