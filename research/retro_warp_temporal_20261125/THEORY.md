R3. x_i=G_i x_(i-1)+b_i, x_-1 fixed. Period p, G_(i+p)=G_i. Ordered transfer T=G_(p-1)...G_0. q_j=sum_(l=0..p-1) G_(p-1)...G_(l+1)b_(jp+l), empty product identity. End state X_j=T X_(j-1)+q_j. Replace q_0 by q_0+T*x_-1 so polynomial equation (I-zT)X=Q mod z^m holds with X,Q of degree<m. Implementation computes q0 with actual initial state by forward period action, and q_j from zero for j>0. Original within-period nodes reconstructed from the previous spectral endpoint; last node of each period remains spectral candidate. Noncommuting G_i allowed; never permute their order.

R5. H_m(z)=sum_(k=0..m-1) z^k T^k. (I-zT)H_m=I-z^m T^m. Since m=2^L, binary expansion of k proves H_m=prod_(l=0..L-1)(I+z^(2^l)T^(2^l)). Powers of T commute although original G_i need not. H_mQ has degree<=2m-2; uniquely H_mQ=X+z^m Y, deg X,Y<m. For 0<alpha<=1, residues R_+=X+alpha Y and R_-=X-alpha Y in z^m=+alpha and -alpha. X=(R_++R_-)/2 and Y=(R_+-R_-)/(2alpha). Only X is needed. This is the return-factor-absorbed closure numerator, not a claim of inverse existence: P_sigma=I-S_sigma otimes T, S_sigma^m=sigma alpha I, P_sigma H_m(S_sigma)=I-sigma alpha I otimes T^m. In invertible cases H_m(S_sigma)=(I-sigma alpha T^m)P_sigma^-1 (block interpretation). Even at singular modal or return factor, H_m is a polynomial and reconstruction works. Test T=I,alpha=1; no inverse used. No actual shifted LU is constructed. At period scale, use T^(2^l) via repeated squaring, O(log m) matrices; include T^m for scan. No generic singular-operator solve claim.

For sign sigma, eta=alpha^(1/m)exp(i pi shift/m), shift 0 or 1. With forward negative-exponent DFT, transform eta^j q_j evaluates Q at z_k=eta exp(-2pi i k/m). Multiply by H_m(z_k) via dyadic factors; inverse and untwist by eta^-j. Real data conjugate partners k -> shift-k mod m. Evaluate one representative, fill partner conjugate, use exact cardinal phases for self partners. Full padded FFT length 2m uses alpha=1, shift=0 and only m H factors; full product fits, extract low m coefficients. Exact arithmetic, approximate binary64 FFT candidate validated separately. Scaling condition alpha^(-(m-1)/m); small alpha no longer needed for inverse avoidance or exact removal of wrap. Observed alpha=1 gives max manufactured CRT error 2.22e-16 vs 6.29e-14 at alpha=2^-12. Choose alpha=1 as initial candidate, not universal optimized alpha. Problem-independent TemporalTable caches phases, pairing and FFT plan for repeated use; no persisted offline byte table or use of previous continuous phi dictionary needed for a discrete recurrence.

R6. Error e_i=x_i-xhat_i, original residual r_i=b_i+G_i*xhat_(i-1)-xhat_i; hard IC e_-1=0. For local within-period residual radius l_j, l_-1=0 and l_j=|G_j|l_(j-1)+|r_j|. Exact ordered prefix P_j=G_j...G_0, |e_j|<=|P_j|E_in+l_j. Carry at period end; retain max at every original node. Form prefix matrices by outward interval multiplication of exact represented G, not rounded transfer/powers. Keeps signed cancellation: G0=[[1,8],[0,1]], G1=[[1/2,-4],[0,1/4]], G1G0=diag(1/2,1/4) but |G1||G0| upper-right=8. This is not an eigenvalue-only bound. Can be conservative for nonnormal or sign oscillations within periods, and overflow fails closed. Real-arithmetic target is discrete represented recurrence; no ODE truncation, representation, arbitrary callback, event or interior interpolation guarantee.

R7. Performance feedback: initial term-by-term directed residual/transport proof expensive. Preserve original as certify_directed. For n-vector row, sequential n+1 rounded operations (subtraction b-x, then n FMAs), u=2^-53, eta=MIN_POSITIVE conservative gradual-underflow additive floor. Under IEEE RN/ties-even with no overflow, |fl(a*b+c)-(a*b+c)| <= u|a*b+c|+eta. With k=n+1, gamma=k*u/(1-k*u), f=k*eta/(1-k*u), absolute residual enclosure |r|<=|rhat|+gamma*(|b|+|x|+sum|G_ij|*||xprev||inf)+f. The row sum is precomputed upward. For positive transport S=s0+sum a_j e_j, a_j,e_j,s0>=0, rounded FMA s_hat >= (1-ku)S-k eta; thus S<= (s_hat+k eta)/(1-ku) evaluated outward. Both denominators downward, numerator/gamma upward. Rounded candidate arithmetic never trusted. Code uses inherited arithmetic probes, checks finite intermediates via directed operations, no independent proof of core directed primitives. This reduces directed operations from per-entry to per-row; bounds are looser but same acceptance threshold. Independent exact Fraction audit of both implementations on 512 ordinary nodes (1024 components) and 64 scale nodes (128 components) incl subnormal and 2^+-500, wrong paths; no bound violations. 100-digit mpmath piecewise linear continuous oracle separately checks 128 nodes per mode; binary representation error distinct from certificate. Aperiodic extension: full represented causal system B with identity block diagonal, forecast B0 same shape with periodic pattern. Absorb actual first IC contribution in RHS. x_(k+1)=x_k+B0^-1(b-Bx_k). K=B0^-1(B0-B) strictly lower block triangular, K^N=0 for N original nodes, so exact arithmetic terminates in at most N corrections. Does not imply robust finite precision or speed. In infinity norm, nonnegative envelope v_0=0, v_i=|G_i^0|v_(i-1)+|G_i-G_i^0|1, i>=1, gives ||K||inf<=max_i||v_i||inf. If q<1 then error contraction and a posteriori error <=||B0^-1 r||/(1-q) in exact arithmetic. Can refine with period-prefix signed bounds. Independent NumPy 64-node 3-state test uses explicit H polynomial coefficients (not Rust dyadic) and actual original block residual. q<1 cases at amplitudes .01,.08,.25 converge in 5,9,15 updates to residual<1e-11; 1 and 2 amplitude (q>1) fail within cap 32, not a proof of divergence or exact-arithmetic impossibility. Preserve failures. Future target adjoint: q_k=c, q_(i-1)=G_i^T q_i gives c^T e_k=sum q_i^T r_i; generalizes Round04 output weights, not implemented controller here.
