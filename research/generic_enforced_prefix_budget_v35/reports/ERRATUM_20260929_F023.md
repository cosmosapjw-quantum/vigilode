# Erratum to the v3.5 fresh holdout verdict, 2026-09-29 (audit F-023)

This erratum is appended. It does not edit any sealed v3.5 file. The
recorded verdict `PASS_ENFORCED_PREFIX_BUDGET_FRESH_DISCRIMINATING_HOLDOUT` in
`results/RESULT_SUMMARY.json` stays as it was written.

## Reading after this erratum

**Survives, n_pos = 1, decided by the one-rank backoff.** The holdout is not
discriminating under the evidence standard below.

## Why

`tools/holdout_verdict.py --v35-holdout320` replays the N = 320 holdout rows
in `results/fresh_holdout320/`:

| Quantity | Value |
|---|---|
| eligible events (zeta34 defined, full E completed) | 28 |
| positives (self-estimate inadmissible) | 1: `hires-ramped`, step 4, zeta34 = 14.320, rank 14 of 28 |
| verdict at tau_final = 13.397 | PASS |
| verdict at tau_selected = 16.882 | FAIL |
| verdict one rank up from tau_final (tau = 14.320) | FAIL |
| verdict one rank down (tau = 7.753) | PASS |
| rule verdict | `INCONCLUSIVE_INSUFFICIENT_POSITIVES` |

tau_final is the calibration-optimal tau_selected moved back by one rank. The
only unsafe holdout event lies between the two, so the backoff alone decides
the pass. With zero misses among n positives the 95 % upper bound on the miss
rate is about 3/n; at n = 1 that bound is vacuous.

The one positive is labelled by the shadow's own error estimate
(`audit_full_e_total_error` = 1.135), not by a reference solution
(audit F-045). The agreement between that self-estimate and a
reference-anchored label is unmeasured on this holdout.

## Evidence standard from now on

A holdout verdict is called discriminating only if the holdout has at least
five reference-unsafe positives and the verdict is unchanged when the threshold
moves one distinct-score rank in either direction. Otherwise the verdict is
`INCONCLUSIVE_INSUFFICIENT_POSITIVES` or `INCONCLUSIVE_RANK_UNSTABLE`. The rule
is implemented in `tools/holdout_verdict.py` and tested in
`tools/test_holdout_verdict.py`.

## Not done

The N = 320 holdout was not rerun with the reference-anchored label that the
G4/S5B0 shadow rows now carry (`reference_local_error_wrms`,
`reference_unsafe`). The 2 x 2 table of self-estimate against reference
verdicts is still unknown. The holdout is consumed in any case: a new safety
claim needs a fresh holdout (docs/HOLDOUT_HYGIENE.md).
