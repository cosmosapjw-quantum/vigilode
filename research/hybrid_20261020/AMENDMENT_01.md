# Convergence before measurement: explicit structured-AD resolvent

The user explicitly permits AD at bottlenecks. The generated model has J=d*Delta-diag(lambda+alpha*m+2*epsilon*q)+u*v^T, u_i=alpha(1-q_i),v_i=1/N. Rather than sending this exact structure through expensive reduced dense8m solves, add an explicit O(N)-storage tridiagonal-plus-rank-one shifted resolvent. Local dual AD evaluates partial derivatives of the reaction graph with respect to q_i and m; known physical diffusion stays outside AD. A denominator guard and current full shifted residual remain. No full N-by-N Jacobian is formed. This is assembly-free/derivative-using, NOT the earlier strict derivative-free contract.

The raw-U RODAS endpoint using this resolvent is an additional protected candidate and has eight sequential linear solves; no new stage-parallel speedup is claimed for it. Existing all-at-once coupled eager/lazy paths are retained and measured separately. Auto selects exact packet only when epsilon=0 and the supported grid permits it; otherwise the structured-AD candidate. This finite structural selector is not a trained or globally optimal cost router.

All candidates use the same generated-model continuous defect/initial-radius/dense-output gate. A candidate method's finite precision and incomplete root solve enter the actual curve defect, not a duplicated ad hoc error sum. Cubic vs quintic is a same-candidate dense-curve ablation. Under IEEE arithmetic and the proof's model/domain hypotheses the radius is a conditional mathematical enclosure; independent rational replay and reference observations are separate checks.
