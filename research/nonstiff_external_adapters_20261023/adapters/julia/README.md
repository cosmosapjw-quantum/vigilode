# Julia comparator adapter

This adapter targets the unchanged model source `45037fc24e8f8101605f309e1fdb3a9a4e3df56d` and the frozen stdin/run schema. It uses Julia 1.12.7, OrdinaryDiffEqTsit5 2.1.5 (`Tsit5`) for nonstiff cases and large vectors, and OrdinaryDiffEqRosenbrock 2.7.5 (`Rodas5P`) for dimension-12 moderate/stiff controls. JSON3 1.14.3 and SciMLBase 3.58.0 are pinned by Project and Manifest. The environment has its own project and depot; no global Julia environment is changed.

`run.sh` receives one JSON stdin object and emits one JSON record. Set `VIGILODE_JULIA_DEPOT` and `VIGILODE_JULIA_EXECUTABLE` to relocate the installed environment. The launcher defaults to this campaign's isolated development depot and observed 1.12.7 executable. It pins one Julia/OpenBLAS thread and disables startup/history files. Package installation and precompilation must finish before benchmark execution.

Each process performs one full preparation solve for the identical case, dimension, method, tolerances, and step cap before starting its fresh measured solve. Its duration and success are recorded independently. Preparation does not supply state, counters or workspace to the timed solve. Campaign warmup remains an additional separate request. The 45-second subprocess cap covers imports, preparation/JIT, measured work and serialization.

Measured seconds include initial data and problem/workspace construction, callbacks, rejected work, integration and output collection. Reference calculation, error scoring and JSON serialization occur afterward. One adaptive solve saves five requested observations using package `saveat` interpolation; it does not restart at observations. The explicit path allocates stage storage proportional to state size. Only the dimension-12 stiff controls construct dense matrices; they supply an analytic diagonal Jacobian and retain the package's default Rodas5P linear solver and autodifferentiation configuration (the supplied Jacobian provides derivative values).

RHS attempted/completed and analytic Jacobian calls are counted by the adapter. Available package solver statistics are reported with their original field names; unavailable fields and allocation counts are null. No equivalence between package statistics and native WorkCounters is claimed. Failures preserve saved observations and the current integrator's last accepted state/time, plus incurred counters. A preallocated accepted-state/time snapshot is updated by an observation-only DiscreteCallback after each accepted step (`save_positions=(false,false)`, `u_modified!(false)`). It adds one O(n) buffer; all setup and per-step copy costs are inside the timer. Rejected candidates cannot overwrite this snapshot. Both preparation and measured solve must succeed for a successful record. Invalid requests fail before solving and return a nonzero status with diagnostics on stderr.

`test_adapter.py --frozen-protocol /path/to/nonstiff_explicit_20261023 --out /new/output` checks every family, both large-vector dimensions, rejected-first-step and accepted-last-step max-step failures and malformed request controls against the frozen independent Python scorer. These are development checks, not the benchmark campaign or scientific admission.
