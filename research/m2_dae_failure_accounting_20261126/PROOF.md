# Boundary-work accounting, not physical authority
Freeze the original source, numerical methods, tolerances, event decisions, charge policy and serialized physical receipts. AttemptCount records every normally returning Result at the named API boundary, whether Ok or Err; returned counts Ok, not necessarily qualified physical work. It does not promise panic recovery. ProjectionAttemptWork partitions RHS requests by eventual projection outcome and sums actual completed boundary RHS columns. For failed linear batch internals the completed subset is unavailable, so rhs_returned counts only successful whole batch/preconditioner returns; it is not a claim that no work was done in a failed kernel. Frozen and root boundary returns likewise do not count every exact arithmetic operation. Legacy InitWork remains unchanged and retained on successful reports. Audited initialization also exposes the reached legacy counters after refusal. Reconstruction aggregates each node before inspecting the result; failure of a subsequent node or coefficient operation cannot erase prior completed node work. Successful node work is not synonymous with committed physical authority.
NativeResourceAudit is an explicit opt-in, frozen diagnostic snapshot per native epoch. Initial source projection and repeated Mass initialization are recorded separately from point projections, scan and replay reconstruction nodes. WARP setup, driver invocation, certificate and guard-build boundaries are observed. Actual returned Stats are cloned from the driver, including unsuccessful Status and winner-less runs. If the facade has not called the driver API, native attempts are known zero. If the API was called but no Stats returned, attempts are unknown (None), never inferred zero; this can conservatively include a driver input refusal before its internal stepping began. No inference about hidden kernel arithmetic. Later user queries are outside the snapshot.
For atlas, every actual native request gets a distinct receipt with mode, source center, clock, route, offered quotas, return outcome, measured attempts and existing debit. Cache hit causes no native invocation; reset guard checks and negative outcomes are tracked separately from event commits. On returned native run, charged attempts are authentic Stats attempts and charged slabs accepted steps. On Err, existing full remaining native quota and requested scan quota are charged, even for known pre-driver zero. Do not refund budget or change control. With disjoint actual native receipts, sums of debit equal the old facade totals and sum of returned Stats attempts equals accepted plus rejected. Retained diagnostic counters convey no physical event/root authority. MultiGuardRun.native_stats() exposes actual returned Stats for all private trials, without selecting a winner. Audited Robertson shared/correlated first-guard/atlas and generic epoch are scoped here; separate independent multi-guard and conserved-chain reset/Picard/guard subkernel internals, failed LU/root/proof partial arithmetic, and missing native driver-internal Stats still unresolved. Existing default API does not automatically enable the atlas audit.
All boundary operations retain previous arithmetic order and authority; 192 old physical CELL records and 96 audited Atlas records independently compared to the published previous commit, including old work metadata; 360 component and 11 refusal logical records identical. Counts and allocations measured on actual native API. No holdout, walltime, peak-memory, full zeroallocation or formal ledger closure.
