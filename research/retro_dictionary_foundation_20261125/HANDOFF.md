## Use (Rust)

Enable vigilode feature "retro-dictionary"; re-exported namespace
vigilode::retro_research includes retro_dictionary, retro_foundation,
retro_portfolio, retro_green, retro_nonlinear, retro_temporal, retro_causal,
warp_cubic, shared_shift_jet, shared_shift_policy, complex_shift_jet,
affine_event_certificate, Fourier clients, ParallelExecution.
Library users may enable the lower crate feature independently. Default
production solver registry/routing unchanged.

Dictionary::get() returns a static immutable provider. Real interval APIs
phi/moment support directed, fast bounded, scaled and hybrid modes. Fast
real enclosure assumes the original source proof's arithmetic environment
(round-to-nearest/ties-even, gradual underflow and no unsupported compiler
fast-math). Integrator proof paths check the existing x86_64 arithmetic
probe; direct core dictionary use retains this stated precondition.
phi_all_fast/moments_all_fast evaluate all coefficients with packed lanes;
phi_batch_into/moment_batch_into provide bounded local pool evaluation into
caller storage. Full source files can be queried by sources().

Basis::green_weight uses a normalized clock; include physical scaling in the
declared input matrices/forcing rather than silently replacing time. All
Lagrange/Legendre/Gram/product/complex/ordered-word data are available in the
typed provider. Legendre normal-equation matrix and complex phi are candidate
utilities; scalar rational response has its own arithmetic enclosure, not a
guarantee of arbitrary IVP stability or accuracy.

RetroTable::with_dictionary(RealMode::...) and
Portfolio::green_dictionary_endpoint(...) explicitly connect the full provider
to the actual Green solver, including original residual. Legacy RetroTable::new
unchanged. PreparedRhs owns one matrix, its factors and scratch; matches()
checks exact shape and bits; prepare again when the actual matrix changes.
Its certificate uses strict row diagonal dominance. This sufficient
admission does not cover every invertible matrix. The adaptive method ranks
three already-prepared variants; fresh-factor is a direct benchmark option,
not an additional warm-cache route. A genuine cache across epochs/shifts is
a future extension of M3, not inferred from identical size.

TensorPencil uses axis-zero-fastest independent tensor monic reduction;
1..3 axes, degree 1..8 each, <=64 channels, center <=64, full block <=512,
<=16 nonconstant terms, exponent <=8, max 128 iterations. Each candidate
is checked against the exact represented quotient operator; conservative
strict inverse-gap admission required. It does not yet accept general
nonseparable ideals, prove arbitrary confluence, or give physical ODE error
for every stage pencil. One coefficient RHS per solve, repeated independent
RHS use the prepared owner. Aperiodic computes represented discrete
recurrence, not arbitrary nonlinear nonautonomous IVP. Ordered Picard
covers degree<=2 normalized-time generator and truncation through length
5; bound uses majorant M and tail exp(M)*M^6/6!, cap M<=8. Nilpotent Green
uses strict upper triangular structure and table basis limits; no numerical
nilpotence or Jordan decomposition is assumed.

## Evidence and limits

All ten raw sources migrated; typed computational consumers exist for each
family. Full general research algorithms are NOT all complete: complex
directed elementary functions, arbitrary nonseparable polynomial ideals,
general nonlinear least-squares slab solver, fully general nonautonomous
nonlinear integration and matrix/DAE mass constraints, transactional event
stop/reset/grazing, full shift/cache crossover across source epochs, and
external matched-error qualification remain open. No fallback is reported
as qualification if the original error contract fails. The full original
benchmark was not rerun this turn; 1,032 original rows and 2,076 expanded
fresh rows are retained. 12/14 disputed original references unchanged.

transaction and grazing contract, M2 consistent DAE initialization and

routes, M4 full dictionary applications and complex proof refinement (source

on the discrete/action primitives, M6 expanded competitors and matched error.
Use existing RESEARCH_PLAN and FOLLOWUP_ADDENDUM as authority, this foundation
is additive.
