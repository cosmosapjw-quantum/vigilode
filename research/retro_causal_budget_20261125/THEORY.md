# RETRO-WARP Round04: causal flow budget, signed endpoint and dense constraints
R1: Continue the seven-round research program from Round03 commit in BASE.txt. Goal: reduce actual native RODAS5P work without changing its formulas or lowering the declared global output-accuracy contract. Source-owned piecewise constant scalar affine IVP, no statistical learning. Other source classes remain open.
R2: Reuse retro_green::RetroTable (unchanged Round03 binary table projection plus directed fallbacks), native fast dense RODAS5P and affine_event_certificate. Literature: Lang & Verwer, SIAM J Sci Comput 2007, DOI 10.1137/050646950 (global control and tolerance proportionality); Cao & Petzold, SIAM J Sci Comput 2004, adjoint global error control; Tran & Berzins, UUSCI-2011-006, defect sampling. These are related methods, not an exhaustive priority/novelty audit. Wolfram verified affine flow ODE, stationary allocation and convexity; independent Python audit tests numerical scope.
R3: y_i=Phi_i(y_(i-1)), ytilde_i=Phitilde_i(ytilde_(i-1)); d_i=|Phitilde_i(ytilde_(i-1))-Phi_i(ytilde_(i-1))|. If Lip(Phi_i)<=G_i, E_i<=G_i E_(i-1)+d_i, hence E_k<=sum_(i<=k) d_i prod_(i<j<=k) G_j for exact initial state. The embedded local estimate is not d_i. For y'=-a_i y+b_i, exact represented constants a_i>0, exact represented endpoints, G_i=exp(-a_i H_i). For forecast a_hat and radius D, use lower bound max(0,a_hat-D), after verifying actual declared rate belongs to the uncertainty box. If out of box or enclosure ambiguous, all gains become 1. Forecast is not a future boundary value or generic callback inference.
R4: Three comparators: Forward (all gains=1, uniform budget), Uniform (checked forecast gains, uniform), Retro (same gains, nonuniform). All use identical native RODAS5P stage equations, local error estimator, retry and output certificate rules.
R5: For positive cost coefficients c_i, p>0, positive weights w_i, min sum c_i delta_i^(-1/p) subject to sum w_i delta_i<=eps has unique interior optimum delta_i=eps*c_i^(p/(p+1))*w_i^(-p/(p+1))/S, S=sum c_i^(p/(p+1))*w_i^(1/(p+1)), cost S^(1+1/p)*eps^(-1/p). Requires positive weights, no active caps. Zero weights may use cap. Uniform cost ratio for c_i=1 is m*(sum w_i)^(1/p)/S^(1+1/p). With multiple constraints W delta<=eps and cap L, dual gamma=W^T lambda, separable minimizer delta_i=min(L,(c_i/(p gamma_i))^(p/(p+1))) when gamma_i>0, else cap. Weak duality bounds optimum; SciPy dual is numerical diagnostic, not interval-certified optimum. Actual implementation p=4,c_i=1, 0.98 reserve, cap, minimum across each target's single-row proposal, cost-proxy uniform fallback and outward feasibility check. Not guaranteed optimal for multiple outputs and real native solver cost.
R6: Endpoint target at slab k uses weights prod_(i<j<=k) G_j, i<k, weight 1 at k. Dense target on entire slab k uses incoming weights prod_(i<j<k) G_j, i<k, weight 1 at k. Because the affine flow is nonexpansive, E_dense<=E_in+d_dense. These bounds are for exact-real dense polynomial; query roundoff is separate. Require final endpoint target. Local cap prevents arbitrarily relaxed early errors. No default tolerance reinterpretation.
R7: Signed residual identity. In normalized theta, r=U'+Ha U-Hb, e=U-y, e'=-Ha e+r. Thus e(1)=exp(-Ha)e(0)+sum_k r_k k! phi_(k+1)(-Ha) for polynomial residual. A bump e(theta)=A theta(1-theta) has residual A(1-2theta)+Ha A theta(1-theta), whose exponentially weighted integral is exactly zero (Wolfram verified); endpoint cancellation does not imply trajectory accuracy. Native implementation uses equivalent exact affine Green flow enclosure to compute local absolute endpoint error, NOT direct signed coefficient convolution. Dense checks reuse native quartic Bernstein defect and interval propagation with local incoming radius zero; global incoming radius then added. Original table not regenerated. Independent audit: 252 local/global endpoint pairs, 129 exact rational budget rows, all inside; worst endpoint error/bound 0.9999999996363848. Nonterminal monotone scalar event bracket sign verification, no crossing if certified endpoints same sign, unresolved if either endpoint unqualified, one unique crossing if opposite. Event time tolerance is qualified only if outward bracket width <= requested tolerance.
R8: Numerically checked dual proxy on five cases; heuristic/optimal-feasible cost <=1.001782 endpoint and <=1.032406 dense, numerical primal-dual relative gaps <=1.51e-9. Retain light heuristic. Real native work decreases in limited tested source-owned problem; actual global bound and achieved observation error can differ by orders of magnitude. Endpoint-only relaxation yields observed early error > final endpoint tolerance: correct for that contract, unacceptable for full trajectory. No claim of equal achieved error speedup or generic black-box forecasting.
