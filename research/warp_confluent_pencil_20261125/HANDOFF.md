## Mathematical and API contract
P=xi^3+p2 xi^2+p1 xi+p0 (ascending array), real exact binary64 inputs, dimensionless xi; caller must normalize D and B coefficients consistently. W=W0+xi D. CubicPencil borrows original matrices immutably; p coefficients retained by value. Require n=1..2048, finite real data, outward sum(abs(p))<=1, and a positive outward lower bound gap=alpha-beta, alpha=min row diagonal dominance of W0, beta=||D||inf. This is sufficient, not necessary; refusal does not assert singularity. Norm sum_{j=0}^2 ||X_j||inf. Multiplication by xi has induced norm <=1; triangle inequality gives ||W X mod P|| >= gap ||X||, hence a forward bound from the original coefficient residual. No claimed nonlinear/ODE error or root certificate. Evaluate returns rounded polynomial values (also at complex roots), not a verified root or evaluation enclosure.

K=-W0^-1 D. Triangular seed Y0=W0^-1 B0, Yj=W0^-1(Bj-D Y_{j-1}). Then (I+p2K+p1K^2+p0K^3)X2=Y2, X0=Y0-p0KX2, X1=Y1-p1KX2-p0K^2X2. Bounded folded Neumann correction only on X2, heuristic stopping based on contraction; final outward original coefficient certificate is sole acceptance authority. Exact confluence p=0 uses 3 solves, 2 matvecs. No explicit matrix inverse or K^m matrix. One center factorization per prepare and reusable LU scratch. All three independent RHS channels retained. Limit 64 updates; rejected reports still expose candidate, callers must inspect status. No automatic fallback in this primitive.

Residual certificate computes V_j=X_(j-1)-p_j X2 with FMA and encloses its rounding with Interval. Then each original row residual uses exactly 2n sequential FMAs. Assume IEEE round-to-nearest binary64 with gradual underflow; for finite exact FMA result error model relative u=2^-53 plus additive floor MIN_POSITIVE (loose, safe). Standard product propagation bounds rounding by gamma_(2n)(||B_j||inf+||W0||inf||X_j||inf+beta||Vhat_j||inf) + 2n MIN_POSITIVE/(1-2nu); add beta times V error, sum coefficient norms upward, divide by gap downward-enclosed. Existing directed arithmetic used. Nonfinite intermediates or bounds fail closed. This is a conservative certificate, not an independent audit of the entire directed arithmetic module or hardware floating point environment.
