# RODAS5P with a declared constant dissipative spectrum

The opt-in Rust type `vigilode::modal_rodas5p::ModalRodas5pStep` maps real modal amplitudes of a time-independent homogeneous ODE to a fixed-step endpoint and its signed RODAS5P embedded defect. The model must actually satisfy `dy_k/dt = lambda_k y_k`, with finite real `lambda_k <= 0`, positive step `h` and identity mass in the supplied coordinates. The method needs no Jacobian, stage solves or Newton iterations at runtime. Rates are model information supplied by the caller. Cache a transfer only while its spectrum and step size are identical. A Fourier pair's real and imaginary amplitudes can be supplied separately when they have the same real rate.

## Derivation

Fix one mode with unit initial amplitude and set `z = h lambda`, `x = gamma z/(1-gamma z)`, `p = 1/(1-gamma z) = 1+x`. The raw tableau equation takes the form

    U_i = x (1 + sum_{j<i} A_ij U_j) + gamma (1+x) sum_{j<i} C_ij U_j.
    R = 1 + sum_i b_code[i] U_i,    E = U_8.

Induction gives polynomials through degree eight. Linearity sends an arbitrary amplitude y to the pair (R y, E y). Contract the complete frozen decimal tableau with exact rationals, including its small high-degree and low-order residuals. The generator constructs both the x and p polynomials by an exact change of variables. When gamma z >= -1, |x| <= 1/2. Otherwise p < 1/2, and the exact constant terms of R(p) and E(p) vanish. Thus the stiff branch retains decay at large negative z without subtracting nearly equal unit terms. Estrin's evaluation groups independent terms. Each scalar pair is evaluated once per plan. After setup, all modes are independent and require two scalar products each. The current implementation is single-threaded, with contiguous-loop compiler optimizations. No benchmark claim for parallel OS threads follows from this construction.

V05 S2 already derived the stability function and its design-order cancellation in `research/production_loop_20261116/theory/THEORY.md`. This implementation reuses that result. Its additions are two numerically bounded charts for both outputs, source-based exact literal verification and measured setup/amortization. Earlier path-forest parallel scans operated within a stage linear solve. The present specialization eliminates the stage solves from the endpoint/embedded calculation altogether. For an autonomous homogeneous diagonal operator an exact exponential is also available and supplies both an independent reference and the relevant computational alternative. Utility here is reproduction of the RODAS5P endpoint/estimator on declared subproblems and controlled comparison of stage costs. Scientific priority and general-purpose speedup remain open.

For periodic constant-coefficient diffusion, the usual second-order Cartesian discretization gives `lambda_h = -4 kappa sum_i sin(pi k_i/N_i)^2 / dx_i^2`. On a continuum sphere of radius a, spherical harmonic coefficients decay with `lambda_l = -kappa l(l+1)/a^2`. Use the actual discretized eigenvalue for a finite-volume grid. A physical-space implementation must separately account for FFT/spherical transforms, basis accuracy and nonuniform weights. Supplied modal amplitudes eliminate the need to construct a basis here. A time-dependent eigenbasis contributes `-Q^(-1)Q' y_modal`; the executable two-mode rotating-basis counterexample measures the failed diagonal approximation. Coupled, forced, hidden or nonnormal operators, dense output and events use the appropriate protected driver. The embedded quantity is a vector. The adaptive entry point weights it in the declared modal coordinates; a physical pointwise tolerance requires the corresponding physical-space driver.

## Reproduction

From the repository root, run `python3 research/modal_transfer_20261124/check_modal.py .`, `cargo test -p vigilode --lib modal`, and `python3 research/modal_transfer_20261124/run_bench.py .`. The first command verifies SHA-256, regenerates the native coefficient literals, and independently replays the raw triangular stages in exact rational arithmetic on 293 real-axis arguments. The second exercises the native contract. The third builds a standalone optimized Rust binary and compares the implemented kernel with a scalar eight-stage raw recurrence and exact scalar exponentials. Every arm consumes the same initial amplitudes. Native raw and modal arms produce both outputs. The exact exponential produces one endpoint.

The numerical checks in `oracle.json` report maximum absolute errors with unit initial amplitude. The coarse 4-to-8 refinement shows a global reduction factor of 28.4 for the chosen z; 8-to-16 and 16-to-32 yield approximately 45.9 and 54.6. The benchmark in `bench.json` records per-call wall time, eleven rotated measurement blocks and a separate warm-up block. Rebuilding a plan and applying an already cached plan are different measurements. They are not a protected adaptive-driver, BDF or Radau comparison. Timing includes the native validation on all arms; raw and exponential cold arms trust the declared spectrum. A routed backend needs full-IVP comparison at matched achieved physical error on held-out inputs including transform and fallback costs.

## Adaptive integration and fallback

`VigilODE::solve_modal(ModalInput::Rates(&rates), (t0,t1), &amplitudes, &opts)` runs the adaptive endpoint kernel on its declared class. It uses the existing represented-time `AdaptiveOutputSession`, signed error vector, scalar/vector tolerance scale, zero-scale WRMS rule and `rodas_next_step_after_attempt` controller. Trial output remains separate until acceptance. An exhausted attempt budget returns the last accepted state and both counts. A dense-output request or a growing mode constructs the same diagonal ODE and invokes protected RODAS5P; `ModalInput::General(&problem)` invokes it directly with the given physical coordinates. See `adaptive_modal.rs` for executed parity, rejection and fallback tests. The signed embedded difference is the method's error estimate and does not bound every true modal error. The homogeneous exact exponential is available for testing.

On the documented single-thread run with 16,384 modes the checked native setup-plus-application took 127.86 microseconds against 108.27 for the raw tableau, and 220.63 for a newly formed exponential multiplier. With cached factors those medians became 10.83, 10.96 and 6.46 microseconds respectively. Reducing the stage dependence did not establish a wall-time advantage against the optimized raw recurrence. The cached exponential is both accurate to rounding and faster on this input. This is an opt-in parity and scientific-control kernel. It does not meet a general speed-based default promotion gate.

## Whole-IVP comparison on the declared class

The release example `cargo run --release -p vigilode --example modal_work_precision` compares the adaptive driver with ordinary protected RODAS5P supplied its exact diagonal band Jacobian, and the analytic homogeneous exponential. For each dimension (64, 512), each of three tolerances, and five timed repetitions following warm-up, the native arms rotate order. The reference is the closed-form endpoint at t = 0.5 for `lambda_k=-1000(k/(n-1))^2`, `y_k(0)=1/(1+0.0001 k^2)`. The closed-exp arm computes the same rounded expression as the reference; its zero measured difference is expected. The nonzero coordinate profile and spread of rates are chosen, so these are manufactured modal tests. `scipy_baselines.py` independently runs BDF and Radau with exact sparse diagonal Jacobians, matching tolerance, initial step and terminal time. Raw samples are in `adaptive_native.csv` and `adaptive_scipy.csv`. Run `python3 research/modal_transfer_20261124/summarize_work.py` to group by a common achieved error threshold. The desktop used a 12-core Ryzen 9 5900X and Rust 1.94.1, with competing workloads (1-minute load average sampled after the run was 48.06 on 24 logical CPUs); absolute timings and cross-runtime rankings are exploratory.

At a maximum absolute endpoint error budget of 1e-8 on 512 modes, the fastest measured eligible native calls took 325.58 microseconds for adaptive modal RODAS5P and 1859.12 for protected RODAS5P. Both achieved a maximum error of 5.53e-9. The analytic flow took 3.95 microseconds. At a budget of 1e-10, the native RODAS5P medians were 703.11 and 4250.42 microseconds at achieved error 6.84e-11. Protected and modal RODAS5P chose the same accepted and rejected step counts in every one of the six measured configurations. These scoped whole-IVP results include the adaptive loop, whereas the setup microbenchmark compares two already specialized scalar implementations. Universal speed superiority, physical-space transform costs, and BDF/Radau competitiveness across general stiff systems remain open.
