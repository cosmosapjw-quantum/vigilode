Question (PLAN.json KS-N8, THEORY.md 8): for non-normal J (advection-diffusion with ring-constant velocity
on the sphere grid of crates/vigilode/src/spatial.rs), what replaces the inertia certificate (THEORY 4.2),
the contractivity bound (5.1) and the Gershgorin spectral/stiffness bound (5.2-5.3)?

1. Operator (to be derived in THEORY.md 10.1; the code has no advection term, it is defined here on the
   code's grid: same ring areas A_r, rates n_r, s_r, a_r, face lengths)
   - Ring-constant (axisymmetric) velocity: zonal speed u_r at ring centres, meridional speed v_{r+1/2} on
     the latitude faces. Flux form (conservative, the same finite-volume form as the diffusion).
     Zonal face flux b_r = u_r R dtheta / A_r (rate units), meridional face flux f_{r+1/2} = v ell_{r+1/2}
     with ell_{r+1/2} = R sin(theta_{r+1/2}) dphi (zero at the polar faces).
   - Primary scheme: centred face values. Reasons: second order; for divergence-free flow it is
     A-skew-adjoint, so the non-normality is undamped (the hard case for any certificate) and the
     A-Hermitian part is exactly the diffusion operator of 4.2. Secondary: first-order upwind, which is
     centred plus an A-self-adjoint negative semidefinite artificial diffusion (lemma to prove), so every
     Hermitian-part bound of the centred scheme carries over.
   - Lemma to prove: on this grid a ring-constant velocity field is discretely divergence-free iff all
     meridional face fluxes vanish, i.e. divergence-free ring-constant flow is purely zonal.
   - Mode blocks: B_m = L_m + cI + Z_m + V, Z_m = diag(-i b_r sin theta_m) (centred),
     V = A^{-1} G (meridional, independent of m), tridiagonal, non-Hermitian.

2. Certificate (to be proven, statuses D / I)
   - Work in the area inner product <u,v>_A (the norm in which diffusion is self-adjoint); the DFT along
     rings is unitary in it, so W_A(J) = conv(union_m W(Bt_m)), Bt_m = Ahat B_m Ahat^{-1}, Ahat = diag(sqrt A_r).
   - mu_A(J) = max_m lambda_max(Ht_m), Ht_m = (Bt_m + Bt_m^*)/2 real symmetric tridiagonal.
   - Hermitian-part inertia certificate: #{non-positive Thomas pivots of zI - Ht_m over modes (multiplicity 2
     for 0 < m < np/2)} = #{eigenvalues of the A-Hermitian part of J at or above z} (Sylvester);
     zero <=> z > mu_A(J). Reduces to 4.2 when the velocity is zero.
   - z > mu_A(J) => W(z) invertible, ||W(z)^{-1}||_A <= 1/(z - mu_A(J)) (log-norm lemma); Euclidean variant
     with mu_2 as in the task text; Thomas without pivoting on the complex blocks W_m is defined with
     Re(pivot) > 0 (Schur complements of accretive matrices are accretive).
   - Contractivity: ||exp(tJ)||_A <= exp(t mu_A) (Dahlquist); ||R(hJ)||_A <= sup_{Re w <= h mu_A} |R(w)|
     for A-stable R whose poles lie right of h mu_A (von Neumann, Hairer-Wanner II Thm IV.11.2); for
     RODAS5P the pole condition is z = 1/(h gamma) > mu_A, the same condition as the certificate.
   - Zonal case: mu_A(J) = c exactly (centred and upwind). Divergent meridional flow:
     mu_A <= c + max_r(-div_r)/2 (Weyl), exact value by bisection on the pivot count.
   - Spectral/stiffness enclosure (Gershgorin replacement): spec J subset union_m P_m where P_m is the
     polygon of K supporting half-planes Re(e^{-i phi_k} w) <= lambda_max(Herm(e^{-i phi_k} Bt_m)),
     K = 64 (multiple of 4, so it contains the Bendixson box directions).
