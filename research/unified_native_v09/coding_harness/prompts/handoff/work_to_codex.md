# Work → Codex handoff

현재 연구 자료를 바탕으로 다음 파일을 만든다:

1. `CODE_TASK.md`: outcome, scientific purpose, in/out scope, acceptance, approvals
2. `SCIENTIFIC_CONTRACT.md`: conventions, invariants, limits, references, tolerances, failure semantics
3. `VALIDATION_MATRIX.md`: software, scientific, numerical, reproducibility checks

구현 세부사항을 임의로 고정하지 말고 과학적·기능적 계약과 검증 기준에 집중한다.
