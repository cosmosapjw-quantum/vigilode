# Research Code Task

1. Read `AGENTS.md`, `SCIENTIFIC_CONTRACT.md`, `VALIDATION_MATRIX.md`, and relevant code/tests.
2. Define task type, outcome, scope, preserved behavior, acceptance/reproduction, approvals, completion bar.
3. Reproduce or lock the baseline before editing.
4. Localize the execution/data/units flow.
5. Compare at most three substantively different solutions and select the smallest sufficient one.
6. Implement a coherent patch with tests.
7. Run software, scientific, numerical, and reproducibility checks as applicable.
8. Perform an independent review pass.
9. Update plans, matrix, state, and logs.
