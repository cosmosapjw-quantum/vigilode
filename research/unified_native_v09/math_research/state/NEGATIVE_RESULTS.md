# NEGATIVE_RESULTS

## N-001 — One-correction output certificate

ATTEMPT: Accept nonlinear stage candidates using a first Newton/output correction.

RESULT: Previous holdout corpus showed severe underestimation and false acceptance under stronger policies.

WHAT_IT_RULES_OUT: Calling the correction a rigorous bound or repairing it by threshold scaling alone.

REVISIT: Only as an operational diagnostic within a conservative two-level scheme.

## N-002 — Equal-tolerance universal ranking

RESULT: Method-specific error estimators and controllers do not map a common input tolerance to common global error.

WHAT_IT RULES OUT: Authoritative ranking by wall time at one shared input tolerance.

## N-003 — All-family single-cycle implementation

RESULT: Variable BDF, SDC, Peer, ROK/BOROK and Leja have independent mathematical state and capability contracts.

WHAT_IT RULES OUT: A credible one-commit implementation of every deferred family.
