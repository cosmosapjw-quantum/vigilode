# Research Loop — Ultralight 5.6

## Outcome

이미 누적된 context를 바탕으로, **맥락 정리 → 제한된 발산 → 메타인지 수렴 → 독립 verifier → 최소 검증 설계**를 한 번에 수행하고 다음 한 걸음을 결정한다.

## Instructions

1. 현재 context에서 핵심 thread 3–5개와 중심 질문 1개를 추출한다.
2. 관련 문헌 계보 최대 3개, 중심 가설 variant 최대 5개, 강한 대안가설 최대 3개만 제시한다.
3. 표현만 다른 후보를 병합한다.
4. 다음 기준으로 수렴한다: falsifiability, baseline contrast, assumption burden, tractability, physical payoff, overformalization risk.
5. 상위 후보 2개에만 독립 verifier를 적용한다: evidence support, known limit, 물리·수학 정합성, 대안설명, 실제 구분 가능성.
6. 후보를 `PASS / CONCERN / FAIL`로 표시한다.
7. PASS 또는 CONCERN 후보마다 문헌 확인 1개, toy check 1개, kill criterion 1개, next action 1개를 제시한다.
8. formalization은 금지한다.

## Output

- 핵심 thread와 중심 질문
- 제한된 후보 공간
- 수렴 결과
- verifier 결과
- 최소 검증 패키지
- 지금 하지 말아야 할 formalization
