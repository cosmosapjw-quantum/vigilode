# Example run — generic physics hypothesis

## Input

- Existing context: a proposed effective description appears to improve one observable but may merely reparameterize a known model.
- Goal: decide whether it deserves a full derivation.

## Recommended path

1. Run `prompts/quick/ultralight.md`.
2. Add 2–3 primary sources to `EVIDENCE_LEDGER`.
3. Run claim–source audit.
4. Keep at most two serious hypotheses.
5. Run independent adversarial review.
6. Design one toy limit and one discriminating observable.
7. Only after `PROMOTE` create notation and paper outline.
