# Exact linear Sturm lattice with preserved legacy receipts
RepresentedPolynomial owns exact binary64-as-rational coefficients and an exact affine clock. The fast path is selected only after exact trimming and only for degree one, after the same arithmetic environment, tolerance, zero polynomial, optional Bernstein/Dictionary screen, square-free factorization and actual Sturm-chain construction as the legacy path. In degree one companion_hints returns no hint and no eigenvalue attempt. Higher degrees, constant/zero/refusal paths remain generic.
Write p(theta)=a(theta-r), a != 0, r=-p0/p1 in Q. The normalized degree-one Sturm chain has first term with sign sign(a)sign(theta-r), second with sign sign(a); ignoring zero, its variation is exactly 1 if theta<r and 0 otherwise. Therefore V(l)-V(h) is the original count in (l,h]. Root 0 excluded, root 1 included, signs/multiplicity unchanged; initializer still rejects either physical branch boundary if its original interval source check cannot exclude zero. For initial partitions [0,1], [0,1/2], [1/2,1], every legacy bisection endpoint prior to stop is representable on lattice k/2^51: target tol/2 >=2^-51, width halves exactly, stop occurs at right endpoint root or width <= target. Compute integer floor of 2^51*r once in rational arithmetic, with exact integer equality flag; roots outside [0,1] have ordered sentinel positions. Then V(k/2^51) iff k<floor or k==floor and noninteger. This is exact comparison, not a floating root estimate. Dyadic width comparison is exact binary64 since k<=2^51. Validate initial partition identity and even split; fallback to original generic algorithm for unsupported partition. Each evaluated variation and each visited isolation node is actually executed and counted, and the actual generic chain and screens execute. Counters remain actual algorithm-level events, not estimates of BigRational operations; no fake skipped-work debit. All terminal endpoints converted to the same exact rationals and projected by original iv() on theta and affine clock, same width check and kind from sign(a). At most one distinct root in disjoint parts, so same result and aggregate counts despite processing part count in reverse before each traversal. Generic code retained via private isolate_impl flag and used in tests. No changes to algebraic source composition, physical branch proof, derivative conditioning, Newton center polishing, tolerances or facade.
Separate isolate_affine_exact diagnostic returns exact singleton theta rational and outward theta/clock enclosure for exactly degree one; different representation from dyadic bracket, no claimed screen/Sturm counts. It is NOT used by ScalarRoot initialization or automatic route selection; using it there could change accepted numerical centers and proof receipts. All higher-degree/zero/constant inputs refuse diagnostic. No new general physical authority, no claim of zero allocation (rational setup, screen, chain and report still allocate), no timing or peak memory authority. Legacy root report and actual native physical identity independently checked. Local root/initialization comparisons are not fictitious complete-chain variants.
