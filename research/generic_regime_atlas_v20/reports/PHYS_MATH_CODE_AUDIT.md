## P1 code risks

1. Full R-JF timing always precedes E-K timing. Repeated campaigns and a large wall gap make
   the continuation verdict robust, but final speed ranking needs randomized/order-reversed timing.
2. Full-step timing is one-shot per state. Campaign medians are acceptable for the atlas but not
   the final performance authority.
3. Replicated blocks may underrepresent sparse cache/preconditioner behavior of genuinely coupled
   large systems.
4. The nonautonomous-forcing family is a regime probe, not a manufactured exact-solution test.

## Regression protection

- focused smoke tests require six families, read-only operation, and zero explicit-J/factorization;
- BDF/Radau hashes match their G0 frozen values;
- seven campaigns have exact scientific/work identity;
- no physical-client binding appears in the new production module.

## Verdict

The new code is a valid paired-regime telemetry layer. It is not yet an active polyalgorithm or a
canonical benchmark suite.
