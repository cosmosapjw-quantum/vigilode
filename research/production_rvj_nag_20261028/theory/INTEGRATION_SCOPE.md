# Integration of the admitted local mathematics

This parent synthesis is theory work, before new runtime execution. The original
target is a finite, explicitly defined physical model and requested observable.
The general polyalgorithm remains a selector of independently admissible routes.

## 1. Common target precedes common cost

PR94's physical-flow induction applies to a realized sequence of accepted
candidates. Each route must enclose its defect relative to the same original
flow, physical norm, represented checkpoint, clock and observation schedule.
No regularity of the selector is required. It does not follow that two routes
with different observable semantics are interchangeable.

The cyclic small-real closure and the all-complex-root quotient trace therefore
have separate model/observable identities. Trace elimination is admissible only
when the client actually requests the full multiplicity-weighted polynomial
observable. A selected physical branch cannot silently be replaced by its sum
with other real or complex branches. The finite monic quartic quotient has rank
four even at repeated roots; the unresolved F5 global collision count is not
an input to that identity.

For a fixed admissible target, charge

    C_total = C_session + C_candidate + C_certificate + C_commit.

Endpoint preparation and all discarded probes belong in these terms exactly
once. Shared certification can change the fastest candidate ranking. Historical
F23 timing is evidence of this effect, not a timing forecast on this host.

## 2. An exact scan formulation, without premature threading

For the cyclic tangent relation v_i = f_i - b_i v_(i+1), let
T_i(z) = a_i + c_i z, a_i=f_i, c_i=-b_i. Represent an affine map by (a,c).
Composition is

    (a,c) o (d,e) = (a+c*d, c*e).

Associativity follows by expanding both parenthesizations into
(a+c*d+c*e*g, c*e*k). A cyclic composition has the form A+C*z, hence its
fixed point is A/(1-C). On the declared box, |C| <= (1/8)^n < 1.
A balanced prefix/suffix scan therefore provides O(n) arithmetic work and
O(log n) span in exact arithmetic. The serial recurrence already has O(n)
work and low storage, and remains the strong baseline for n=4,8,16.

Parallel reassociation changes floating rounding and may widen interval
enclosures. An implementation must use outward composition or supply a bound
on the original residual v_i+b_i*v_(i+1)-f_i, then apply the same inverse bound
8/7. Scheduling, synchronization, workspace and discarded work must be charged.
This result does not parallelize arbitrary nonlinear RK stages and is not a
new measured parallel speed result. Native parallel scan is deferred to the
existing N05 work/span gate until a measured full-cost crossover warrants it.

## 3. Polynomial alternatives keep their prior admission requirements

The PR93/94 Chebyshev, Laguerre, finite causal and quotient-algebra constructions
are retained. A real symmetric interval can justify a Chebyshev minimax bound;
eigenvalues alone do not control a nonnormal matrix function. A Laguerre/Leja
action still needs its domain, degree/tail, rounding and original-action
certificate. Finite structural quotient identities can remove iteration only
on the declared algebra. None supplies a whole ODE error merely by returning a
small projected residual. Selective supplied JVP/AD remains an explicit option
for cases where the admitted derivative-free route fails or is more expensive.

The present coding target removes root enumeration/iteration for two admitted
structured clients and reduces their certificate work. It does not disable
Krylov or change the default dispatcher. Generic routing, residence guarantees,
owned continuation and the six N tasks retain their existing completion gates.

## 4. PR95 is a future real-client remainder leaf

For its pinned chemical source and frozen coefficients,
F(z)=b+Pz+(e^T z)Qz implies

    J(z)=P+(e^T z)Q+(Qz)e^T,
    F(z+d)-F(z)-J(z)d=(e^T d)Qd.

Thus a fixed-norm bound Gamma yields Gamma*rho^2; a different carrier J0
requires an additional verified ||J(z)-J0||*rho. This can feed the PR94
near-affine causal theorem. Omitting electron feedback is a model error, not
an optimization. Rate/clock enclosures, omitted geometry blocks, full-state
norm/lift and callback rounding remain separate obligations. No actual-model
native qualification is inferred from the conditional six-variable identity.

## 5. Exact constants versus chosen resources

Contraction 1/8, inverse/root factor 8/7, dissipation 6/7, cubic endpoint
factor 3/4 and the trace lognorm bound are derived mathematical constants.
The user accuracy cap is a requested physical contract. Grid candidates,
repeat counts, test fixtures, timeouts and memory limits are declared finite
experimental/resource choices. They are not mathematical safety factors.
The first passing grid in a finite menu is not a globally minimal grid.

New physical certificates must include finite representation/rounding and
the exact reconstruction they certify. A proof for exact-field Hermite slopes
does not automatically cover an unrelated rounded dense interpolant.
