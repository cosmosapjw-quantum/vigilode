## Hypotheses

  client can be traced to exact artifact bytes and coupled to the reusable
  transactional API. Existing prose, demos, or unrelated equations falsify
  this hypothesis for an already-existing client.
- **H2 — independent reference:** a distinct implementation path produces a
  reference with a defensible asserted uncertainty upper bound. Empirical
  agreement or an uncontrolled floating-point value is insufficient.
- **H3 — independent budgets:** output-L2, embedded-error,
  original-target-residual, and contraction budgets can all be frozen before
  observing a candidate. A value widened after a miss falsifies admission.
- **H4 — canonical operator and PC:** frozen-W serialization, ordering,
  precision, digest, and a nonidentity diagonal preconditioner can be specified
  without candidate-dependent data.
