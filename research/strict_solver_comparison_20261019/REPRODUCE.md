# Reproduction and immutable readback

Run these in a fresh clone/worktree, not in a concurrent solver development tree. Commands below correspond to the executed build/readback paths. The manual command block itself is documentation, not a new host benchmark.

## 1. Verify saved results without new integrations

Use a checkout containing this node and its saved run directories. Install Python 3.13, NumPy2.3.5, Matplotlib3.10.7 in an isolated environment. From repository root:

```bash
python3 -m venv /tmp/vigilode-readback-env
source /tmp/vigilode-readback-env/bin/activate
python3 -m pip install 'numpy==2.3.5' 'matplotlib==3.10.7'
NODE=research/strict_solver_comparison_20261019
(cd "$NODE/refined_runs/39261895983" && sha256sum --check SHA256SUMS)
# Destination is a NEW directory; never overwrite a historical run.
python3 "$NODE/postprocess/readback.py" /tmp/vigilode-frozen-readback-new
```

Expected scope: no solver execution, exact original source hashes, 270 calibration +408 timing rows, 189 unique full-state objects, 42 recomputed paired medians. The original exact-initial-bit gate remains FAIL_PRESERVED; the explicit floating consistency gate and unchanged error calculations are reported separately.

The auditor source from refinement/audit.py is retained unchanged and hash-checked; the readback emits the exact executed version and an explicit one-assertion change receipt. Editing that source invalidates this strict replay.

## 2. A NEW numerical run from the actual measured source

A new run is scientifically reproducible but its time samples, host identity and binary hash will not necessarily equal the historical ones. Capture a new manifest and do not append new observations to an old run directory.

```bash
git fetch origin research/benchmark-results-20261019-dual
git worktree add --detach /tmp/vigilode-matched-source 9c6a6d9145795e35b978652a567b806ddc84a6bd
cd /tmp/vigilode-matched-source
NODE=$PWD/research/strict_solver_comparison_20261019
PREVIOUS=$NODE/runs/39257390707
# Ubuntu 24.04 packages: gfortran (recorded version13.3.0), libblas-dev.
# Provision them under your normal system policy before building.
rustup toolchain install 1.94.1 --profile minimal
python3 -m venv /tmp/vigilode-run-env
source /tmp/vigilode-run-env/bin/activate
python3 -m pip install 'numpy==2.3.5' 'scipy==1.16.3' 'matplotlib==3.10.7'
cp "$PREVIOUS/Cargo.lock" "$NODE/Cargo.lock"
export STRICT_VODE_SOURCE="$PREVIOUS/sources"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 RAYON_NUM_THREADS=1
(cd "$STRICT_VODE_SOURCE" && sha256sum --check ../NETLIB_SHA256SUMS)
cargo +1.94.1 build --manifest-path "$NODE/Cargo.toml" --profile measurement --locked -j2
cargo +1.94.1 test --manifest-path "$NODE/Cargo.toml" --profile measurement --locked -j2 -- --test-threads=1
OUT=/tmp/vigilode-new-matched-run
mkdir "$OUT"
{ date -u; uname -a; lscpu; rustc +1.94.1 -Vv; gfortran --version; python3 -m pip freeze; git rev-parse HEAD; } > "$OUT/host.txt"
CPU=$(python3 -c 'import os; print(min(os.sched_getaffinity(0)))')
taskset -c "$CPU" python3 "$NODE/refinement/refine.py" --binary "$NODE/target/measurement/strict-compare" --previous "$PREVIOUS" --out "$OUT"
python3 "$NODE/refinement/verify_links.py" "$OUT"
```

This measured source contains the original additional exact-initial-bit audit, so directly running its refinement/audit.py may reproduce the preserved bit-equality failure. Do not silently edit raw states or mark that assertion passed. The final postprocess/readback.py illustrates the explicitly documented floating-consistency readback for the historical observations; its SOURCE binding is intentionally historical. Adapting it to a new run requires a new source/run binding record, not pretending the old audit covers new data.

## 3. Evidence storage

`calibration.jsonl.gz` and `timing.jsonl.gz` contain complete record metadata, scores, output-time grids and every timing replicate. `states_sha256` resolves into `states/<hash>.json.gz`. Hashes address canonical JSON bytes containing the observed binary64 values; they are not the original stdout byte hashes. `verify_links.py` verifies state/selection/timing linkage.

In the final matched run, all objects fit the 16MiB per-file publication budget and RECONSTRUCTION.json is empty. If a future run has split objects, concatenate `parts_in_order` and verify the recorded original SHA-256. No historical wall-clock measurement can be regenerated byte-for-byte by simply running the solver again.

Compiled toolchains, Cargo target directories and downloaded crate caches are intentionally excluded. Netlib and LINPACK numerical source bytes and exact hashes are retained so public upstream drift cannot silently change the comparator.
