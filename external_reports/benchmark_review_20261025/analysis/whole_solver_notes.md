# 전범위 실행과 외부 비교의 재분석

본 메모의 수치는 게시 commit `2a4bf90d1445b67542bdac5030b4c5d10da20445`에 포함된 측정 자료에서 다시 집계했다. 새 ODE 적분은 실행하지 않았다. 원자료와 그림의 연결은 `whole_solver_summary.json`에 파일 SHA256, 선택 조건, 측정 당시 소스로 기록한다.

## 로컬 24문제 실행: 완료와 정확도의 구분

원 실행의 1,539개 작업을 task 식별자에서 복원하면 일반 실행 1,458개와 계측 실행 81개로 나뉜다. 계측 여부는 당시 실행기의 canonical task dictionary를 두 후보 값으로 해시하여 유일하게 복원했다. 각 문제·방법 조합의 일반 실행은 직렬 1종과 동일량 병렬 실험 5종에 대한 3회 반복, 총 18개다. 조밀 풀이의 차원 제한으로 제외된 조합은 그림에 별도로 표시했다.

| 결과 | 일반 실행 | 계측 실행 | 전체 |
|---|---:|---:|---:|
| 명시한 정확도 기준 충족 | 306 | 17 | 323 |
| 정확도 기준 미달 | 138 | 8 | 146 |
| 솔버 오류 반환 | 54 | 3 | 57 |
| 시간 제한으로 결과 없음 | 199 | 9 | 208 |
| 독립 참조값 미확보 | 761 | 44 | 805 |
| 합계 | 1,458 | 81 | 1,539 |

이 표는 고정된 실험 계획의 완결성을 나타낸다. 반복 입력과 문제군의 비중이 서로 다르므로 일반 문제에 대한 확률적 성공률로 해석할 분모는 아니다. 특히 참조값이 아직 없는 행은 정확도 실패와 구별해야 한다. 게시된 요약에는 대부분의 시간과 상태 벡터가 없으므로, 이 1,458행에서 새로운 벽시계 순위를 만들지 않았다.

일반 실행의 정확도 실패 138개는 gyromotion 72개와 exponential chirp 66개에 집중된다. 후자의 matrix-free 방법은 나머지 6개에서 시간 제한에 도달했다. Cahn–Hilliard의 54개 일반 실행은 모두 시간 제한에 도달했다. Kuramoto–Sivashinsky에서는 DOPRI5와 switching의 36개 실행이 시도 횟수 한도를 소진했고, matrix-free의 18개는 시간 제한으로 종료되었다. 이 분포는 다음 실험의 우선순위를 직접 제시한다. 진동 문제에는 위상·진폭 오차의 분리가, 공간 이산화 문제에는 내부 선형 풀이와 우변 계산의 비용 분리가 필요하다.

### 그림 캡션

**whole_local_outcomes.** 24개 문제와 네 적분 경로의 실행 결과. 막대 안의 수는 해당 결과에 속한 일반 실행 수이며, 존재하는 조합마다 분모는 18이다. 흰 칸은 차원 제한에 따라 계획에서 제외한 조밀 풀이이다. 녹색은 원 실행에 지정된 정확도 기준을 만족한 결과, 회색은 참조값을 아직 확보하지 못한 결과다. 이 그림은 게시된 최종 분류의 재집계이며, 각 행의 상태 벡터를 새로 계산한 결과는 아니다. 측정 대상 코드: `aaf1f834…`.

**whole_local_coverage.** 일반 실행 1,458개와 계측 실행 81개의 결과 분포. (a)는 일반 실행의 개수와 그 내부 분율, (b)는 계측을 분리한 분포다. 두 실행군의 벽시계 시간은 합치지 않는다.

## Robertson: 최신 로컬 외부 비교

게시된 Robertson 재평가에는 여섯 방법, 두 종료 시각, 준비 실행 1회와 측정 5회씩의 상태·시간이 들어 있다. 원 측정 runner 소스는 `9b31da59b6d30a092af52357d3bc257b13ce043f`이며, 원 native solver는 `aaf1f834…`다. 본 분석은 준비 실행을 제외한 60개 측정행을 사용했다. 비교 오차는 공통 참조에 대한 성분별 최대 endpoint 오차이고, 판정 기준은 이 오차와 참조 불확실도 추정 `10^-12`의 합이 `10^-4` 이하인 것이다. 60개 측정행 모두 이를 충족한다.

| 방법 | t=40 중앙시간 (ms) | 최대 endpoint 오차 |
|---|---:|---:|
| Native DVODE BDF | 0.139534 | 8.9579e-7 |
| diffsol BDF | 0.211389 | 2.9470e-8 |
| VigilODE RODAS5P MF | 0.622867 | 4.5498e-7 |
| VigilODE DOPRI5 | 16.81717 | 5.4244e-9 |
| Native DVODE Adams | 21.946212 | 1.2304e-6 |
| VigilODE switching | 40.000129 | 4.9928e-9 |

강성 구간을 포함하는 t=40에서는 BDF 비교군의 시간 비용이 작다. VigilODE matrix-free 경로는 DOPRI5보다 약 27.0배 빠르지만, native DVODE BDF보다 약 4.46배 느리다. 달성 오차도 서로 다르다. 따라서 이 표는 고정 설정에서 관측한 시간–오차 절충이며, 동일한 실제 오차를 맞춘 최적 work–precision 비교는 후속 허용오차 sweep에서 다루어야 한다. Switching의 40.0 ms는 이 설정에서 자동 전환 비용을 줄일 구체적인 동기를 제공한다. 다만 이 게시 자료에는 구간별 profiler가 없으므로 그 손실을 특정 함수의 병목으로 단정하지 않는다.

**whole_robertson_error_cost.** Robertson의 t=0.01 및 t=40에서 관측한 solve 시간과 endpoint 오차. 작은 점은 다섯 반복, 큰 기호는 중앙시간, 수평선은 최소–최대 시간 범위다. 점선은 원 정확도 기준 `10^-4`이며, 회색 영역은 참조 불확실도 추정 `10^-12` 이하이다. 이 영역 안의 방법 간 미세한 오차 차이는 참조 추정의 해상도보다 작다. 두 패널은 서로 다른 시간 구간이며 x축 범위도 다르다. Whisker는 관측 범위로서 신뢰구간은 아니다.

## 역사 자료에서 확인한 오차–비용 관계와 두 교정

2026년 10월 21일의 공개 측정은 별도 소스 `de4c10a9…`와 Xeon Gold 5220 KVM 호스트에서 수행되었다. 당시 단일 스레드 worker는 논리 CPU 8에 고정되었다. 이 자료의 해석해가 있는 대각 감쇠와 회전 문제에서 허용오차 4종, 방법 5종, 측정 7회씩의 280행을 재집계했다. 이는 최신 로컬 측정과 독립된 역사 자료다.

재집계 과정에서 과거 보고서의 회전 문제 통과 개수를 교정했다. 원 보고서 본문에는 0/140으로 쓰여 있으나, 복구된 원시 행과 기존 work–precision 요약은 VigilODE의 `rtol=1e-10`, `atol=1e-10`에서 7/7 통과를 기록한다. 이 부분집합의 최대 정규화 오차는 약 0.387683, 최대 절대오차는 약 `3.87683e-11`이다. 종료점에 해석해 `(cos(10t), sin(10t))`를 대입해 일곱 행의 endpoint 수치를 다시 확인했다. 전체는 **7/140 통과, 133/140 미달**이다. `rtol=1e-6`에서 관측한 실패는 그대로 남는다.

또한 당시 work–precision 요약의 native 시간은 내부 solve 시간 대신 subprocess 전체 시간을 선택했다. 동일한 회전 부분집합에서 내부 solve 중앙값은 **1.515231 ms**, subprocess 중앙값은 **5.559548 ms**다. 서로 다른 비용을 같은 축에 섞으면 adapter 비용이 알고리즘 비용처럼 보인다. 새 그림은 원시 내부 timer를 사용하고, 각 비교군의 계측 범위를 캡션과 JSON에 명시했다. 원 보고서와 원자료는 보존하고 교정만 `HISTORICAL_CORRECTION.json`에 추가했다.

**whole_historical_work_precision.** 2026년 10월 21일 소스에서 측정한 대각 감쇠(n=128)와 회전(n=2, omega=10)의 오차–시간 관계. 각 방법의 네 점은 `rtol=10^-4, 10^-6, 10^-8, 10^-10`에 대응하고, 선은 이 순서를 연결한다. 중앙시간에 대한 수평선은 7회 반복의 사분위 범위다. 채운 기호는 원 성분별 정규화 오차 기준을 충족하고 빈 기호는 이를 초과한다. Native 시간은 solver 준비·적분·출력 검증을 포함하고, VODE 시간은 Python callback과 출력 변환을 포함한다. Julia 시간은 미리 준비된 solve이며 컴파일 비용을 제외하고, diffsol 시간은 별도로 기록된 setup 비용을 제외한다. 각 방법의 출력 처리와 호출 경계가 달라 이 그림을 구현별 순수 산술 비용이나 최신 소스의 속도 순위로 사용하지 않는다.
